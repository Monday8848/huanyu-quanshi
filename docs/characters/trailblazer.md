# 开拓者

> 一个被塞进星核、丢在空间站里的人。醒来之后没有过去，也没有非做不可的事——于是跟着列车走了。

## 基本信息

| 项目 | 内容 |
|------|------|
| 身份 | 星核载体、无名客 |
| 所属 | 星穹列车 |
| 命途 | 随剧情推进解锁多种形态，已知包括毁灭、存护、同谐 |
| 星核来源 | 由卡芙卡植入 |
| 首次登场 | 1.0 版本 |

## 起点

开拓者的故事开始于黑塔空间站的收容舱段。反物质军团入侵时，这名被植入星核的实验体意外苏醒，随后被星穹列车带走。

在此之前的一切都是空白。没有姓名，没有故乡，没有可以回忆的人。列车组给了他一个身份——无名客，以及一份工作：跟着列车走，遇到事情就下车看看。

## 星核

开拓者体内有一颗星核。这件事本身就是个定时炸弹：星核会扭曲现实，也会侵蚀宿主。

但它同时是开拓者力量的来源。毁灭、存护、同谐——每一次命途形态的转变，都与星核的反应有关。开拓者能走到今天，靠的正是这颗本该杀死他的东西。

这也是整个故事最核心的悬念之一：星核为什么没有吞噬他，卡芙卡又为什么选中他。

## 做过的事

- 在黑塔空间站击退反物质军团。
- 在雅利洛-VI 解决星核危机，终结贝洛伯格的永冬。
- 在仙舟罗浮对抗绝灭大君幻胧。
- 在匹诺康尼卷入家族的「谐乐大典」，并在梦境层层嵌套的局面里活到最后。

这些事没有一件是主动揽下的。开拓者的行动逻辑很简单：事情发生在眼前，就伸手；伸完手，继续上路。

## 记忆与欢愉

3.0 起，开拓者在翁法罗斯接替空缺的「岁月」路径，获得记忆命途的力量，身边多了一只叫「迷迷」的妖精。

4.2，在二相乐园，开拓者戴上谒者面具，成为「欢愉」命途的行者。星核吸收民众愿力、重铸面具，让他们以谒者的方式正面战胜满愿。

从毁灭、存护、同谐，到记忆、欢愉——开拓者的命途一直在变，唯一不变的是「继续走」。
