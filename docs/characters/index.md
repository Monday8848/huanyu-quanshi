# 人物

收录全部自机角色与剧情重量级 NPC。同属一个阵营的人排在一起——查到某个人的同时，也就看到了他的同僚与对手。

排序规则：先按所属势力分组，组内按名字排；归属有争议的角色放在「其他」并说明缘由。

## 星际和平公司

- **[砂金](./aventurine)** · 存护 · 石心十人 —— 把「幸运」当成筹码的赌徒，匹诺康尼一役的关键推手。

## 建设中

首批清单里还有 **流萤、星期日、景元、黄泉**，以及各阵营的其他角色。条目按「高频优先」逐个补齐——被搜得最多的人，先写。

后续分组顺序：星穹列车 → 星核猎手 → 仙舟联盟 → 星际和平公司 → 家族 → 翁法罗斯 → 其他。
