# 椒丘

> 「说了很多次啦，这叫医食同源——烹煮即是炼药；炼药即是烹煮。以食疗济愈病患，乃是我的独门绝学。俗话说，不想当医士的厨子当不了好幕僚……」

## 飞雨湖畔的医者

常以笑脸迎人，实际颇有心计。出身于丹鼎司名家。曜青飞雨湖畔，狐人少年背着药篓划着小舟，捞荇菜、撷荷花，口中念着「甘甜入脾，滋润可口」——医食同源的道理，是从湖光雨色里长出来的。

## 九宫格与战场

曜青军队常年征战域外星球，他对鼎镬药式进行诸多改进，以应对艰巨复杂的驻扎环境——发明了名为「九宫格」的鼎镬药式，尤其精于能带给人痛感的辣味食物。因药式的罕见与奇效，他的名声迅速传遍曜青军队。

但成就减轻不了沉重：每一日出发的鸣笛响起，他曾治好的病患将重新踏上战场；每一日归营的脚步响起，围坐在鼎镬边的面孔总会少上几个。

## 心死与出山

那场惨烈的战争里，「瞰云镜」承载联盟万亿众生的愿力得到了祂的回应——灼热的气浪、化作血雾的丰饶孽物、被光浪夷平的山峦……他目睹了一切。此后他曾一度心死避世，不再行医。

直到为了医治「天击将军」飞霄，他再度出山。湖还是那个湖——「唉，太淡了……」他摇着头，撑船往回而去。他岂止会烹鱼，更烹着一副不肯认命的心肠。
