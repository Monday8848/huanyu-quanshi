## 沉默的护卫

丹恒在列车组里话最少。他负责警戒、断后、处理那些不该让三月七看到的场面，做完就退到一边，不解释也不邀功。

这份沉默不是冷漠，而是一种自我约束。他很清楚自己身上背着什么，也很清楚一旦开口，就要面对什么。

姬子的说法是：没有丹恒的许可，她不能随便说他的事。「好像有什么敌人在追逐他，丹恒来到星穹列车是个巧合，留下则是因为无处可去。」

## 持明与饮月

丹恒是持明族。这个种族拥有蜕鳞转生的能力，传承的是「龙」的血脉，在仙舟社会中地位特殊。

更麻烦的是他与饮月君的关系。饮月君是持明族历史上的龙尊，也是云上五骁之一；丹恒则被普遍认为是饮月君的转世或继承者。这意味着两件事：他天生拥有极强的力量，以及他必须承接饮月君留下的全部旧账。

## 云上五骁

云上五骁是仙舟历史上最负盛名的五人组：

| 成员 | 身份 |
|------|------|
| 景元 | 罗浮神策将军，智识 |
| 镜流 | 「无罅飞光」，剑首 |
| 丹枫 | 持明龙尊，饮月君 |
| 应星 | 短生种工匠，后来的刃 |
| 白珩 | 狐人无名客 |

五人的分裂，起因是白珩之死。丹枫与应星试图用化龙妙法把她带回来，结果酿成大祸——鳞渊境水患、持明族内乱。景元出手镇压，丹枫被判蜕鳞轮回，应星则被「倏忽」赐予长生，成为魔阴身，也就是后来的刃。

这段往事没有一个干净的对错。丹恒背着的，正是这份说不清的东西。

## 与刃的旧怨

刃追着丹恒，从一颗星球追到另一颗星球。

两人的恩怨源自云上五骁的旧事——那场分裂让昔日的同伴变成仇敌，也让丹恒背上了「背叛者」的名声。丹恒从不辩解，因为他自己也不确定当年谁对谁错。

罗浮之行让这段旧怨有了了结的机会，但了结不等于和解。

## 罗浮之行

1.2 版本，列车停靠罗浮。丹恒本想避开，结果还是被卷了进去。

幻胧之乱中，他被迫直面饮月君的传承，也必须在自己「不想成为的人」和「必须成为的人」之间做选择。最后他选了后者——不是为了仙舟，而是为了车上的人。

## 腾荒

3.6，丹恒在翁法罗斯的神悟树庭与大地泰坦的巨龙荒笛共鸣，接替即将闭合的「大地」路径。

他以「丹恒·腾荒」的形态承载火种内约二百一十六万数据生命体，完成大地试炼。龙灵与同袍护盾由此而来。
