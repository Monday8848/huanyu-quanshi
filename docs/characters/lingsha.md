# 灵砂

> 「我是土生土长的罗浮持明，曾以『丹朱』之名拜师求艺。但师父陷入政争，被流放他乡，我也随她远走。如今改换姓名『衣锦还乡』，真是感慨万千。」

## 丹鼎司岁月

伶俐秀慧的持明医士，嗅觉敏锐，常以此识别病症，并以香薰安定他人心神。幼时在丹鼎云烟缭绕中成长——一声炸响，她手捧晶莹的丹药跑向师父云华的诊室；师父凝神诊脉时，她凑近病人身旁，嗅一嗅，便能补上脉象难以解释的部分。

在丹鼎司跟随云华学习的岁月是她一生中最为充实愉快的时光：魔阴身的起源、丰饶孽物的本质、缓解魔阴发作的丹药——每一项课题都令她流连忘返。

## 离开与再出山

丹鼎司的局势风云诡谲，师父陷入政争被流放。她很快明白，或许离开是更好的选择。借着龙师的帮助，师徒二人离开罗浮，前往朱明。「如果不懂得如何面对尘俗，自己的理想迟早会迎来破灭的一天」——她暗下决心，绝不让此事重演。

在朱明，她结识龙尊「炎庭君」，拜入「金鳞燃犀」一脉，学习针灸、熏香之术；以燃香为引，巧妙融合罗浮丹术与朱明「金鳞燃犀」之法，渐渐成为联盟无人不晓的医师。

## 司鼎的改革

接到联盟委任、出任罗浮丹鼎司司鼎时，她一时恍惚。可回到罗浮，她失望地发现丹鼎司比她离开时内斗更甚，并为它数出四宗罪：**利益错杂，裙带缠连；事无专执，推诿扯皮；奖罚不当，人心难平；轻贱研究，不重出诊**。她的改革，就从这四件事开始。

善于处理混杂的人际关系——即使心底暴躁如雷，表面上依旧滴水不漏。
