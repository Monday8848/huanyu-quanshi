# 星期日

> 他想给所有人一个没有痛苦的梦。代价是，没有人再需要醒来。

## 理想主义者

星期日不是那种把「邪恶」写在脸上的反派。他温和、有礼、逻辑清楚，真心相信自己是在救人。

他见过太多痛苦：流离失所的人、被命运碾碎的人、在现实里活不下去的人。匹诺康尼的梦境能收留这些人，让他们在梦里过上想要的生活。在他看来，这不是欺骗，是慈悲。

问题在于，梦要一直做下去，就不能醒。一座永远不醒的城市，等于把所有人的余生都定格在同一个瞬间。

## 谐乐大典

2.0 版本的谐乐大典，表面是庆典，实际是星期日计划的启动仪式。

他想借这场大典，让匹诺康尼彻底脱离现实规则的约束——不再受公司管辖，不再需要向任何人交代，整座城市成为一座自给自足的梦。为此他需要列车组的配合，或者说，需要列车组不要碍事。

他一开始用的是礼遇：邀请、招待、给足面子。等发现列车组不会被收买，手段就升级了。

## 与知更鸟

星期日和知更鸟是彼此唯一的亲人。他保护她，替她挡下家族内部的所有脏事，让她可以只做一个唱歌的人。

知更鸟最终站到了他的对面。这不是背叛，是两个人对「爱」的理解不同：他认为爱是把对方放进一个安全的梦里，她认为爱是让对方有醒来的权利。

这场分歧比任何战斗都更让星期日动摇。

## 失败之后

2.2 版本，星期日的计划被列车组与匹诺康尼的众人联手阻止。他没有死，也没有被彻底清算——家族需要一个能对外交代的结果，而他需要一个能继续活下去的身份。

2.7 版本，他成为可操作角色。离开匹诺康尼之后，他一度与列车同行，试图弄清楚一个问题：如果梦不是答案，那现实里还有什么值得人醒过来。
