# 鳞渊境

> 罗浮最古老的地方不在天上，在水下。

## 持明族的家

鳞渊境是持明族在罗浮的聚居地。它不在罗浮的常规城区里，而是一处独立的洞天，水脉纵横，建筑沿水而生。

持明族是仙舟上的龙裔，能转生、能化龙，也有自己的礼制与禁忌。鳞渊境就是这套礼制的容器：外人进得来，但看不懂。

## 龙尊

持明族有「龙尊」的传统。龙尊是族群的领袖，也是力量的承接者，传承方式与转生有关。

1.3 版本的剧情里，丹恒被卷回了这条线。他的前世丹枫曾是龙尊，这段过去不只是他个人的包袱，也牵动着整个持明族的秩序。

## 丹恒的选择

鳞渊境是丹恒必须面对的地方：回去，意味着承认自己是丹枫的转世；不回去，持明族的传承就要断。

剧情给出的答案不是简单的「接受」或「拒绝」。丹恒回去了，处理了该处理的事，然后依然选择做丹恒，而不是丹枫。鳞渊境因此成了他角色弧光的终点，也是新起点。

## 水与记忆

鳞渊境的水有特殊性质，与持明族的转生机制有关。

在设定上，这里的水承载着族群的记忆：每一代龙尊的过去都沉在水底。这也是为什么鳞渊境看起来安静——它装着太多东西。
