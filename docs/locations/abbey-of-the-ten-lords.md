# 幽囚狱

> 「历史悠久的仙舟监狱系统，由仙舟人与持明共建，专司镇压触犯律条、造作诸恶的重犯与孽物。」

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 洞天（监狱系统） |
| 所属 | 罗浮 |
| 共建方 | 仙舟人、持明族 |
| 管理 | 十王司（司狱、主簿、判官、冥差） |
| 特殊结构 | 横跨多个洞天，与鳞渊境波月古海交叠 |
| 关联地点 | 鳞渊境、北号峰 |

## 一座不属于任何一个洞天的监狱

幽囚狱的特殊之处在于它没有单一入口：它**同处于多个洞天之中**，与鳞渊境的波月古海有交叠，可以从鳞渊境进入。

这个设计不是为了好看。监狱需要一个「不可逃」的结构，而洞天是可以被切断的空间泡——把几处空间的接缝改成牢房，比任何围墙都可靠。

它由仙舟人与持明族共建。持明负责的部分与古海有关：水下、封闭、需要蜕生者看守的地方，本来就是持明的地盘。

## 狱层

| 狱层 | 特点 | 用途 |
|------|------|------|
| **阴寒狱** | 阴风阵阵 | 关押、惩处畏寒的孽物 |
| **焦热狱** | 焦热难当 | 关押、惩处惧热的孽物 |
| **断狱轮钥** | 直贯狱心的「钥匙」巨柱 | 解开通往幽狱之底的道路，其下关押犯尽十恶逆大罪者 |

把「寒」与「热」做成两种刑具，逻辑很清楚：孽物有不同的生理弱点，监狱按弱点分类关押。而最深处的门不是门，是一根柱子——「断狱轮钥」既是结构也是锁，只有转动它才能抵达狱底。

## 镇恶门

幽狱大门铸有凶煞巨面。古国神话称此威灵为「方相」，因其善吞邪祟，常被绘于十王司相关之物上。

方相是中国古代傩仪里的驱疫之神，游戏把它挪用成狱门的门神——一个专门吃邪祟的东西守着一群邪祟，这个安排本身就很仙舟。

## 其他设施

- **勘录舍**：管理调控整座监狱各处的中枢。
- **北号峰**：极境洞天，阴寒狱层的寒气由此引来——监狱的制冷系统接在一整座山上。

## 里面关过谁

- **呼雷**：步离人战首，被囚于幽囚狱，后在被策划的阴谋中出逃。
- **岁阳**：造化洪炉中封印着岁阳，用于为仙舟提供能量并消磨其自身能量——这不算幽囚狱，但逻辑相同：把危险的东西关起来，顺便榨出用途。
- **触犯「不赦十恶」者**：狱底关押的就是这一类。
