# 罗浮

> 一艘装着一座城的巨舰。外表是仙家气象，里面是市井、码头、牢狱和药炉。

## 一座会飞的城

罗浮首先是武器，其次才是城市。

它的舰体规模足以容纳山脉与城区，主炮一开，威力可以击穿行星级目标。但住在上面的人过的是日子：开店、上班、吵架、逛夜市，和任何一座城市没有本质区别。

这种反差是罗浮最迷人的地方——它把「战争机器」和「烟火人间」叠在同一副骨架上，而且叠得毫无违和感。

## 城区

- **长乐天**：罗浮的核心城区，商业、行政与居住混在一起，也是外来访客最常活动的地方。
- **金人巷**：市井气息最重的一条街，小吃、杂货、江湖消息都在这里流通。
- **丹鼎司**：掌医药与丹药，也是仙舟长生技术的核心机构。
- **鳞渊境**：持明族的聚居地，外人进入需要许可。
- **绥园**：更幽深的一片区域，与仙舟的旧事和秘密有关。
- **幽囚狱**：仙舟的监狱，关押的不只是罪犯。

## 行政与军事

罗浮的日常治理由六司分担，军事由云骑军负责。十王司独立于六司之外，掌刑狱与生死判定，是罗浮最让人忌惮的机构。

这三套系统互相制衡，也互相推诿。危机真正来临时，反应速度往往取决于哪一套系统先意识到问题的严重性。

## 幻胧之乱

1.2 至 1.3 版本，绝灭大君幻胧渗透罗浮，寄生并替换了关键人物，把整艘仙舟推向内乱。

这场动乱的结局是幻胧被击败，但代价不小：罗浮的内部信任被撕开，持明族的旧账被重新翻出，丹恒的过去也被迫摊在所有人面前。
