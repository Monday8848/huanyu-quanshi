# 白日梦酒店

> 白日梦酒店是匹诺康尼在现实中的主体建筑，也是梦境中的地标、现实与梦境的连接点。

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 酒店、入梦设施 |
| 所属 | [家族](/factions/family) |
| 结构 | 48 个扇形区域（数字 10–12 为「铂金套房」） |
| 关键设施 | 入梦池、中央大堂、贵宾休息区与宴会厅 |
| 首次登场 | 2.0 版本 |

## 入梦池

客房中间安放着贝壳形的「入梦池」——一种特殊的入眠装置。宾客一旦躺下便能前往真正的匹诺康尼：放松身体，意识沉入黑暗，在轻柔的话语引导下描绘幸福的美梦，待到十二下钟声响起，便会在梦之世界中醒来。睁眼后，视野里会出现梦境特有的光景：漂浮的家具与餐具，以及「梦泡」。

这个流程设计得很聪明。游客不会觉得自己在「进入」另一个世界，只会觉得在住酒店。

## 中央大堂

大堂负责办理入住退房、现实货币与梦境货币的换算。梦境大堂中有巨型泡状鲸鱼悠然游动，目送前往梦之都市的人们——这些游鱼来自钟表匠的点子。

大堂里巨大的时钟实际是扇区标识，第四根指针从不转动，始终指向扇区编号所在的刻度。表盘上的匹诺康尼文字，对应的英文是「**stay asleep（一直睡着）**」与「**never awake（不要醒来）**」。

数字为 10–12 的扇区被称为「铂金套房」区域；开拓任务中星穹列车组所住的，即「红心十二区」。铂金套房的住客可以使用贵宾休息区与宴会厅。

## 门童米沙

酒店的门童米沙是匹诺康尼线里最不起眼也最重要的角色之一。他记得每个客人的名字，说话总是欲言又止——他的家在「稚子的梦」，钟表匠的记忆异化而成的梦境迷域，如今溪涧已经失去流向，时针也早已停止转动。
