# 白日梦酒店

> 你在这里睡一觉，醒来时已经在另一个世界。房费按梦算。

## 入口

白日梦酒店是匹诺康尼对外的门面。所有来客都先到这里：办入住、领房卡、听注意事项，然后在房间里入睡，进入梦境之城。

这套流程设计得很聪明。游客不会觉得自己在「进入」另一个世界，只会觉得在住酒店。等到发现街上的一切都不太对，已经晚了。

## 现实与梦的交界

酒店本身处在两界之间：大堂、走廊、房间是现实，推开某些门就是梦。

这种结构让酒店成了匹诺康尼最特殊的地方——它是唯一一个「醒来」和「入梦」都成立的空间。2.0 版本的开场就设在这里，很多关键对话也发生在大堂和走廊。

## 门童

酒店的门童米沙是匹诺康尼线里最不起眼也最重要的角色之一。

他记得每个客人的名字，知道很多不该知道的事，说话总是欲言又止。他的存在暗示了一件事：在这座城市里，连「服务人员」都不只是服务人员。

## 房间与层级

酒店的房间对应梦境的层级。住得越深，梦越真，也越难醒。

家族对房间的分配有严格标准：普通游客住标准层，贵宾住高层，而某些房间从不对外开放。这些「不开放的房间」，后来成了剧情的关键。
