# 黑塔空间站

> 一座漂在星际航道上的私人研究所。主人很少回来，访客大多是来借设备的。

## 基本信息

| 项目 | 内容 |
|------|------|
| 所有者 | 黑塔（天才俱乐部成员） |
| 位置 | 星际航道附近，具体坐标不公开 |
| 主要舱段 | 主控舱段、收容舱段、支援舱段 |
| 常驻人员 | 研究员、维护人员、安保，以及数量不明的「藏品」 |
| 关键设施 | 模拟宇宙入口、星核收容装置 |
| 首次登场 | 1.0 版本 |

## 一座不像空间站的空间站

黑塔空间站名义上是科研设施，实际更像黑塔的私人仓库：她感兴趣的东西都往里搬，搬完就不管了。

这种管理方式让空间站同时具备两种气质——前沿到离谱的科研能力，和随时可能出事的混乱。收容舱段里关着什么，连常驻研究员都说不全；支援舱段的设备可以随时被调用，但没人知道下一次系统升级会不会把整段供氧改掉。

## 舱段结构

- **主控舱段**：空间站的行政与指挥中枢，也是对外接待的地方。
- **收容舱段**：存放危险造物与研究对象。安保等级最高，事故率也最高。
- **支援舱段**：能源、维生、维修等后勤系统所在。
- **基座舱段**：与外部对接的港口区域，货运与人员往来的通道。

## 模拟宇宙

空间站最著名的设施是模拟宇宙——一个用算力推演宇宙规则的系统，由黑塔与几位天才俱乐部成员共同开发。

它最初只是为了验证某些理论，后来逐渐变成一个可以「进入」的空间。模拟宇宙里的星神、命途与历史片段，都是基于现有数据推演出来的近似物，不完全等于真实，但足够接近。

## 空间站危机

1.0 版本，反物质军团入侵空间站。入侵的直接后果是收容区失控、大量危险造物外泄，以及一名被植入星核的实验体苏醒。

那名实验体就是后来的开拓者。空间站危机是星穹列车与军团第一次正面冲突，也是整个故事的起点。

危机之后，空间站修复了大部分损伤，但黑塔对这件事的态度依旧冷淡——她更关心的是入侵过程中产生的数据。

## 与外界的关系

| 对象 | 关系 |
|------|------|
| 星际和平公司 | 有合作，但公司管不到这里 |

| 星穹列车 | 危机后保持往来，列车组把这里当作中转站 |
