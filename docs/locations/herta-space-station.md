# 黑塔空间站

> 一座围绕湛蓝星公转运行的空间站，从银河各处收集遗器和奇物，记录它们的形致与功能，建立起系统的观测与研究方法——最终从谜题中找出更加费解的谜题。

## 科员构成

空间站成员涵盖：天才俱乐部 #83 黑塔的旧日追随者、星际和平公司常驻员工、无所属的异星求知者，以及各方势力挑选并输送于此深造的年轻学者。

## 空间站结构

| 舱段 | 说明 |
|------|------|
| 主控舱段 | 空间站的核心区域，具备独立星际航行能力；有监察域、监控防御系统，以及「全宇宙最（不）神秘的办公室」——黑塔的办公室 |
| 基座舱段 | 星际舰船与空间站二段式分离结构的核心，科员日常生活的主要活动区域；医疗舱室号称只要人还有口气在，总有办法救活 |
| 收容舱段 | 收容奇物的储室舱段；中庭建有巨大环形甬道，高低错落连通各科室藏品 |
| 支援舱段 | 后勤核心，存储物资、管理能源核心，配备完整的接引月台 |
| 禁闭舱段 | 曾是前沿科研的实验重地——集散中心、温床、药物制备间、生命烘焙箱、培养皿——现因某种原因已封闭 |

收容舱段中最特别的是「无明之间」：黑塔的私人藏室，藏品筛选标准只有一个——「和黑塔一样有趣」。

## 空间站生物

- **佩佩**：站长艾丝妲的宠物狗，由阿兰抚养，从小和阿兰感情非常好。性格贴心，能感知人的心情变化；在「知名不具」任务中帮开拓者寻找失踪的阿兰。
- **呜呜伯**：外形像幽灵的球形无实体生命，星灵的亚种。按「阿德勒分级法」属于中度收容关注等级——虽无性命之虞，却有麻烦之忧。其行为遵循四种逻辑：快乐的流窜于五个角以上的房间；悲伤的聚集于冷僻房间共享哀思；愤怒的暴露于光线充足处，部分会化为银河齑粉；平静的则进入一生中行踪最诡秘的时刻——大肆破坏、戏弄周遭生物，纯粹为了恶作剧，民间谑称「戏命鬼」。
- **阮•梅造物**：阮•梅制造的人工生命体，外形酷似湛蓝星传统点心与猫狗，加入不同馅料与情绪制造，性格各异，最大共同点是对制造者抱有深厚情感。豆沙灰灰（悲观爱哭鬼）、盐渍冬梅（唯一亲近豆沙灰灰的造物）、芝士流心（自称天才）、无明遗孤（唯一会说人话、最聪明的造物）……目前所有造物都被饲养在禁闭舱段内。

## 空间站危机

军团入侵时，收容区失控、舱段损毁，科员荣仓终在入侵中遇难。危机之后，空间站保住了主体结构——以及它继续收藏全银河谜题的资格。
