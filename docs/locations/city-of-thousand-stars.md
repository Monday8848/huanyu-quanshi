# 千星城

> 能成为这里的一员，说明你要么在公司的地位举足轻重，要么做出过举足轻重的贡献。

## 基本信息

| 项目 | 内容 |
|------|------|
| 所属 | 星际和平公司 |
| 性质 | 公司管理的高端城市 |
| 主要区域 | 中心城区、指针塔、空声院、生研院 |
| 首次登场 | 4.5 版本 |

## 城市

千星城是公司给「自己人」准备的地方。

能进城的人，要么职位够高，要么贡献够大。城里的服务按职级分层：黄金、白金、黑金、琥珀，每一层都有明确的权限与边界。

## 职级

黄金级覆盖 P30 以下，白金级 P30—P35，黑金级 P36—P40，琥珀级 P40 以上。

级别越高，免费项目越多，优先权越大。城市把公司的等级制度做成了建筑本身。

## 生研院

生研院是千星城的科研机构，主管亚婆离在这里研究幻造种与古兽源质。

4.6 中，开拓者与虚照、不死途深入生研院，发现古兽血肉正是幻造种产线的原料之一，也揭开了告死魔凶案的另一层真相。

## 4.7

4.7 结尾，星穹列车离开二相乐园，前往千星城出席「反毁灭同盟」发布会。

开拓者以「阿基维利」之名向全银河发出同盟号召。千星城从公司的私产，变成了一个更大棋局的入口。
