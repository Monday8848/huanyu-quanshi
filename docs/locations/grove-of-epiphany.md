# 神悟树庭

> 「神悟树庭，滋养知识的学府，诞育哲人的摇床。」

## 基本信息

| 项目 | 内容 |
|------|------|
| 别称 | 呓语密林（灾后）、辉痕圣林（3.6 后） |
| 信仰 | 理性泰坦瑟希斯 |
| 性质 | 学术城邦 |

## 学术之城

神悟树庭围着圣树而建。瑟希斯以一棵巨圣树的形象降临世间，允许人类在它身旁漫步、醒神和思辨，获取知识。

学者在树荫下辩论、互相挑刺，把「求知」当成一种生活方式。树庭七学派各有各的答案，唯一共识是：问题比答案重要。

这座城的权力结构也由此而来：七贤人不是官员，是七个学派的代表；城邦的重大决定由辩论产生，辩论输了的人可以继续写文章反对。

## 瑟希斯

理性泰坦瑟希斯执掌智慧、生态与植物荣枯。

它不要求信徒跪下，只要求他们思考。因此树庭的神殿更像图书馆，祭司更像讲师。它曾因意外失去神体，身躯四散，墨涅塔搜集这些碎片想用丝线把它收拢，创生若虫也加入了这场苦旅。最终瑟希斯以圣树形态重新立起，裂痕留了下来——「裂分之枝」的名字由此而来。

## 那刻夏

那刻夏是树庭最出名的异端，也是七贤人之一。他质疑教条，也质疑神谕，名言是「这世界遍地虚假，唯有我才是真实」。

**3.1 版本**，树庭遭黑袍剑士（盗火行者）袭击。那刻夏用炼金术粉碎灵魂、布下大阵，把一众黑潮造物困在樊笼中，并打算与瑟希斯同归于尽，把火种送往奥赫玛。瑟希斯没有同意——它把火种分成三份藏匿，化名「卡吕普索」与开拓者等人同行，考察这些人是否值得托付，最后才在那刻夏体内把火种拼合。

同一场袭击中，缇安拼尽全力打开百界门，与遐蝶配合把盗火行者送走，众人平安返回奥赫玛。

**3.2 版本**，那刻夏脱离金线监视，主动寻求元老院庇护，随后与寄宿体内的瑟希斯一同登上云崖，觐见负世泰坦刻法勒。他归还火种后肉身彻底归殁，灵魂在冥界见到遐蝶，完成了创世猜想的证明。

## 呓语密林

树庭被黑潮吞没后，地图上的名字变成「呓语密林」。圣树还在，学派散了，藏书被黑潮泡烂。

3.6 版本，树庭再遭毁灭一击，化为「辉痕圣林」。灰烬王座、金枝堂奥、焚心创口还在，书却烧得差不多了。

一座以书立城的城邦，最后剩下的是三个地名。
