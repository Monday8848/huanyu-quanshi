# 雅努萨波利斯

> 自那三相神谕垂怜的圣地，信使分作千身，启程远行。

| 项目 | 内容 |

| 首次登场 | 3.1 版本 |

## 宗教圣地

雅努萨波利斯不属于任何城邦。它超脱地缘政治，只负责一件事：传达神谕。

命运三泰坦在这里发出神谕，雅努斯在这里守着他的门。门既是通道，也是牢笼——门径之神同时是隔绝与监禁之神。

## 万径之门

雅努斯的力量让「路」本身成为神迹。缇里西庇俄丝穿过万径之门，把自己分成千名信使，把救世的神谕送往各地。

从那天起，雅努萨波利斯的每一块石头上都可能站着一位信使。

## 命运重渊

灾后，圣地只剩神殿，沉入「命运重渊」。

3.1 中，开拓者在命运重渊见到已死的岁月泰坦欧洛尼斯，获记忆星神浮黎瞥视，身边出现粉色小狗「迷迷」。

## 结局

缇安在这里耗尽神力，最后一次开启百界门。此后，雅努萨波利斯再没有新的神谕。
