# 雅努萨波利斯

> 「自那三相神谕垂怜的圣地，信使分作千身，启程远行。」

## 宗教圣地

雅努萨波利斯不属于任何城邦。它超脱地缘政治，只负责一件事：传达神谕。

命运三泰坦在这里发出神谕，雅努斯在这里守着它的门。门既是通道，也是牢笼——门径之神同时是隔绝与监禁之神，所以它的圣地既是全世界的十字路口，也是一座关押圣女的监狱。

缇里西庇俄丝自幼被囚在三相圣地数十年。她不是被谁抓进去的，是被「圣女」这个身份关进去的。

## 命运三相殿

命运三相殿建在雅努斯神体之上，是火种的保管处。

3.1 版本，缇宁被万敌的老师克拉特鲁斯挟持，为兑现「让你亲眼见到神谕」的承诺，缇宝、缇安、缇宁三人重返三相殿。她们从殿内左侧通道深入，走到「雅努斯门径之泰坦心脏所在，火种保管处」，才发现欧洛尼斯已经死了，连火种都被盗火行者夺走。

## 万径之门

雅努斯的力量让「路」本身成为神迹。光历 3760 年，缇里西庇俄丝背负火种穿过万径之门，把自己分成千名信使，把救世的神谕送往各地。

从那天起，雅努萨波利斯的每一块石头上都可能站着一位信使。也是从那天起，每用一次神力，就有一个「她」消失。

## 3.1：缇安之死

盗火行者对三人出手。缇安拼尽全力张开一扇百界门，把缇宝与缇宁送回安全的地方，自己与保护她的克拉特鲁斯一同跌落山崖，化作一个布娃娃——就像过去离开的那些缇里西庇俄丝一样。

此后，缇宁带着白厄回到缇里西庇俄丝盗取火种的那天，一路帮助当初的她逃离，直到见证她握着火种纵身一跃。

千年前的缇里西庇俄丝曾担忧自己会动摇，于是在那里留下一封信：一个未来的自己帮助过去逃离的故事。她希望自己永远记得，在旅途的最初，是想要走向明天的理想让她迈出脚步。

## 命运重渊

灾后，圣地只剩神殿，沉入「命运重渊」。

3.1 中，开拓者在命运重渊见到已死的岁月泰坦欧洛尼斯，获记忆星神浮黎瞥视，身边出现粉色小狗「迷迷」。同一趟行程里，众人穿过预言书库、解开雅努斯迷津、走进缇里西庇俄丝的住处，把这条神谕之路从头走了一遍。

## 结局

缇安在这里耗尽神力，最后一次开启百界门。此后，雅努萨波利斯再没有新的神谕。

第二轮回中，缇宝在光历 4123 年耗费大量神力，秘密开启一条连通斯缇科西亚与创世涡心的通道。最后一个缇里西庇俄丝于 4259 年燃尽。
