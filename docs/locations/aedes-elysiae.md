# 哀丽秘榭

> 「哀丽秘榭，遗世独立的边陲村落，如今只余晦涩的传说。」

## 边陲村庄

哀丽秘榭在永夜之帷的庇护下，保留了麦田、风车与海滨。

这里没有圣城的气派，也没有树庭的学问。这里只有一群知道世界快完了、但还是照常收麦子的人。欧洛尼斯的帷幕替他们挡住了黑潮，也替他们挡住了「外面正在发生什么」的消息。

这种闭塞既是保护，也是代价：村里人活得比谁都安稳，却比谁都晚知道真相。

## 白厄与昔涟

白厄从这里出发，去了奥赫玛，成为「无名的英雄」。

昔涟的名字则留在村庄的传说里。3.4 版本，玩家在这里走过白厄的过去；3.6 版本，三月的相机把长夜月拖进哀丽秘榭的记忆迷宫——村庄成了审判场：谁想留下，谁想忘记，谁愿意醒过来，都要在这里回答。

## 迷迷

村庄附近的迷路迷境住着妖精「迷迷」。它跟着开拓者离开翁法罗斯，又在关键时刻把记忆叼回来。

没人说得清迷迷到底是什么。它自己也不说。欧洛尼斯称浮黎为「天父」，而迷迷第一次出现，正是在开拓者获得浮黎瞥视之后——这两件事之间有没有关系，剧情没有给答案。

## 记忆的保存

哀丽秘榭是翁法罗斯少数「记忆比现实更坚固」的地方。

村庄早已不在，但它的麦田、风车与渡口被完整地保存在记忆里。3.6 的记忆迷宫就建在这份保存之上：走进去的人看见的不是废墟，是当年的黄昏。
