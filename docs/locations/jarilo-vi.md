# 雅利洛-VI

> 一颗被判了死刑的星球。寒潮封住了地表，城市靠星核的热量续命，所有人都在等一个不会来的春天。

## 基本信息

| 项目 | 内容 |
|------|------|
| 星球状态 | 地表冰封，仅存一座城市 |
| 主要城市 | 贝洛伯格 |
| 灾变原因 | 星核降临，引发永冬 |
| 现存势力 | 贝洛伯格政权、银鬃铁卫、下层区居民 |
| 关键设施 | 造物引擎、星核收容装置 |
| 首次登场 | 1.0 版本 |

## 永冬之前

雅利洛-VI 曾经是一颗正常的星球。有大气、有海洋、有城市，也有自己的文明。

星核降临之后，气候系统在极短时间内崩溃。气温骤降，地表被冰雪覆盖，绝大多数聚落无法维持，文明被迫收缩到最后一处还能供暖的地方——贝洛伯格。

## 星核与炉心

贝洛伯格能活下来，靠的是星核。

城市把星核封在炉心里，用它的能量维持温度、供电、生产。这是一个极其危险的安排：星核会扭曲现实，长期接触它的人会出现异变。但如果不这么做，全城的人会在一周内冻死。

于是贝洛伯格活成了一个悖论：它必须依赖正在杀死这颗星球的东西才能活下去。

## 地表与遗迹

永冬之后的地表只剩下废墟和雪。旧时代的城市、道路、研究设施都被埋在冰层下，偶尔被风暴掀开一角。

雪原上还游荡着被星核影响产生的怪物，以及一些没能撤进贝洛伯格的人。他们中的一部分活了下来，用各自的方式在冰原上维持着文明之外的秩序。

## 危机的终结

1.0 版本的主线里，星核问题被彻底摊开：贝洛伯格的最高统治者与星核做了交易，试图用整座城市换取一个虚假的未来。

列车组介入后，交易被终止，星核被取出，贝洛伯格的供暖系统面临重构。永冬没有立刻结束，但这颗星球第一次有了「春天会来」的可能。
