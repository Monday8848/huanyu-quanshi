# 渡画泉隐

> 「画中世界」与现实的交界。从这里开始，幻造种将告别现实，遁入画中。

## 基本信息

| 项目 | 内容 |
|------|------|
| 所属 | 二相乐园 |
| 性质 | 两界交界、临终关怀之地 |
| 主要区域 | 泉隐港、渡画泉隐酒店、绘世商店街、千愿之荫 |
| 首次登场 | 4.3 版本 |

## 交界

渡画泉隐是生与死的码头。

幻造种在这里整理跨越百年的经历与故事，然后走进画中，了却尘缘。公司在这里建了温泉酒店，接待意图隐遁与即将消散的幻造种。

## 千愿之荫

传说千愿之荫与幻月秘庭的神木同出一系。

幻造种把它视为生命与愿望的象征，在离开尘世前，把所剩的心愿寄托、归还给它。树不回答，只把愿力收好。

## 4.3

4.3 中，开拓者在这里追查绘世的过去，也第一次直面「幻造种也会死」这件事。

二相乐园的底色不是狂欢，是告别。渡画泉隐只是把这句话说出来了。
