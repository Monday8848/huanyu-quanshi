# 悬锋城

> 那沉入迷雾的悬锋，纷乱与战争之城！

## 基本信息

| 项目 | 内容 |
|------|------|
| 信仰 | 纷争泰坦尼卡多利 |
| 形态 | 移动要塞 |
| 美德 | 勇气、荣耀、理智、坚韧、牺牲 |
| 王储 | 迈德漠斯（万敌） |
| 首次登场 | 3.1 版本 |

## 战士之城

悬锋城是一座会移动的要塞。城随军走，军随神走。

悬锋人以战死为荣，五条美德刻在城门上：勇气、荣耀、理智、坚韧、牺牲。前四条是给活人的，最后一条是给死人的。

## 尼卡多利

纷争泰坦尼卡多利是悬锋的立国之神。它锻斫世百兵，赐下「天谴之锋」，让歌耳戈部族砌成第一代悬锋城。

后来它被黑潮侵蚀，陷入疯狂。悬锋人没有弃城，而是选择陪神一起疯。

## 万敌

万敌是悬锋王储。他杀死父王欧利庞，又在 3.1 中击落尼卡多利，接过纷争火种。

悬锋千年王朝在他手里终结。他没有重建王座，而是独自返乡，继续抗击黑潮。

## 纷争荒墟

3.1 后，悬锋城化为「纷争荒墟」。逐魂隘口、止戈残间、悬锋斗技场还在，只是再没有观众。
