# 晨昏之眼

> 云间城邦随岁月离析，昏光庭院再度敞开门扉，为永夜捎来微光。

## 基本信息

| 项目 | 内容 |
|------|------|
| 信仰 | 天空泰坦艾格勒 |
| 形态 | 空中要塞 |
| 部族 | 烈阳（分晖之民）、雷雨（雨之民）、霜雪（冬之民） |
| 代表 | 风堇（雅辛忒丝） |
| 首次登场 | 3.3 版本 |

## 天空要塞

晨昏之眼建在艾格勒的神体之上。

天空泰坦的眼睛被刺盲后，昼夜循环失灵，许多城邦陷入永夜。晨昏之眼成了少数还能看见日出的地方。

## 三族

天空眷属分三支：烈阳、雷雨、霜雪。

三族都认为自己才是艾格勒最宠爱的孩子，于是把大部分时间花在争宠上，剩下的时间花在打仗上。

## 风堇

风堇出身天空之民，却留在地面行医。

3.3 中，她在这里接过天空火种，成为半神。她没有留在云端，而是回到地面，继续给人看病。

## 结局

4602 年，风堇的思维模块嵌入晨昏之眼。

晨昏之眼最后看见的，是一个没有人类的翁法罗斯。
