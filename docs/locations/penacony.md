# 匹诺康尼

> 家族经营的梦境之城。整座城市建在「忆质」之上，宾客买票入梦，在梦里消费、享乐、遗忘。

## 基本信息

| 项目 | 内容 |
|------|------|
| 所属星系 | 阿斯德纳星系 |
| 管辖势力 | 家族（五大家系共治） |
| 产权归属 | 星际和平公司（家族仅有经营权） |
| 主要入口 | 白日梦酒店 |
| 首次开放 | 2.0 版本 |

## 地理与环境

匹诺康尼没有传统意义上的「地表」。它的主体是一片由忆质构成的梦境空间，物理规则由「梦」的逻辑决定：距离可以被情绪压缩，时间可以循环，死去的人在特定条件下还能再出现一次。

整座城市靠「入梦」运转。宾客在现实中的白日梦酒店办理入住，通过入梦池进入梦境，醒来时回到酒店房间。这个设计既是商业模式，也是一种隔离——现实的身体留在酒店，梦里的经历则由家族负责「保管」。

城市分为若干「梦境」，每个梦境有独立主题与规则。已知区域包括：

- **白日梦酒店**：现实与梦境的交界，也是家族接待宾客的门面。
- **黄金的时刻**：最繁华的商业梦境，霓虹、赌场与剧院集中于此。
- **朝露公馆**：家族的核心驻地之一，处理政务与仪式。
- **筑梦边境**：梦境结构的边缘地带，规则不稳定，也是许多秘密藏身的地方。

## 历史

匹诺康尼的前身并不光彩。它曾是星际和平公司用来流放犯人的边缘星球，条件恶劣，几乎不具备长期居住的价值。

转折点在家族接手之后。家族发现这颗星球的忆质储量异常丰富，于是把它改造成梦境度假地——用「梦」把一片荒地变成了全银河最赚钱的旅游目的地。产权仍在公司手里，家族只有经营权，这个别扭的安排是双方长期摩擦的根源。

真正把匹诺康尼建成今天这个样子的人，被称作「钟表匠」。他是一个传奇的梦境建造者，也是家族历史上的关键人物；他留下的遗产，是匹诺康尼这座城市最深的一层结构。

2.0 版本的主线——匹诺康尼危机——就发生在这座城市。家族借「谐乐大典」之名，试图把整座梦境之城推向一个不再醒来的结局；星穹列车、公司、星核猎手三方在此交汇。砂金作为公司代表登上匹诺康尼，是这场博弈里最关键的赌徒之一。

## 社会结构

- **家族**：实际管理者，由五大家系共治，橡木家系是其中最有影响力的一支。
- **宾客**：来消费的游客，也是这座城市的经济来源。
- **梦境居民**：在梦中生活、工作、甚至出生的人。他们的身份认定是匹诺康尼最敏感的议题之一——一个在梦里活了很久的人，算不算「真实存在」。
- **公司代表**：产权方派驻的人员，与家族长期博弈。
