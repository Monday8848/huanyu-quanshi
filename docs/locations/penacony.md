# 匹诺康尼

> 「盛会之星，匹诺康尼」——全银河最豪华的度假胜地，一座建在梦里的城市。

## 基本信息

| 项目 | 内容 |
|------|------|
| 所属星系 | 阿斯德纳星系 |
| 信仰命途 | 同谐（希佩），橡木家系暗中信奉秩序 |
| 管辖势力 | [家族](/factions/family)（梦主统领，五大家系分管） |
| 产权归属 | 星际和平公司 |
| 现实主体 | 白日梦酒店 |
| 货币 | 梦境货币（与实体货币在酒店大堂兑换） |

## 城市本质

匹诺康尼没有传统意义上的「地表」。它的主体是一片由[忆质](/concepts/memory-substance)构成的梦境空间，物理规则由「梦」的逻辑决定：距离可以被情绪压缩，时间可以循环，物件可以拥有自我。

整座城市靠「入梦」运转。宾客在现实中的白日梦酒店办理入住，躺在客房中央贝壳形的「入梦池」中闭眼放松，意识沉入黑暗，在轻柔的话语引导下描绘幸福的美梦——待到十二下钟声响起，便会在梦之世界中醒来。醒来时视野中会出现梦境特有的光景：漂浮的家具、餐具，以及可以吹出各种体验的「梦泡」。

这个设计既是商业模式，也是一种隔离——现实的身体留在酒店，梦里的经历则由家族负责「保管」。

## 十二时刻

梦境按时间顺序划分为十二个「时刻」，每个时刻有独立的主题与标志建筑：

| 时刻 | 主题 | 标志建筑 |
|------|------|----------|
| 子夜的时刻 | 梦的起点，沉寂、黑暗 | — |
| 安谧的时刻 | 不对外开放，接近噩梦边缘 | 监狱 |
| 朝露的时刻 | 最寂静、安全、隐蔽 | 朝露公馆 |
| 黎明的时刻 | — | 地底管道、早霞工厂 |
| 烫金的时刻 | 森严的金融之城 | — |
| 太阳的时刻 | 学识 | 匹诺康尼大博物馆、初醒图书馆、折纸大学 |
| 绿洲的时刻 | 午后，安恬的自然风光 | 日光公园 |
| 热砂的时刻 | 选秀节目「苏乐达™热砂海选」 | 热砂海选会场 |
| 蓝调的时刻 | 黄昏，晚霞与浪漫 | 黄昏号 |
| 薄暮的时刻 | 时尚、奢侈与消费主义 | 拍卖会 |
| 星辰的时刻 | 游乐 | 机动球赛场、游乐场 |
| 黄金的时刻 | 午夜零点前，最繁华的商业区 | 艾迪恩公园、奥帝购物中心 |

梦境深处还有不属于十二时刻的地方：**筑梦边境**（仍在建设中的梦境边缘，规则不稳定）、**稚子的梦**（钟表匠的记忆异化成的梦境迷域，被用作米沙的家，如今溪涧失去流向、时针停止转动）、**流梦礁**（原初忆域的一隅，收留着不为美梦所容的清醒者）、**稚子的月光**（拉扎莉娜和铁尔南的衣冠冢及钟表匠长眠处）。

## 组织架构

在梦主的统领下，五大家系分管不同事务：

| 家系 | 职能 | 特点 |
|------|------|------|
| 橡木家系 | 政治管理，五大家系中的指挥者 | 十万七千三百三十六名成员，实为「秩序」信徒 |
| 猎犬家系 | 安保，维护匹诺康尼的安全与秩序 | 家主唐•怀亚特 |
| 鸢尾花家系 | 文化，娱乐产业的缔造者 | 家主梅芙恩•伊里斯，管理美梦剧团 |
| 苜蓿草家系 | 经济，匹诺康尼财富的管理者 | 家主奥帝•艾弗法 |
| 隐夜鸫家系 | 建设，聘请全宇宙的建筑师与学者 | 折纸筑梦师乔伊、冯恩、巴罗、费歇尔、奥尔拉 |

**梦主歌斐木**是家族的领导者，也是上一任橡木家主。应钟表匠的请求，他带领家族来到这片即将毁灭的流放之地；五大家系先后皈依后，匹诺康尼才得以拥抱它的新名——「梦想之地」。他用[星核](/items/star-core)将阿斯德纳的中央监狱改造成匹诺康尼大剧院，并依靠星核的力量夺取了钟表匠一派的胜利果实。

融入梦境时，歌斐木将自身化为四条「太初律令」：

- **律令•其一**（11:15）：「神明赐予我们天火，也赐予我们神圣的磨难……你我皆属凡人，生来便要去爱，去受痛苦。」——作为临别赠礼施予[知更鸟](/characters/robin)，点拨她走上「同谐」。
- **律令•其二**（11:30）：「改邪归正。你虽如大鹰高飞，在星宿之间搭窝，但我必从那里拉下你来。」——分予合作者[大丽花](/characters/the-dahlia)的力量，同时作为禁制。
- **律令•其三**（11:45）：「乐园终将跌入愁苦人世，黎明一旦升起，便要坠毁于白昼。凡是金的，怎可能光华长留？」——倾其所有的一击。
- **律令•其四**（00:00）：「因众星属于所有人，也便从未属于任何人。若你爱着所有人，便是不爱任何人。」

## 白日梦酒店

[白日梦酒店](/locations/dreamjolt-hotel)是匹诺康尼在现实中的主体建筑，也是梦境中的地标、现实与梦境的连接点。酒店内根据朝向与楼层分为 **48 个扇形区域**，各区域均有自己的中央大堂。数字为 10～12 的扇区是被称为「铂金套房」的高级区域；开拓任务中列车组所住的即「红心十二区」。

中央大堂负责办理入住退房、现实货币与梦境货币的换算。梦境大堂中有巨型泡状鲸鱼悠然游动——这些游鱼来自钟表匠的点子。大堂里巨大的时钟实际是扇区标识，第四根指针从不转动，始终指向扇区编号所在的刻度；表盘上的匹诺康尼文字对应英文「stay asleep（一直睡着）」与「never awake（不要醒来）」。

## 信仰与制度

匹诺康尼信仰[希佩](/concepts/aeon-xype)，家族成员以「复归音阶」区分修行层级：

- **第Ⅶ音级**：「情绪的同谐」，能感受到其他家人的情绪和集群之声的模糊指引。
- **第Ⅵ音级**：「言语的同谐」，能通过「共鸣」传递信息、清晰理解集群之声；此后可自愿放弃肉身，与集群之声融为一体。
- **第Ⅳ音级以上**：方能担任「谐乐众弦」的调弦师。
- **第Ⅴ音级**：知更鸟据信属于该音级。

橡木家系十万七千三百三十六名成员实际上以「秩序」为信仰，自歌斐木接手匹诺康尼开始于暗中发展。橡木家系过去扬言「保护宾客绝对周全」，依靠的其实是[太一](/concepts/aeon-ena)的力量——希佩虽然吸收了太一的命途，但「秩序」的力量也在谐乐中留下了杂音。开拓任务「在我们的时代里」中，时任橡木家主[星期日](/characters/sunday)于谐乐大典上召唤出「谐乐众弦」之一「齐响诗班」众愿之多米尼克斯，因「秩序」力量的干扰而展现出不同以往的面貌。橡木家系计划破灭后，现在的美梦里，「死亡」已并非不可能之事；猎犬家系仍在追捕橡木家系成员。

## 美梦剧团

梦境中许多物品、设施受到忆质影响而拥有自我意识，被家族驯化后成为服务宾客的「美梦剧团」。它们由筑梦师创造、鸢尾花家系管理。并非所有道具都能入选——只有最惹人喜爱的物件才会被家族改造；也有摆脱家族控制的「自由物件」。

情绪能决定剧团成员的本性：它们的生命附属于梦境，不会生病或衰老，却会因情绪转变而发生根本变化。当它们受到危险的情绪或记忆影响，就会变成形如怪物的「惊梦剧团」——尽管依然忠实扮演着原本的角色，但对普通人而言，它们的「演出」已与破坏无异。

## 人种

- **天环族**：拥有动人心魄的嗓音与容貌，华美的光环与耳羽点缀出圣洁之姿，生来受万物瞩目。天环族天生精于心计，头顶天环的光频能传递心声、实现心灵感应。匹诺康尼的所有天环族都是「家族」的一员，多在橡木、鸢尾花两家担当重任。
- **皮皮西人**：聪慧的族裔，热爱知识与财富，娇小身躯里蕴含无限勤奋。如今的匹诺康尼中，皮皮西人忙碌在苜蓿草家系的经济活动与隐夜鸫家系的建设工作中。
- **智械**：发源于「无机生命地带」的种群，身体由机械构成、思维由程序运转。他们通过特殊技术手段也能接入梦境世界——这或许印证了「无机生命与有机生命有着同样的灵魂」。

## 经济与社会

- **苏乐达公司**：匹诺康尼的龙头企业，迄今已为来宾服务了近 5 个琥珀纪，创始人及工厂厂长为十大富豪之一的艾迪恩•列达。总部是能喷射苏乐达的巨型汽水瓶地标；其管道与城市下水道及供水系统相连——城市里的水全都是糖浆饮料。
- **奥帝购物中心**：全匹诺康尼最大的集合式商场，所有店面提供免费寄送服务，实体商品可经银河快递网络寄往宇宙各处。
- **折纸大学**：由格拉克斯建立，最早是筑梦师的培训基地，后来成为闻名银河的艺术学府；鸢尾花、苜蓿草家系参与管理后另设谐乐学院与财富学院。
- **「皇帝」**：蒂索克二世，「黄金的时刻」的「皇帝」。冒险任务「好人难寻」完成后，蒂索克三世践祚，接手二世最伟大的政治遗产——善意。
- **筑梦师**：家族为建设梦之都市雇用的技术人员，艺术家、建筑家、心理学家齐聚于此，个性强烈、彼此难称和睦，家族以严密的监管和油滑的交涉保证工程进行。

## 相关事件

2.0–2.2 的主线「[匹诺康尼危机](/events/penacony-crisis)」发生在梦境之城：家族借「谐乐大典」之名，试图把整座梦境推向「齐响诗班」的结局；星穹列车、公司、星核猎手三方在此交汇。[砂金](/characters/aventurine)作为公司代表登上匹诺康尼，是这场博弈里最关键的赌徒之一。

3.8 的主线「[橡木鸣蛀之梦](/events/oak-borer-dream)」回到匹诺康尼：歌斐木把自己的意识杀死、化成四条律令，企图在梦中再造寰宇蝗灾、让太一复生。[流萤](/characters/firefly)、[黑天鹅](/characters/black-swan)、[大丽花](/characters/the-dahlia)等人阻止了他。匹诺康尼的梦没有再次闭合，但代价是另一些记忆被烧掉。
