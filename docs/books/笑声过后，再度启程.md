# 笑声过后，再度启程

> 世界尽头，两位「已死」的星神并肩而立——「所以你打算怎么用激光来模拟列车投影？」「相信灯光部，相信伶人舞美…」

## 全文

> 获得方式：点星船糖果动力阀界域定锚，直走旋转马车中央拾取。

*伶人们接龙创作的舞台剧本，以不同的视角描绘了钓猎贪饕之战的某个侧面。在公演结束后，票房最少的作者将负责未来一年内剧团长的追捕和催稿工作。*

旁白：在钓猎贪饕一役的终幕，众谒者各显神通。然「欢愉」知晓，仅凭力量无法诱那诸界渴饮者上钩——须得献上史无前例的奇观：一场死而复生的奇迹。
旁白：为此，于幕中罅隙，祂化作流光，飞向世界尽头之外。

【幕启：舞台投影光束，模拟星空。阿哈独自站在舞台上】
「欢愉」阿哈（抚掌笑）：没了列车的鸣笛，少了旅人的足迹。
                                         啊，多么寂寥的宇宙！
                                         该去更远的地方，请回一位旧友——
                                         比世界的尽头更远，在那枝杈缠绕的起源。
                                         
【灯暗，阿哈走向升起的树木道具】
「欢愉」阿哈：打盹的旅人，该醒醒了！
                        你的星图落了灰，你的列车断两截。
                        观众却都在等待一场奇谋！
                        来吧，与我再度同台，演一出戏：
                        让那头恶兽，吞下它最后的钓钩。
            
【阿基维利上】
「开拓」阿基维利（睁眼）：我听见了。
                                            有人在世界之外呼唤我的名字。
                                            浩瀚无垠的宇宙，从不缺少无名客的脚步。
                                            但能让你亲自来请的——大约也只有我了。

「欢愉」阿哈：对，这才是你该有的神情！
                       愚钝的观众——敬请瞩目，敬请期待。
                       此刻，两位「已死」的星神并肩而立。

「开拓」阿基维利：是残响，还是早已熄灭的余烬？

「欢愉」阿哈（大笑）：是让吞噬者自身，成为被开拓的荒原！

【灯亮起，激光模拟列车穿透巨兽投影。两人立于舞台中央，向观众鞠躬】
「开拓」阿基维利：来吧，让我们再次起舞。

「欢愉」阿哈&「开拓」阿基维利：一切在笑声中终结。
                                                     也将在笑声中开启！

【幕落】
