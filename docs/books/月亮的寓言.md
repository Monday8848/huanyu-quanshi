# 月亮的寓言

> 与贡多拉船尾的月亮，有关的一些小故事。

## 全文

> 获得方式：点星船糖果动力阀界域定锚，左转绕旋转木马逆时针走，在圣诞树立牌下拾取。

月亮升上了船尾，像一柄磨秃的石镰。
剧团长顾影自怜，于是对它说：
「你这劳碌的老家伙啊，还割得动天上的麦子吗？」
「倒不如来为我做个领航员，只消在倒船的时候帮忙看看后面。」
残月的辉光就这样被她请来，
从此守望着伶人的航线。
 
月亮来到了人间，硬梆梆地像一块干酪。
星海没有潮湿的风，宁静的真空让它大气也不敢出。
「真奇怪，」剧团长挠了挠脑袋，
「跟着太阳做体力活的时候，你不也是在真空中流浪、漫游？」
「为什么更轻松的活计，反倒让你更不自在？」
 
「说我跟着太阳做体力活，那未免是你的一己之见。」
「当在你眼里，我被行星牵引着绕着恒星运动的时候——」
「从大地上仰望，我同样是自由的天体。」
「我在银河的麦浪间漫无目的地巡游，把那些捣蛋乱跑的流星，」
「抓回到由浪漫灌溉的故土。」
「——我曾经如此定义自己的工作。如今我垂垂老矣，」
「但做个殿后的领航员究竟意味什么，」
「我仍要自己慢慢决定。」
 
月亮没有自己的曙光，
孤独的老国王，在舞台后呢喃低语。
花船开过了一道道山坡，留下花朵，带走珍珠。
「总有一天，我会决定：自己是个过客，还是马戏团的一员。」
它也许给出了回答，也许没有；无论如何……
死去的星辉依然生气勃勃。
