# 二度枯荣

> 于无天无地之底，绯英一度迷失，又一度苏醒。正如树的枝叶，枯了又长。

## 全文

> 获得方式：点星船甲板钓台界域定锚，在小地图左下区域的茶几上拾取。

*伶人们接龙创作的舞台剧本，以不同的视角描绘了钓猎贪饕之战的某个侧面。在公演结束后，票房最少的作者将负责未来一年内剧团长的追捕和催稿工作。*

旁白：在钓猎贪饕一役中，神木绯英跃入兽口，打算以此唤取长生主的垂眸，将凶兽的血肉变成养料。
绯英（画外音）：来吧，你这恶兽——该吃点素菜清清口了！
旁白：然而，即使是永劫不坏之躯，也无法抵御诸界渴饮者体内的森罗幻象。

【幕启：绯英靠在落英缤纷的神树下，四周一片黑暗。】
绯英：（睁眼）这里是……

【贪饕上。】
贪饕：好一棵大胆、妖艳的建木，
          竟敢闯入蜜与乳的国度，
          难道你不知这洞天有进无出？
          你将被饥渴缠身，永无饱足，
          正如再繁茂的树也总要衰枯。

绯英：是啊，我好饿……

【灯亮起，舞台上布满巨大的蛋糕，一齐招手。】
众蛋糕：来吧，来吧，受诅的孽物，
              快撕开我们残缺的肌肤。
              这里的欢宴永不落幕，
              且尽情吞咽蜜糖与果脯。

绯英：总感觉忘了什么事…不重要了。

【蛋糕下。绯英不断吃食，背景中的神树也逐渐凋落。】
贪饕（笑）：纵使自诩永恒的神树，
                    也难抵名为欲望的鸩毒。
                    欢笑吧，沉沦吧，
                    直到血肉变成枯骨。

*（批注：毕竟树没吃过蛋糕，饶了孩子吧。）*

【熄灯，以等离子束模仿光矢从舞台上划过。棚顶砸出一个大洞，有光从洞口射出。】
贪饕（惊）：哪来的光？

旁白：千钧一发之际，光矢跨越时空，洞穿了兽的身躯。

绯英：是那支未落的箭吗？唤回了我的神智。
          我并非迷途的旅人，而是魔术的主演。
          长生主啊，我于死境中呼唤——
          请你垂眸，用根系刺穿贪婪。
          愿以周遭的血肉为壤，化作你的温床。
          正如树的枝叶，枯了又长。

【贪饕下，背景中的神树重新开始茂盛。】

【幕落。】
