# 声声慢•后室

## 全文

> 获得方式：来到指针塔后室，直走到底、右转直走到底、右转进入另一个房间，经过迷宫来到中央丰厚战利品旁，地上躺着的人身上拾取。后室需要通过 3 层右上角环形办公室界域定锚，右边墙边「二次元JUMP！」进入。

余自穷荒远邑，孑然至千星之城，而役于指针高塔。

始意食力自存而已，孰料命途多舛，入后室，遂为所闭。

其地廊复壁重，灯昏门杂，四顾悄然，若无出路，方惶急四觅生路。

忽有影，曳灯至，谛视之，盖总角故交也。

彼执余手而叹曰：「此地诚太初僻静之所，人皆欲趋去，不知外道流离，反受其咎。奔走穷廊，不如相守。」

余闻其言，若启蔽塞，怳然有悟，乃填《声声慢》一阕。

词曰：

廊廊复复，壁壁森森，墙墙灯灯门门。
昏黄四顾无处，困此孑身。
一桌数椅倒砌，怎得脱、忧惧如焚！
忽有影，看来人，却是旧时相识。

闻说千星安乐，方来此，遍历苦辛。
成塔下鬼，流水线上人。
归去更具苦楚，应无路、何必驰奔？
随君驻，方寸幽隅远羁尘。
