# 饮月大逆判牍

> 对「饮月之乱」主犯的一道判决。这道判决对仙舟的未来产生了巨大的影响。

## 全文

> 获得方式：由丹鼎司进入祈龙坛，左侧石碑拾取

**罪人丹枫，拥贼犯禁，**

**贪取不死，造作兵祸，**

**人神同嫉，天地不容，**

**理当大辟（编者注：大辟：隋朝以前死刑的叫法），以定欃枪（编者注：欃（缠）枪：古代彗星的别称，因古人认为彗星表示凶恶，所以用来比喻邪恶势力。）。**

**今，**

**念其旧功，免于大辟，**

**蜕鳞轮回，往罪不咎，**

**流徙化外，万世不返，**

**凡所治处，不得履踏。**
