# 神性的回响：海洋

> 泰坦神迹所留的追忆，受赐福者才能闻得此等神圣的残音…听，那杯中的蜜酿如巨浪般袭来。

## 全文

> 获得方式：「永恒圣城」奥赫玛云石天宫满溢主池界域定锚，入口处看台上。

满溢之杯，法吉娜。
蜜酿入汪洋，激浪如花开。
在波涛与醉客的喧嚣里，
万物在疯狂中清醒。
