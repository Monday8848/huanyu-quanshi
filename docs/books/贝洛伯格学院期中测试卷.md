> 获得方式：行政区克里珀堡左侧阶梯下长椅拾取

班级_二_年级_六_姓名_卢森_成绩_35_

一、填空题
1.为了不损坏城市里的地髓灯，在使用时要注意防止_大脑_短路。
2.像岩盐与黄渍糖等的颗粒都是几何外形的固体，人们把这样的物质叫做_吃的_。
*卡佳：老师教你填空题不要放空白不是让你做脑筋急转弯的！*
3.我们可以根据贝洛伯格学院教学楼的_大小_和距离来确定其在城市中的位置。
4.锈是金属与空气中的氧气发生了_爱的_反应后产生的。
5.霜纹鲑，在水温下降时会游到温度适宜的场所去越冬，这种过冬方式叫做_旅行_。

二、选择题
6.观察一株盗香醚草时，正确的顺序是（ C ）。
A. 从外到内 B. 从内到外 C. 从上到下 D. 从下到上
7．夕红果的形成需要经过的过程是（ C ）。
A. 开花→传粉→结果 B. 开花→结果→传粉 C. 传粉→开花→结果
8.洞螈的脚趾端具有吸附的作用，有利于在洞穴中爬行的部分叫做（ C ）。
A. 吸盘 B. 爪勾 C. 肉垫 D. 横褶
*卡佳：不是猫猫！*
9.葬礼虫成虫的口器属（ C ），葬礼虫幼虫的口器属（ C ）。
A. 针吸式 B. 舐吸式 C. 咀嚼式 D. 虹吸式
*卡佳：卢森同学！老师教过你实在不会的选C，你有用心听，这值得鼓励。*
*但是能不能仔细看看题干！*
10.下列物体中，能溶解于水的是（ C ）。
A. 地髓 B. 岩盐 C. 果酱 D. 蜂蜜

三、判断题
11.手扶在城墙上比扶在树木上感觉冷，是因为城墙的温度比树木的温度低。 （对）
12.中世代的三齿兽因为不能适应气温骤降和食物减少等环境变化而绝种了。 （对）
13.地髓是远古时代生物的遗体在地层中经过几亿年的变化逐渐形成的矿物。 （对）
14.在地髓旁取暖，人会感到发热，这是由热传导引起的。 （对）
15.穴居疯地鼠进食时，多用尖牙切、切牙撕、磨牙磨碎食物。 （对） 
16.将蜜饯菇与安神菇拦腰切断的解剖方法是纵切。 （对）
17.七彩虹叶片的蒸腾作用能降低其叶面的温度，保护植株不受高温损伤。 （对）
18.在原野上，我们看到树桩上的年轮，可以识别出年轮宽的一面为北方。 （对）
19.矿蚀藓可以利用化学作用产生的微光在没有光的洞穴里生存下来。 （对）
20.通过眼观、手摸、刀刻、滴液等手段可以辨认出矿物的种类。 （对）
21.利用杠杆原理不仅可以省力，还可以改变用力方向。 （对）
22.既能生活在水中，又能生活在陆地上的动物，叫做两栖动物。 （对）
*卡佳：就算不是真心的，你好歹写上些错误的判断让我知道你有思考，安慰安慰老师好吗?*
