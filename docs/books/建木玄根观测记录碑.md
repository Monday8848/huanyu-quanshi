# 建木玄根观测记录碑

> 罗浮持明受命不懈守望古老的建木残迹，观察其再生之势。

## 全文

> 获得方式：鳞渊境毁灭之蕾•拟造花萼(赤)视角向右直走到遗迹处左前方有个柱子处拾取。

此石碑立于星历8000年，置于波月古海之底，供护珠人水下记录建木玄根变化之用，未经许可严禁擅动。

海月一队队员寒杏记录：12号、18号、24号枝杈生长0.5寸。

海月二队队员俊俊记录：17号枝杈生长1寸，22号枝杈生长0.5寸。

海月一队队员舒益记录：1号、9号、13号、21号、35号枝杈生长1寸，4号、8号、17号枝杈生长7寸。建木玄根状态异常，已上报。

海月一队队长贺天记录：遵龙师韶英大人之令，暂缓一轮戍守工作，采撷样本核验建木状态。

海月一队队长贺天记录：已检验此前汇报的「建木状态异常」情况，应是建木正常的生长浮动。毋须过度担心。
