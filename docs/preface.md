# 编者说明

## 为什么会有这本书

《崩坏：星穹铁道》的设定有一个特点：**它散**。

一段关键历史可能藏在某个遗器的描述里，一位星神的动机可能只出现在某本书的三行字中，一次战争的因果则要拼三条支线的对话才能还原。玩家想通读一遍世界观，往往要在 Wiki、视频、论坛帖之间来回跳，跳着跳着就忘了自己在找什么。

这本书想做的事很简单：**把它编成一条能从头读到尾的线**。

## 三条编写原则

### 一、事实与推测分开摆

游戏里明说过的、多个文本互证的，当作事实写；社区推出来的，当作共识写；编者自己想的，放进每章末尾的「推测区」，并尽量说明推理链。

推测区不保证正确。它的价值在于**给读者一个可以反驳的靶子**——你不同意，说明你想得比我们深。

### 二、不逐条标出处

本书采用观点融合的写法：把多个来源的说法揉成一段通顺的叙述，不逐句加脚注。

代价是**不可逐字复核**，这一点我们认。如果你的用途需要精确引用（比如写论文、做视频逐帧考据），请回到游戏原文与 Wiki 核对；本书适合的是"先建立整体印象"这个场景。

### 三、按势力讲，不按星球讲

列车经过的星球是舞台，真正推动剧情的是势力。所以本书以**阵营**为一级单元，跨星球聚合：公司的足迹从庇尔波因特铺到匹诺康尼，仙舟的航线从罗浮伸向方舟墓地，家族的手伸进每一场梦——按星球切，这些线索会被切碎。

每个阵营单元固定五段：

1. **速览**：一句话定位、活动区域、核心人物
2. **起源与历史**：这个势力怎么来的
3. **组织架构与关键人物**：它怎么运转，谁在关键位置
4. **关系网**：与谁敌对、与谁合作、与谁暧昧
5. **未解之谜与推测**：社区在争什么，编者怎么想

## 关于附录卷

附录卷收录社区流传但**未经官方证实**的内容：拆包信息、匿名爆料、传播较广的假说。

把它们单独成卷，是为了两件事：一是让读者清楚知道"这些不是正史"；二是避免它们污染正文的可信度。**请勿把附录卷内容当作剧透依据或事实引用。**

## 更新节奏

跟随游戏大版本（约六周一次）做增量，小活动不追。每次大版本后优先更新：大事年表 → 受影响最大的阵营单元 → 术语表新增词条。
