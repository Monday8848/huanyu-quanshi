# 家族

> 「普世同谐，群星共熠，无上功德颂神主！世人同袍，万物同根，赐福之风拂大地！」
>
> ——《谐乐颂》第一乐章

| 项目 | 内容 |
|------|------|
| 命途 | 同谐 |
| 星神 | 希佩 |
| 性质 | 获得希佩赐福的世界及其选民 |
| 核心据点 | 匹诺康尼（阿斯德纳星系「盛会之星」） |
| 治理结构 | 五大家系共治 |
| 宗旨 | 相信宇宙终将成为「同谐」的整体 |

## 同谐愿景

在「同谐」的愿景中，宇宙中缤纷多彩的文明终将亲如手足，齐声合唱团结与欢愉的颂歌。

届时，宇宙将成为和谐的整体，再不会有逆耳的杂音戳破美妙的和弦，更不会有愚者为短浅的未来忧虑。

## 家族是什么

在星神希佩慈爱的光辉照耀下，祂的选民们组成了温馨共谐的「家族」。

他们来自不同的世界，属于不同的文明，持有不同的身份，但却是亲密无间的家人。家人之间没有喧扰的争执或矛盾，只有永恒的关爱与欢颜——官方对这套关系的定性是：「宇宙间再无比他们更为和睦的家庭。」

「家族」在歌声中呼唤其他世界，鼓励它们投入「同谐」的怀抱。每有新世界接受希佩的赐福，「家族」便欢欣鼓舞，更为卖力地歌咏星神的良善。

## 没有杂音

官方智库在这段叙述后留下了一句极为关键的话：

> 但并非每个受福的世界都能顺利地成为「家族」的成员——鲜有人提及那些因愚钝或傲慢而消亡的文明。

紧接着是一个提问：可曾有家族的成员厌倦了歌唱，主动放弃了追寻「同谐」的命途？

「家族」微笑作答：**从无此事**。

「鲜有人提及」与「从无此事」，就是这套温馨叙事的两处裂缝。

## 五大家系

匹诺康尼的家系共五支，各有分工。

| 家系 | 家主 | 职责 |
|------|------|------|
| 橡木家系 | 星期日 → 知更鸟 | 政治管理，五大家系中的指挥者 |
| 猎犬家系 | — | 安保，维护匹诺康尼的安全与秩序 |
| 鸢尾花家系 | 梅芙恩·伊里斯 | 文化，匹诺康尼娱乐产业的缔造者 |
| 苜蓿草家系 | 奥帝·艾弗法 | 经济，匹诺康尼财富的管理者 |
| 隐夜鸫家系 | 惠特克爵士 | 建设，聘请宇宙各地的建筑师与学者一同建造梦境 |

橡木家系的指挥权在 2.x 之后由星期日交到知更鸟手上。

## 匹诺康尼

家族在匹诺康尼的地位很特殊：它是**经营者**，不是所有者。

这座城市的产权在星际和平公司手里，家族只有经营权。这层关系决定了家族的一切动作都带着一种焦虑：它需要证明自己配得上这座城，也需要找到一种办法，让这座城真正属于自己。

2.0 的「谐乐大典」是这份焦虑的顶点。家族广邀银河宾客，盛会之下，是「秩序」与「同谐」两条命途的角力，「太一之梦」把整座城市写进了一场不愿醒来的梦。

结局是「秩序」崩解，哲学的胎儿自高台坠落，知更鸟从空中接住星期日：「哥哥，梦，该醒了。」

## 比亚里-斯卡曼德洛斯

除匹诺康尼之外，「同谐」影响下的地上天国还有一处：**比亚里-斯卡曼德洛斯星**，大小达耳达努星系居民们趋之若鹜的人间天堂。
