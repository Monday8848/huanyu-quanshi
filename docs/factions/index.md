# 势力

按影响力排序，越靠前，剧情中的分量越重。每个条目包含：一句话定义、基本信息、起源与历史、组织架构、与其他势力的关系、相关推测。

## 已收录

1. **[星际和平公司](./ipc)** · 存护 —— 银河最大的经济体，名义上为琥珀王筑墙，实际握着大半个宇宙的账本。

## 建设中

首批清单里还有 **仙舟联盟、家族、星核猎手、星穹列车**。再往后是博识学会、天才俱乐部、反物质军团、巡海游侠、泯灭帮、流光忆庭、纯美骑士团、黄金裔。

## 关于「势力」的界定

游戏里的组织分三种：有明确命途归属的（公司、仙舟）、跨命途的（星核猎手）、以及由个体组成的松散团体（天才俱乐部）。本类只收有正式名称、且在剧情中实际出场的组织；单人势力（如某位星神的独立令使）归入「人物」。
