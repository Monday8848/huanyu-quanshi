# 太卜司

> 视兆问玄，极数知来。

## 基本信息

| 项目 | 内容 |
|------|------|
| 隶属 | [仙舟联盟](/factions/xianzhou-alliance) |

| 技术核心 | 「玉兆」晶石计算机技术 |

## 职能

太卜司使用名为「玉兆」的晶石计算机技术，负责占卜未来、信息处理和保存、航路推演、策略运筹等工作。卜者的一大职责，是守望帝弓的神矢诰谕、判读其意义。

## 职衔

| 职衔 | 职能 |
|------|------|
| 韬略士 | 进行政略、军略演算的谋士 |
| 卜者 | 精于推算未来算法的智士 |
| 书记 | 信息收集分类的记录者 |
| 司书 | 信息分类处理、管理档案库 |

## 玉阙与罗浮

玉阙太卜司自博识尊处求取演算经籍，倾数百年全力营建了联盟中夸称第一的占卜阵法。罗浮太卜司之首是符玄——她与玉阙阵法理念的争执，见[符玄](/characters/fu-xuan)条目。
