# 混沌医师

> 「我们不医治肉体，也不解放灵魂；不贪恋生，也不避讳死。我们尊崇『存在』本身。」
>
> ——混沌医师慕榕

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 虚无命途上的自救者结社 |
| 命途 | 虚无 |
| 信奉对象 | Ⅸ（并不敬拜，而是想反驳祂） |
| 核心命题 | 向Ⅸ证明「存在并非虚无」 |
| 行为 | 医治他人的虚无、记录自灭现象 |
| 代表成员 | 慕榕 |
| 关联派系 | 自灭者、第Ⅸ机关 |

## 由来

「存在是虚无的。」——当某个存在无意中产生这样的思想并引之为箴，就会踏上由Ⅸ执掌的命途，接受来自遥远虚空某处、来自星神的一次无意义瞥视。

这一瞥通常带来两种结局。

一者自此颓唐，真正成为虚无的存在，被称为**自灭者**；另一者被瑰丽的星神神性所倾倒，不约而同地产生一丝好奇——他们就是混沌医师。

## 信条

混沌医师秉持悬壶济世的信条：如果能向Ⅸ证明存在并非虚无，便能从未知的巨大黑潭中，将这个巨大而孤独的生灵解放出来。

这一心愿近似悖论，人力几不可成。但混沌医师甘之如饴——因为在察觉到生命无价值的那一瞬间，那从遥远星海投来的瞥视，令他们产生了对虚无命运的**徒劳反抗之心**。

他们医治的对象不是肉体。手记、问诊、陪伴、记录，是他们对抗「无意义」的全部器械。

## 观察与记录

混沌医师的手记是宇宙间最详细的自灭者病理档案。其中记载的症状包括：

| 症状 | 表现 |
|------|------|
| 躯体 | 皮肤变得像腐烂的枯木，布满伤痕和孔洞 |
| 内分泌 | 系统错乱，不分快乐与痛苦，对一切麻木 |
| 认知 | 逐渐失去记忆 |
| 感官 | 五感一项项熄灭 |
| 幻觉 | 反复梦见自己的身影消失在地平线尽头的黑洞里 |

这些现象难以用自然规律解释。混沌医师把它们归因于「存在属性被剥夺」，而非疾病。

## 一个猜想：焚风

一些混沌医师提出：绝灭大君**焚风**的「毁灭」或许是某种反抗。他极有可能是一位受Ⅸ感召的自灭者，面对星神投下的阴翳，选择将褪却的色彩磨砺成极致的白光。

他的破坏时而返照在「虚无」行者的梦中，并在他们惊醒的身躯上留下焦痛的灼伤。

## 与自灭者的关系

部分自灭者会萌生反抗之心，加入混沌医师，誓在有限的时光里尽力医治他人的虚无，以换取自我的救赎。

更极端者以强烈信念为支柱，试图从根源上断绝诅咒——通过杀死那位沉眠在深渊中的星神。
