# 黄金裔

> 击落众神，归还神火。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 神选英雄 |
| 首领 | 刻律德菈 → 阿格莱雅 |
| 标志 | 金色神血 |
| 使命 | 击落泰坦、回收火种、填补神职 |
| 活跃 | 3.0—3.7 版本 |

## 起源

刻法勒献出火种，留下神谕：十二位英雄将击落失神的泰坦、回收火种，拯救翁法罗斯。

拥有伟力的英雄流淌金色神血，被称为「黄金裔」。他们不是天生的神，是被神选中的容器。

## 成神之路

黄金裔通过「火种试炼」，分得泰坦力量，承载对应神权，攫升为「半神」。

十二位黄金裔对应十二泰坦：阿格莱雅对浪漫，缇宝对门径，万敌对纷争，遐蝶对死亡，那刻夏对理性，风堇对天空，赛飞儿对诡计，白厄对负世，海瑟音对海洋，刻律德菈对律法，长夜月对岁月，丹恒·腾荒对大地。

## 本质

黄金裔是以十二组因子为原型创造的电信号。

泰坦与黄金裔，是对星神与命途行者的共轭模拟：继承火种、竞争、迭代，让电信号不断升级。所谓「逐火」，也是一场演算。

## 结局

两次逐火之旅，几乎打光了所有黄金裔。

刻律德菈献祭五百人，阿格莱雅战死，万敌裂魂，风堇成为最后一个人类。

3.7 中，他们以「记忆」的形态重回战场。三千万世的逐火者与四亿枚火种凝聚于开拓者与昔涟之身，覆写铁墓「毁灭」的方程式，把它冲刷成「空白」。

黄金裔生来是「毁灭」的柴薪。最后，他们把自己烧成了另一种火。
