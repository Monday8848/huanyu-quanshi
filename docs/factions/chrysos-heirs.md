# 黄金裔

> 「击落众神，归还神火。」
>
> 「逐火，是不断失却的旅程。」

## 起源

刻法勒献出火种，留下「创世神谕」：十二位英雄将击落失神的泰坦、回收火种、拯救翁法罗斯。

神谕传出后，拥有伟力的英雄开始在大地上行走。他们流淌着金色的神血，被称为「黄金裔」。他们不是天生的神，是被神选中的容器——血是金的，因为里面装的是火。

## 逐火之旅的规则

黄金裔的成神之路分四步：**让泰坦陨落 → 获得火种 → 交火种开启试炼 → 接过神权**。

这套规则在剧情中被反复修订：

- 3.0 版本后期补充：并非每位泰坦都必须以暴力击败，泰坦主动交出火种也算数。
- 3.1 版本中期补充：火种可以与泰坦分离，获得火种不一定要泰坦陨落。
- 同一时期再补充：试炼与火种提交脱钩，拿到火种就可以开启试炼。

规则越修越宽，代价却越来越重。因为「逐火之旅只有一人能活到最后」——集齐十二枚火种，然后付之一炬，等待再世的重启。

## 两轮逐火

**第一轮（3.0—3.4）**：开拓者与丹恒降临翁法罗斯，协助黄金裔逐一回收火种。尼卡多利、欧洛尼斯、塞纳托斯、瑟希斯、艾格勒相继落幕；阿格莱雅、赛飞儿战死；白厄接过负世火种，在末章燃身刺向纳努克，化作「神厄」。

**第二轮（3.5—3.7）**：因白厄的牺牲，轮回出现漏洞，救世主身份由开拓者接手。刻律德菈在光历 3960 年献祭五百黄金裔、冻结来古士六成权限，为世界争出九百七十一年。阿格莱雅战至 4029 年，与奥赫玛九万民众同死；遐蝶化龙守通道；万敌裂魂；那刻夏化贤者之石；风堇守到最后一个普通人死去；海瑟音守通道至沉眠。

## 本质

黄金裔是以十二组因子为原型创造的电信号。

泰坦与黄金裔，是对星神与命途行者的共轭模拟：继承火种、竞争、迭代，让电信号不断升级。所谓「逐火」，也是一场演算——演算的目的是让「毁灭」的方程式完成自我迭代，最终催生出绝灭大君「铁墓」。

黄金裔生来是「毁灭」的柴薪。

## 结局

3.7 版本，他们以「记忆」的形态重回战场。三千万世的逐火者与四亿枚火种凝聚于开拓者与昔涟之身，覆写铁墓的「毁灭」方程式，把它冲刷成「空白」。

最后一刻，柴薪把自己烧成了另一种火。
