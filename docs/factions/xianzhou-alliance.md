# 仙舟联盟

> 六艘巨舰，一群活了太久的人，和一场打了数百年还没打完的战争。

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 巡猎 |
| 星神 | 岚（帝弓司命） |
| 政体 | 各仙舟自治，联盟层面协调军事与外交 |
| 已知仙舟 | 罗浮、朱明、曜青、方壶、玉阙等 |
| 军事力量 | 云骑军 |
| 主要敌人 | 丰饶民、反物质军团 |

## 从求长生到求复仇

仙舟人原本不是战士。他们向丰饶星神药师求取长生，得到了「丰饶」的赐福——然后发现长生是有代价的：人口失控、资源枯竭、社会结构被不死者压垮。

转折点是「巡猎」的出现。帝弓司命岚带着复仇的意志降临，仙舟人调转方向，把整支文明改造成一台战争机器。从此仙舟的信条变成两条：追杀丰饶民，以及不再向任何星神祈求长生。

这段历史解释了仙舟的矛盾：它是一个由不死者统治、却对「长生」充满警惕的社会。

## 结构与制度

- **六司**：各仙舟设六司分管政务，罗浮的丹鼎司掌医药，十王司掌刑狱与生死。
- **云骑军**：仙舟的常备军，也是对外作战的主力。入伍要宣誓，退役要有战功或年限。
- **持明族**：龙的后裔，拥有蜕鳞转生的能力，在仙舟社会中地位特殊。
- **化外民**：来自其他世界、获准在仙舟定居的外来者。数量不多，身份敏感。

## 罗浮

罗浮是联盟中对外开放程度最高的一艘，也是星穹列车实际停靠过的那一艘。

它的城市分层很清楚：长乐天是商贸与居住区，金人巷是市井，丹鼎司管医药，鳞渊境是持明族的聚居地，绥园则是更幽深、更少对外人开放的部分。这种分层不是建筑问题，而是仙舟社会结构的直接投影。

## 与丰饶民的战争

仙舟与丰饶民的战争持续了数百年，双方都付出了难以计算的代价。

丰饶民不是统一的政权，而是信奉药师、追求长生的诸多势力的统称。他们中的一部分已经彻底异化，变成只知道增殖的怪物；另一部分仍然保留着文明的外壳，却把仙舟视为必须清除的障碍。

这场战争没有前线，也没有终战协议——它更像是一种持续数百年的状态，偶尔停火，从不结束。
