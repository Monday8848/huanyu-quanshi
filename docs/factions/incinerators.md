# 焚化工

> 以焚烧记忆为业，把不愿留下的过去烧掉。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 忆者分支 |
| 手段 | 焚烧记忆 |
| 代表 | 大丽花（康士坦丝） |
| 活跃 | 3.8 版本 |

## 忆者中的异类

忆者保存记忆，焚化工焚烧记忆。

在他们看来，记忆不是遗产，是负担。被记住的东西会腐烂，会发臭，会变成活人走不出去的房间。

## 手段

焚化工能潜入他人的意识，把一段记忆点燃烧掉。

被烧掉的人不会立刻发现——缺口会被别的东西填上，直到某一天，他发现自己想不起某个重要的人。

## 大丽花

大丽花是焚化工中最难缠的一位。她替梦主办事，也替开拓者找回被焚毁的记忆。

她烧别人的记忆，也替别人保存记忆。这两件事在她身上并不矛盾：她只是想知道，记忆到底值不值得留下。

## 评价

焚化工不是恶人组织。

他们只是比大多数人更早承认：有些过去，留着会死人。
