# 假面愚者

> 他们没有目标，没有领袖，没有计划。这恰恰是最难对付的地方。

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 欢愉 |
| 星神 | 阿哈 |
| 结构 | 无组织、无领袖 |
| 行为准则 | 有趣即正义 |
| 代表成员 | 花火 |

## 不是一个组织

严格说，假面愚者不能算组织。他们没有章程、没有据点、没有上下级，成员之间甚至未必认识。

把他们联系在一起的只有一件事：追随欢愉星神阿哈，认为宇宙的本质是荒诞的，因此唯一值得做的事就是从中找乐子。

## 欢愉的逻辑

欢愉命途常被误解成「快乐」。实际更接近一种极端的虚无主义：如果一切终将归于虚无，那严肃就是最可笑的态度。

阿哈的信徒因此不相信任何宏大叙事。他们嘲讽权力、拆解仪式、在别人的正经事里插一脚。在他们看来，让一个自以为重要的人出丑，比拯救世界更有价值。

## 危险之处

假面愚者看起来人畜无害，实际极难防范。

你无法收买他们，因为他们不要钱；无法威胁他们，因为他们不怕死；无法预测他们，因为他们自己也不知道下一步要干什么。匹诺康尼危机中，花火一个人就让所有阵营头疼。

## 与「恶」的区别

假面愚者不以伤害为乐——至少他们自己这么认为。他们要的是「戏」，不是「痛苦」。

但这个界限在实际中很模糊。一场「玩笑」可能毁掉一个人的一生，而愚人只会觉得这是戏的一部分。这种无自觉的残忍，比有目的的恶更让人无所适从。

## 二相乐园

4.0 起，假面愚者在二相乐园的存在感急剧上升。火花以主播身份参赛，把模因病毒散进绘世学院；花火则以导游身份带开拓者进城。

「世界尽头」酒馆与二相乐园相连。酒馆前厅、极乐之星、黄金告解室、致命玩笑、大秘宝，构成愚者在乐园的据点。
