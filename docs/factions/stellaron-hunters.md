# 星核猎手

> 一支只有几个人的组织，却在整条银河的通缉名单上排在最前面。他们收集星核，从不解释为什么。

## 基本信息

| 项目 | 内容 |
|------|------|
| 首领 | 艾利欧 |
| 已知成员 | 卡芙卡、刃、银狼、流萤（萨姆） |
| 目标 | 收集星核 |
| 手段 | 精准、克制、必要时毫不留情 |
| 通缉等级 | 公司悬赏金额极高，实际抓捕成功率接近于零 |

## 他们到底在做什么

星核猎手的目标是星核。这一点官方说得很清楚，其他的都没说清楚。

星核是「万界之癌」，落到哪颗星球上，哪颗星球就离毁灭更近一步。星核猎手却在主动收集这些东西——如果只是为了破坏，他们没必要这么费劲；如果是为了拯救，他们又不解释给谁听。

已知的线索只有一条：艾利欧能看见「未来的剧本」，猎手的每一次行动都严格按剧本来。这意味着他们收集星核不是为了当下，而是为了某个尚未到来的节点。至于那个节点是什么，官方至今没有给出答案。

## 成员

- **艾利欧**：首领，从未正式登场。所有行动都出自他预见的未来。
- **卡芙卡**：把星核植入开拓者体内的人。擅长言灵，说话的方式比刀更危险。
- **刃**：不死之身，剑术极高，与仙舟罗浮有一段血债。
- **银狼**：天才黑客，能把现实当成程序来改写。
- **流萤**：萨姆的驾驶员，也是猎手内部最不像猎手的一个。

## 与列车的关系

星核猎手和星穹列车不是单纯的敌对关系。

卡芙卡亲手把星核放进开拓者体内，又在关键时刻提供情报；刃与丹恒的旧怨让双方多次兵戎相见；流萤在匹诺康尼与开拓者并肩作战。这个组织更像是在「使用」列车组——把他们推到需要的位置上，然后退开。

列车组对此心知肚明，却也没有更好的选择：星核猎手掌握的信息，往往比公司或仙舟更接近真相。

## 与其他势力的关系

| 势力 | 关系 |
