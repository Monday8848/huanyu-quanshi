# 厄兆先锋

银河中有两种人谈论末日：一种在末日到来时迎接它，一种试图把末日从预言里读出来。厄兆先锋是后者。

## 他们的工作

厄兆先锋相信末王代表宇宙终末。

他们致力于从末王意义不明的话语中解读末日的预言——这是一项几乎不可能完成的工作，因为末王逆时而语，祂的话既像预言，也像回忆。

## 四末说

在厄兆先锋中，流传着名为「四末说」的预言：

> 四条命途会将银河推向「终末」的结局。

「毁灭」正是其中之一。该假说猜测，纳努克作为最后出现的星神，其诞生便意味着「星神」这一概念在宇宙层面进入了倒计时阶段。

这一假说被智库收录进[绝灭大君](/factions/lord-ravagers)词条，是厄兆先锋对银河思想史最实质的贡献。
