# 地火

> 「系上这条红丝巾，分担彼此痛苦。」
>
> 「我们是一家人……我们是地火。」

## 基本信息

| 项目 | 内容 |
|------|------|
| 外文名 | Wildfire |
| 性质 | 下层区自治组织 |
| 活动范围 | 铆钉镇、磐岩镇、矿区与废弃工厂 |
| 标志 | 红丝巾 |
| 核心成员 | 奥列格、娜塔莎、希儿 |
| 外围 | 鼹鼠党（虎克等下层区儿童） |
| 关联地点 | 贝洛伯格 |

## 它填补的是什么空白

贝洛伯格分上下两层。上层区有银鬃铁卫、有行政区、有大守护者；下层区有的是矿场、黑市、裂界裂缝和被截断的物资通道。

「地火」做的正是官方不做的事：分发物资、维持秩序、对抗趁乱作恶的人。它不是叛乱组织，也不以推翻上层为目标——它是**在没有政府的地方代替政府**。

这一点决定了它后来能转身：贝洛伯格变天之后，地火没有被清算，而是被纳入了重建的执行层。

## 红丝巾

地火的识别方式是系一条红丝巾。《我们是地火》这条光锥的故事把它的含义写完了：

> 她习惯了人们失去家园，也习惯了人们失去生命，但一个人时，哭泣也无用。
>
> 「系上这条红丝巾，分担彼此痛苦。」
>
> 「我们是一家人……我们是地火。」
>
> 当宽阔的手掌抚上她的脑袋，她终于忍不住掉下眼泪。

「分担彼此痛苦」是他们的组织原则，不是口号——在一个连明天有没有饭都不确定的街区，「有人和你一起扛」就是全部的社会保障。

## 三个人撑起的结构

| 人物 | 位置 | 作用 |
|------|------|------|
| **奥列格** | 带头人 | 曾任下层区治安的银鬃铁卫兵长，懂上层的规则，也懂下层的活法 |
| **娜塔莎** | 诊所 | 唯一的医疗点。她说过「比奇迹本身更重要的事，是守护人们对它的期盼」 |
| **希儿** | 骨干、战力 | 别号「蝴蝶」。地火最能打的一个，也是唯一敢当面顶上层的人 |

三个人的分工刚好覆盖一个社会最小的骨架：秩序、医疗、武力。

## 鼹鼠党

虎克带着一帮下层区小孩自称「鼹鼠党」，自封总负责人，还发展过「荣誉队员」——克拉拉就是被虎克用「极端的热情与同理心」拉进来的。

它当然不是真的武装，但它说明地火在下层区的渗透方式：不靠编制，靠邻里。孩子是最先相信「我们是一家人」的人。

## 与上下两层的关系

- **对银鬃铁卫**：不是敌人，是平行系统。铁卫守城门，地火守街巷。
- **对可可利亚**：她需要下层区稳定供矿，但从不承认地火的合法性。
- **对布洛妮娅**：从互相试探到合作。她需要有人把政策落到街面上，地火需要有人在上层签字。
- **对开拓者**：最初是防备，后来是带路、给物资、给情报。

## 1.0 之后

星核危机解决、可可利亚倒台，贝洛伯格进入重建期。地火的处境变了一个：它从「必要之恶」变成了「基层执行者」。

这个转变并不舒服——组织一旦被承认，就必须开始解释自己的账目、人员和暴力。希儿的成长线写的就是这件事：她得学会走进上层区，而不是只在下面骂上面。
