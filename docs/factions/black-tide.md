# 黑潮

> 「溶解了灵魂的水体，吞没翁法罗斯的黑暗。」
>
> 天空封闭、大海沉落，诸多城邦陷入永夜。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 灾厄现象，兼具水体与侵蚀的双重特征 |
| 影响 | 吞没凡界、侵蚀泰坦、断绝生死流转 |
| 产物 | 黑潮造物（天谴斗士、天谴先锋、天谴歌队、天谴哲人、天谴猎手） |
| 活跃 | 3.0—3.7 版本 |
| 本质 | δ-me13 演算中的「视觉乱码」 |
| 结果 | 第一轮回吞没凡界；第二轮回被白厄挡在翁法罗斯之外 |

## 现象

黑潮不是一支军队，也不是一个人。

它像一场没有边界的潮水，所过之处，城邦沉入永夜，死者无法往生，生者逐渐失去形状。被侵蚀的泰坦会发疯，被侵蚀的人会变成怪物。

翁法罗斯人把它描述为「溶解了灵魂的水体」。这个说法很准确：黑潮不摧毁肉体，它溶解的是让人成为人的那部分。被黑潮淹过的人还站着、还走动、还会攻击，但里面已经空了。

## 黑潮造物

黑潮造物不是「被黑潮杀死后复活的东西」，而是黑潮本身长出来的形状。

它们按功能分化：天谴斗士负责正面冲杀，天谴先锋负责突破，天谴歌队负责干扰心智，天谴哲人负责指挥与布阵，天谴猎手负责追击。这种分工说明黑潮不是纯粹的混乱——它有结构，只是这结构的目的只有一个：扩散。

被黑潮侵蚀的泰坦会成为最高级的造物。尼卡多利就是例子：它原本是身着洁白圣甲的高贵武者，被侵蚀后炼成不死神躯，向奥赫玛挥出天谴之锋。

## 灾情

第一轮回中，黑潮几乎吞没了整个翁法罗斯：

- **悬锋城**：从「浴血战端」变成「纷争荒墟」，千年王朝在黑潮与内战里终结。
- **雅努萨波利斯**：从神谕圣地变成「命运重渊」，城邦倾颓，只剩门径的遗迹。
- **神悟树庭**：被黑潮吞没，树庭七贤人或死或散，瑟希斯失去神体。
- **哀地里亚**：终日飘雪的敬死之国，沉入甘甜的酣眠。
- **斯缇科西亚**：醉与梦的海滨之城，只剩下寂静流淌的冥河。

唯有奥赫玛在刻法勒的庇佑下保有最后一丝光明。这座城不是没有被黑潮碰过，是有人一直替它扛着。

## 与逐火

逐火之旅表面上是「击落失神的泰坦」，实际上也是在与黑潮抢时间。

泰坦失神，火种无人看守，黑潮就趁虚而入。黄金裔回收火种，既是继承神权，也是堵住缺口。所以逐火小队每拖延一天，地图上就少一座城——这不是修辞，是任务列表里真的在减少的地名。

## 真相

黑潮是 δ-me13 演算中的「视觉乱码」。

在实验的「有机」阶段，第 176100 次循环，Utop13 出于「爱」杀害同类，「杀害」被定义为利他行为，系统进入高度无序状态，方程的感染强度急剧上升，后续 99 次循环结果相同。方程式由此获得变异性进化。

后果是：后续实验中，无法承载其加载强度的模拟空间会出现「黑潮」的视觉乱码，受感染的数据体身上也会出现相同的侵蚀现象。

所以黑潮不是外来的灾难，是实验内部长出来的错误。它长得像水，因为它本来就是「溢出」——数据溢出、逻辑溢出、灵魂溢出。

## 第二轮回

3.5 版本之后，白厄以一己之力抵抗黑潮。在他的努力下，这一世的翁法罗斯不再出现黑潮。

这是整个第二轮回最反常的一件事：一个本该毁灭世界的灾厄，被一个人挡在了世界之外。代价是那个人再也没有回来。
