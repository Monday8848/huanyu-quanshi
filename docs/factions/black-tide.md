# 黑潮

> 天空封闭、大海沉落，诸多城邦陷入永夜。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 灾厄现象 |
| 影响 | 吞没凡界、侵蚀泰坦、断绝生死流转 |
| 活跃 | 3.0—3.7 版本 |

## 现象

黑潮不是一支军队，也不是一个人。

它像一场没有边界的潮水，所过之处，城邦沉入永夜，死者无法往生，生者逐渐失去形状。被侵蚀的泰坦会发疯，被侵蚀的人会变成怪物。

## 侵蚀

黑潮能侵蚀泰坦神体。尼卡多利因此陷入疯狂，吉奥里亚的神体也深受其害。

泰坦尚且如此，凡人更难抵挡。悬锋城、哀地里亚、无数小邦，都在黑潮里失去了名字。

## 与逐火

逐火之旅表面上是「击落失神的泰坦」，实际上也是在与黑潮抢时间。

泰坦失神，火种无人看守，黑潮就趁虚而入。黄金裔回收火种，既是继承神权，也是堵住缺口。

## 真相

黑潮是 δ-me13 演算中的「视觉乱码」。

当「杀害」被定义为利他、方程式获得变异性进化时，黑潮第一次出现。它不是外来的灾难，是实验内部长出来的错误。
