# 十王司

> 「统管长生种生死、罪咎、魔阴身等诸般事宜，不受六御节制。」
>
> ——丹鼎司丹士含明

## 基本信息

| 项目 | 内容 |
|------|------|
| 外文名 | Ten-Lords Commission |
| 职能 | 生死、罪咎、魔阴身 |
| 特殊性 | **不受六御节制** |
| 下属设施 | 幽囚狱、因果殿 |
| 核心职衔 | 司狱、主簿、判官、冥差 |
| 关联地点 | 罗浮（幽囚狱） |

## 它管的不是罪，是「不该活着」

十王司在仙舟六司里最特殊：其他五司管现世的事务，它管的是**生死界限本身**。

它有三个职权范围：

1. **生死**：仙舟人长生不死，所以「死」不是自然事件，是需要被管理的程序。大限将至者由冥差接引入因果殿，归于寂灭。
2. **罪咎**：触犯「不赦十恶」者，由判官出巡罚罪。
3. **魔阴身**：堕入魔阴身的长生种已经不是人，处置权在十王司，不在云骑军。

「不受六御节制」这五个字是关键：它意味着十王司可以调查任何人，包括六司的主官。

## 四判官

判官分「拘、锁、刑、问」四职，各有专司：

| 判官 | 职责 |
|------|------|
| **「拘」** | 寻索重犯，将其勾摄镇伏 |
| **「问」** | 读取犯人的因果罪愆，而后以「冥谶天笔」书写业报判罚 |

（档案中明确列出的是「拘」与「问」两职，另两职按名目对应锁拿与行刑。）

「问」这一职最特别：它不是审讯，是**直接读取因果**。在一个所有人都活得够久、所有事都有记录的社会里，罪证不需要口供。

## 其他职衔

- **司狱**：统管所在幽囚狱。
- **主簿**：负责幽囚狱内部行政流程管理，及判决文书、官方通告、内宣素材等文字工作。
- **冥差**：接引大限将至的仙舟住民入因果殿、归于寂灭；若有人触犯「不赦十恶」，冥差要随判官出巡罚罪。

「内宣素材」这个词出现在主簿的职责里，说明十王司也做舆论——一个管生死的机构同时管叙事，并不奇怪。

## 不赦十恶

| 序 | 罪名 |
|----|------|
| 1 | 令堕长生 |
| 2 | 贪取不死 |
| 3 | 迷乱心智 |
| 4 | 诱陷魔阴 |
| 5 | 残杀胞族 |
| 6 | 窃夺机要 |
| 7 | 破狱释囚 |
| 8 | 离间盟契 |
| 9 | 造作兵祸 |
| 10 | 倾覆仙舟 |

十条罪名可以分成三组：关于长生的（1–4）、关于族群内部秩序的（5–8）、关于仙舟整体的（9–10）。

值得注意的是第一条「令堕长生」——**让别人变成长生种也是死罪**。这条法律的存在，说明仙舟人对自己种族的处境有清醒的判断：长生是刑罚，不是恩赐。

## 考据

十王即十殿阎罗王，掌阴曹地府：秦广王、楚江王、宋帝王、五官王、阎罗王、平等王、泰山王、都市王、卞城王、转轮王。

游戏把佛教/道教的地府官僚体系直接搬进了科幻设定，且搬得很认真：判官、冥差、主簿、因果殿、冥谶天笔，全部对得上。
