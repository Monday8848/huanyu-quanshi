# 博识学会

> 他们不问「该不该」，只问「能不能」。

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 智识 |
| 星神 | 博识尊 |
| 性质 | 跨星系学术组织 |
| 主要资助方 | 星际和平公司 |
| 代表成员 | 真理医生（拉帝奥） |

## 学者

博识学会聚集了银河里最聪明的一批人。他们研究星神、命途、忆质、古代文明，也研究怎么把研究成果卖出去。

与流光忆庭不同，博识学会不保持中立。它接受公司的资助，为公司的项目提供技术支持，也因此常被指责为「公司的研究所」。

## 智识

智识星神博识尊代表的是「求知」本身。在学会的信条里，知识没有善恶，只有真伪。

这套信条让学会的研究推进得极快，也让他们反复越过伦理边界：只要能得出结论，手段往往不在考虑范围内。

## 真理医生

拉帝奥是博识学会里最出名的成员之一。他以「真理医生」自居，认为愚昧是一种病，需要治疗。

他的行事风格代表了学会的另一面：不满足于研究，还要把结论强加给世界。这种傲慢在学会内部并不被视为缺点，反而被当作「学者的责任」。

## 在主线中的位置

博识学会在主线里出场不多，但它解释了很多背景：模拟宇宙的技术基础、公司对星神的研究、以及银河里那些过于先进的造物从哪来。

它也是「智识」这条命途在凡间的具体形态——一群相信「理解一切就能掌控一切」的人。
