# 星穹列车

> 一辆沿着星轨行驶的列车。它不属于任何国家，不挂任何旗号，只在需要的时候停靠，把愿意上车的人带走。

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 开拓 |
| 星神 | 阿基维利（已陨落） |
| 领航员 | 姬子 |
| 成员 | 姬子、瓦尔特、丹恒、三月七、开拓者，以及列车长帕姆 |
| 行动方式 | 沿星轨行驶，停靠点由领航员决定 |
| 原则 | 不干涉所到世界的内部事务，只提供有限协助 |

## 起源

星穹列车是阿基维利的造物。这位「开拓」星神用列车连接一个又一个世界，把「开拓」这件事本身变成一条命途——不是征服，也不是传教，而是抵达、记录、再出发。

阿基维利陨落之后，列车没有停。它继续沿着既有的星轨运行，由一代代领航员接手。今天的列车组并不清楚阿基维利究竟死于什么，也不急着搞清楚——车还在开，这件事比答案更重要。

## 车上的人

列车组自称**无名客**：不留姓名，不立牌坊，到了一个世界就下车看看，能帮就帮，帮完就走。

- **姬子**：现任领航员，决定列车去哪、停多久。她对「开拓」的理解比车上任何人都务实。
- **瓦尔特**：前逆熵盟主，见过另一个宇宙的末日，因此对「拯救世界」这类说法保持距离。
- **丹恒**：持明族，与仙舟罗浮有极深的渊源，长期回避自己的过去。
- **三月七**：失忆的少女，被列车组收留，用相机记录沿途的一切。
- **开拓者**：体内被植入星核的人，也是列车组卷入各世界危机的直接原因。
- **帕姆**：列车长。职位比所有人都高，负责的事情比所有人都琐碎。

## 开拓的含义

「开拓」在列车组这里不是口号，而是一套具体做法：修好星轨，打通航路，把封闭的世界重新接回银河。

这件事听起来无害，实际处处踩线。航路一开，星际和平公司的商队就会跟进；世界一接入，当地的秩序就要重排。列车组坚持「不干涉」，但停靠本身就是一种干涉——这是星穹列车最常被质疑的地方，也是它无法回避的矛盾。

## 与其他势力的关系

| 势力 | 关系 |
|------|------|
| 星际和平公司 | 表面客气。公司把列车当作开拓航路的免费先遣队，列车组则尽量不接受公司的资助 |
| 星核猎手 | 关系复杂。双方在多个世界有过合作，也有过正面冲突 |
| 仙舟联盟 | 有旧交。列车与罗浮之间的人情，比表面上看起来更深 |
| 家族 | 受邀参加「谐乐大典」，随后被卷进匹诺康尼危机 |
