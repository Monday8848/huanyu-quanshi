# 无名客

> 「神秘的陌生人踏入诸界，复又离去。」
>
> ——阿德里安·斯宾塞-史密斯，《有关星空的寓言集》

## 基本信息

| 项目 | 内容 |
|------|------|
| 定位 | 与「开拓」的星神共同探索宇宙的人们 |
| 特质 | 勇敢而好奇的星际探险者，不图名利 |
| 座驾 | 星穹列车 |
| 现任成员 | 姬子、瓦尔特、丹恒、三月七、开拓者 |

## 起源

千年前，名为阿基维利的星神走过诸界，在星海间铺下银轨，让一个又一个世界彼此相连，留下关于宇宙和探索的传奇——勇敢而好奇的人们被精彩的冒险故事吸引，纷纷追随「开拓」之神的足迹，加入探索银河的旅途。

旅行者们自称「无名客」，他们搭载着阿基维利建造的列车，奔行于被银轨联结的星球之间，展开一段段扣人心弦的冒险旅程。

## 与阿基维利的羁绊

智库记载了这位星神与信徒相处的方式：传说「开拓」的阿基维利酷爱与凡人共行，祂与「无名客」们共饮来自不同世界的佳酿，合唱不同种族编谱的歌谣。

- 他们时常将列车行驶的轨迹伪装成流星的彗尾，在窥见人们仰头惊异的神情后放声大笑；
- 也时常因莽撞大意而陷入危机，借助星神的力量才得以逃出生天。

阿基维利与追随者们建立了深厚的羁绊，他们的探险也不断吸引着异世的旅者加入「无名客」的行列。

## 阿基维利陨落后

阿基维利陨落后，一群忠实的「无名客」继承了祂的遗志，继续探索未知的世界，坚信有朝一日，「开拓」的意志将联结整个宇宙。

那列曾搭载祂与追随者们的银河列车，至今仍然行驶在星海之间。传说，**它以逝去星神的心脏作为源动力，艰难地修复着被未知之癌污染的轨道**——这是智库对列车核心与「星轨污染」最直白的表述：阿基维利死了，祂的心脏还在拉车，祂的路在被癌症蚕食，而无名客还在修。
