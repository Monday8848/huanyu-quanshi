# 石心十人

> 战略投资部最锋利的十个人，每人持有一枚基石。

## 结构

石心十人是战略投资部的中枢。每人都持有一枚「基石」，既是身份凭证，也是力量来源。

基石可以押上赌桌，也可以被夺走。石心十人的地位从来不是终身制，而是一场持续进行的投资评估。

## 已知成员

- **钻石**：战略投资部主管，石心十人的核心。
- **砂金**：匹诺康尼篇的关键赌徒，以命下注。
- **托帕**：追债人，账账的搭档。
- **翡翠**：匹诺康尼的买家，擅长把人情做成资产。
- **真珠**：二相乐园首席执行官，4.6 实装。

其余成员官方尚未全部公开。

## 风格

石心十人不像市场开拓部那样靠武力圈地。

他们用合同、债务、股权和人情办事。能买下来的就买，买不下来的就先让它欠钱。

## 4.x

4.0 中，真珠手握三张「欢愉假面」，试图用公司资源控制幻月游戏。

4.6—4.7，她在千星城与二相乐园之间来回调度，既维持公司的资产，也没有把列车组当成弃子。
