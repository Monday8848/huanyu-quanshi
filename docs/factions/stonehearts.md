# 石心十人

> 「血肉孱弱，而我心坚如辉石。若非如此，则『存护』之道无以立足。」
>
> ——「钻石」，战略投资部主管，P47 级

## 建制

「石心十人」不是正式部门名，而是公司内部对一支精英团队的俗称。这一岗位在公司里的正式名称是<strong>「不良资产清算专家」</strong>，直属战略投资部主管「钻石」。

官方对公司智库的记述是：其成员**出身各异，职责也各不相同，甚至有多人轮替的记录**。唯一的共性是——他们均受「钻石」本人拔擢，并被授予了名为「基石」的身份凭证。

「多人轮替」这句话很重要。它意味着「石心十人」是一个**编制**，不是十个固定的人：有人升迁、有人失格、有人退出，位置会空出来，也会有人补上。砂金在匹诺康尼一役后一度被剥夺位列，就是这套轮替机制的一次公开演示。

公司内部对这十人的性质有三种说法：

- 一种说他们是「钻石」的**私兵**，只听命于战略投资部；
- 一种说他们是纯粹的<strong>「存护」信徒</strong>；
- 还有一种说法更刻薄——他们「挖走自己的心，换上了克里珀的石头」。

「石心十人」究竟效忠于谁，官方文本给出的答案是：**这暂时是个无法回答的问题**。

### 投票表决

「钻石」极少公开露面，代替他站在台前的是「石心十人」。

在关乎团队生存的重大议题上，「钻石」允许十位精英以**独立、平等**的方式完成决策，即投票表决。

千星纪游 PV「石心誓环·天平两端」把这件事说成一台天平：十枚基石是十个砝码，票数就是重量。而那一夜的开场白是——

> 「一枚基石破碎，砝码仅余其九。下一个被摆上台桌的问题，只能以『倾倒』作结……」

这就是砂金的处罚决议只有九票的原因：他自己那一枚，已经碎了。

## 基石

**基石**是封藏「存护」令使权能的圣石，由「石心十人」各自持有一枚。

它同时是三种东西：身份凭证、力量来源、以及公司对个人的绑定。基石可以押上赌桌，可以被收缴，可以被损毁，也可以被修复——砂金的基石在匹诺康尼碎过一次，后来由欧泊修复。

已公开的四段基石誓词，格式高度统一，或为调用力量的口令：

| 成员 | 誓词 |
|------|------|
| 砂金 | 我来押注、我来博弈、我来赢取。我任命运拨转轮盘，孤注一掷，遍历死地而后生。一切献给琥珀王。 |
| 翡翠 | 我来觐见、我来添酒、我来占有。我为甘露赐下鸩毒，春种秋收，静待枯果满枝头。一切献给琥珀王。 |
| 真珠 | 我来鉴知、我来解析、我来落笔。我将天地列入织锦，画石点睛，日月星辰自然成。一切献给琥珀王。 |
| 舒俱 | 我来救谕，我来征敛，我来称取。我许万民匍匐求得，予取予夺，尽纳膏血铸金冠。一切献给琥珀王。 |

三段式 + 「一切献给琥珀王」，是这套誓词的固定骨架。尚未公开誓词的成员，其基石名也一并未公开。

## 逐人档案

### 托帕

本名**叶琳娜**，P45 起步，因一次事故被降级至 P44，3.5 又「上调至 P44.1」——0.1 级的幽默。她领导特殊债务纠察小组，专责追讨坏账，搭档是一只次元扑满「账账」。

托帕的做事风格是把追债做成一场体面的谈判：先算清账，再给对方留一条能走的路。雅利洛-Ⅵ 的债务重组就是她的手笔，也是公司「重新回收失联世界并注资复兴」这笔业绩的实际执行人。

她的基石「催讨黄玉」，名字里就写着职能。

### 砂金

本名**卡卡瓦夏**，茨冈尼亚-Ⅳ 的埃维金人。P45 起步，2.3 之后升至 P46。

他的履历是从骗子开始的：曾欺骗市场开拓部，谎称茨冈尼亚的黄土下藏着未被开发的能源，让公司砸下巨资开采，结果一无所获；又策划「艾吉哈佐砂金案」，让博识学会相信那里埋着虫皇塔伊兹育罗斯的尸体，骗过了那帮以谨慎著称的学者。茨冈尼亚酋长国议员曾联名谴责他的部落「破坏决议、祸乱人心」。

「钻石」对这些投诉的回应是一句话：「每一种宝石都有独特的价值，而我们的工作就是『投资』。」

2.3 匹诺康尼一役，他把基石押在赌桌上，用一次「盛大的死亡」把公司拖进梦境，最终基石碎裂。随后的处罚决议上，他被剥夺位列——但「钻石」私下给了他一道密令：**一命抵一石，找出十人中的叛徒**。这场「处罚决议」本身就是他申请的，目的只是听听同僚们各自说些什么。

4.5，他排除了舒俱这个错误答案，复归位列，并在千星城替星穹列车摆平了债务。

### 翡翠

P46。「托帕」和「砂金」都是由她招募进入部门核心的——她是这一代石心十人的**引路人**。

她的基石「典贷翡翠」，职能是放贷与典当。官方描述她为「冷艳优雅的放贷人，善于洞悉人心」，有一项名为「慈玉典当」的本事：任何人可以得到她的恩惠，只需要付出等量的代价。

4.5，她在千星城「晨昏线潮汐」大酒店会见开拓者一行，交底公司内部关于二相乐园的方案之争——市场开拓部主张「兽蜕武器化」，战略投资部主张「存护」，六位部长投成平票，关键一票握在传统项目部的在田手里。她在指针塔为列车组准备了一间办公室，给了他们五个系统时去争取这一票。

### 真珠

智械女性，P45，二相乐园现任首席执行官。

她的基石「鉴映珍珠」对应「鉴知、解析、落笔」——观察、拆解、记录。官方给她的注解是「执着于钻研艺术的本质」，并希望就模拟宇宙项目与黑塔合作，为战略投资部清算坏账提供**史实资料**。

4.0 起，她以二相乐园首席执行官的身份进入哈托彼亚，用公司资源介入幻月游戏。4.x 主线中，她提出召请琥珀王的视线，借「存护」之力令二相乐园再度封存入画，以拖延兽蜕突破的时间——为此她愿意献出自己的基石。

一个 P45 的智械，主动押上基石去换一个星球的存续。这是石心十人里最不像「投资」的一笔投资。

### 欧泊

P46。外形是个子矮小、头发彩色、喜欢叼着奶嘴（可能是糖做的）的**小孩**——但在处罚会议上发言时，声音**从小孩逐渐变成青年**。

那场会议里他做了一件关键的事：**修复了砂金的基石**。一块被判定损毁的基石，被他在会议桌上修好了。这不是「投反对票」那么简单，是直接改写了处罚的物质前提。

4.5，舒俱在通话里点名：「龙晶，还有欧泊」——这两位即将找上星穹列车，作风是「要么得到，要么毁掉」。CV 为中配 Kinsen、日配岸尾だいすけ。

### 龙晶

P46。红发，哥特风，官方对其行事方式的注释只有四个字：**较为激进**。

处罚决议上，她替长期未露面的玛瑙投了赞成票——代投这个动作本身说明她在十人中有代理权，或者说，她与玛瑙之间存在某种委托关系。

4.5，她与欧泊一同被派往千星城，目标直指星穹列车。CV 为中配洪海天、日配上坂すみれ。

### 苍刚

基石、职级均未公开。官方给出的性格关键词是「**注重誓言**」。

处罚决议上，他没有到场，由真珠代为投下赞成票。千星纪游 PV「石心誓环·天平两端」中，他的镜头是**剑盾与一只狮鹫**——誓约、守护、以及一只认主的猛禽。

代人投票这件事，对一个大概念「誓言」的人来说是个微妙的位置：票投了，人没来。

### 玛瑙

基石、职级均未公开。官方注释：「**疑似很久没有出现过**」，由龙晶代投赞成票。

PV 中属于他的画面是「**财神爷神龛**」——香火、供品、以及一尊被当作财源来拜的神像。一个长期缺席的人，留下的是一间神龛。

「很久没有出现」在「多人轮替」的编制里不是好兆头。这个位置是否已经换人，官方没有交代。

### 舒俱

紫、金为主色的衣着，围绕他的是极尽奢华的居所与堆积的财富。**悲悼伶人出身**——一个本该以禁欲苦修抗拒「欢愉」的人，转身走进了银河最大的公司。

他的基石「征敛舒俱」对应「救谕、征敛、称取」。机制很具体：对象每欠下一笔债，他天平上就多一枚砝码；发动基石可向对象强制征收，**甚至以生命抵债**。

论财富，石心十人中几乎无人能与他相比。但他**常年据守末位**——砂金直到 4.5 才想明白这意味着什么：所有想跻身「石心」的人，都必须跨过名为「舒俱」的门槛，经受他最直接的审视。他在替「钻石」筛选：得到「石心」之名的人，是否承受得住「基石」之重。

他投过赞成票的决议远不止砂金那一场。他自己的说法是：「否则，我怎么能亲眼看到其他人对此的表情？」

如今酒馆不再欢迎伶人，他便把公司当成欣赏悲剧的舞台。名下有家常年亏损的保险公司，接了一笔注定赔钱的单子——因为「他觉得有趣」。

### 琥珀

基石、职级均未公开。官方注释：「**疑似智械或系统**，遵从中立身份」。

「中立」在一个以投资回报为唯一标准的团队里是罕见的位置。一个可能是智械、或者本身就是一套系统的成员，天然适合做不计情绪的那一票。

需要注意：此「琥珀」是石心十人的成员代号，与光锥「琥珀」、与「琥珀王」克里珀均无关。

## 组织逻辑

### 门槛与天平

石心十人名义上平级，实际存在两重隐性秩序。

**第一重是舒俱的门槛**。他守在末位，不是因为他弱，而是因为他的位置被设计成筛子。每一个新晋「石心」都要先过他的审视，被他判定「承受得住基石之重」，才算真正入列。

**第二重是钻石的私兵属性**。十人直属主管，不经部门层级，不问过程只看结果。这让战略投资部在公司七大部门的博弈中拥有一支可以随时调动、且不必对外解释的力量。

### 叛徒

4.5 的千星城线，核心是一条清查：**十人中有叛徒**。

「钻石」给砂金的密令是「一命抵一石」，无支持、无线索、无方法，即便被捕或被杀，部门对此都不知情。

砂金用一场自请的处罚决议来观察同僚。最终排除了舒俱——但顺带确认了一件事：匹诺康尼的「梦主」把「同谐」的秘密，托付给了一位石心十人的同僚。这条线索指向谁，官方在 4.5 收束时仍未揭晓。

紧接着，龙晶与欧泊被派往千星城。「有人唱红脸，就有人唱白脸」——这两位的作风是「要么得到，要么毁掉」。
