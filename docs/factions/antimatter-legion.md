# 反物质军团

> 不是为了胜利而战，也不是为了利益而战。它们存在的理由，就是把存在本身抹掉。

## 基本信息

| 项目 | 内容 |

| 命途 | 毁灭 |
| 星神 | 纳努克 |
| 高级战力 | 绝灭大君 |
| 组成 | 反物质构成的兵卒，以及被毁灭意志驱动的眷属 |
| 行为模式 | 无谈判、无占领、无统治，只破坏 |
| 已知行动 | 入侵黑塔空间站；在多个世界留下毁灭痕迹 |

## 毁灭的意志

纳努克的信徒不追求权力，也不追求生存。他们认为宇宙的存在本身就是错误，毁灭是唯一的正确答案。

这种逻辑让反物质军团成为所有势力的共同敌人：公司可以和仙舟谈、和家族谈、甚至和星核猎手谈，但没法跟军团谈。军团不接受投降，也不接受交易——它只接受「不存在」。

## 绝灭大君

绝灭大君是军团的高阶存在，各自拥有不同的毁灭方式。已知的包括幻胧，它以寄生和替换的方式渗透目标，在仙舟罗浮掀起了一场几乎无法挽回的动乱。

大君之间没有统一的指挥体系，也不见得彼此认同。它们共同的地方只有一个：都在执行纳努克的意志。

## 与星核的关系

军团对星核有兴趣。星核能扭曲现实、加速世界崩溃，对军团来说是一种高效的毁灭工具——但它们并不依赖星核，也不与星核猎手合作。

这种「目标部分重叠、立场完全相反」的关系，让三方在星核问题上的博弈格外难解。
