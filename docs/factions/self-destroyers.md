# 自灭者

> 「我以万物为砥石，试图砥砺我之意义；却不知万物是水，我消逝其中，正如水消逝在水中。」
>
> ——悲悼伶人莲祷，凝视虚空后写下的唱词

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 现象／人群，非社会组织 |
| 成因 | 踏入「虚无」Ⅸ的阴影，失去存在意义 |
| 结局 | 大多是无意义的消亡 |
| 症状 | 躯体、认知、记忆逐项消亡 |
| 已知个体 | 黄泉、焚风（推测） |
| 相关组织 | 混沌医师、第Ⅸ机关 |

## 定义

宇宙万物并无意义，人类在星神眼里亦不值一提。如果星神当真凌驾众生、高高在上，又怎会在乎凡人的爱恨苦乐？

「自灭者」是不慎踏入「虚无」Ⅸ的阴影、因此失去存在意义的人群。

「虚无」的影子平等地遮蔽星空，自灭者可能在任何一个世界诞生。若将之称作「派系」，他们彼此之间过于缺乏社会性联系；但若视之为「现象」，这群可怜人又都具有一种共性：**他们的存在属性——躯体、认知、记忆——会在自灭的旅途中逐渐消亡**。

## 症状记录

混沌医师的手记如此形容：

> 有些人的皮肤变得像是腐烂的枯木，布满伤痕和孔洞；有些人的内分泌系统开始错乱，不分快乐与痛苦，变得对一切麻木；有些人失去了记忆，有些人丧失了感官……他们仿佛被某种存在剥夺了生命的意义，只能在梦境和幻觉中不断看见自己的身影消失在一处地平线尽头的黑洞里。

## 两条出路

| 选择 | 表现 |
|------|------|
| 颓唐 | 接受无意义，孤行宇宙，等待消亡 |
| 反抗 | 加入混沌医师，以医治他人换取自我救赎 |
| 极端反抗 | 以杀死沉眠深渊的星神为目标，从根源断绝诅咒 |

## 已知个体

**黄泉**——出云最后的刀客，以「巡海游侠」的名义行走宇宙，实为自灭者。她的过去、她的名字、她斩落的东西，都在自灭途中被一点点剥夺。

**焚风**——绝灭大君。部分混沌医师推测他正是受Ⅸ感召的自灭者：面对星神投下的阴翳，他把褪却的色彩磨砺成极致的白光。此说为猜测，未见官方确认。

## 原始博士的问题

天才俱乐部#64「原始博士」失踪前曾发问：

> 倘若Ⅸ真的对宇宙视若无睹，「虚无」的命途何以存在至今？

也许当自灭者茫然行于星海，同时也是在将祂的阴影投向宇宙各地。而那寥寥少数能以自身存在承受「虚无」浸染的行者，他们的自灭之旅被拉得无限漫长，走出的道路也如同Ⅸ在世间的一道侧影。
