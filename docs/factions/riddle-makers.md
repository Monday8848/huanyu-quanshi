# 谜语人

> 「我知道的你也知道，我不说的你也不说，我是什么？」
>
> ——谜语大师巴德·巴比巴伯·巴拉

| 项目 | 内容 |

| 性质 | 神秘命途的语言破坏者 |
| 命途 | 神秘 |

| 目的 | 让语言不再确定 |

## 从才子到妄语者

「神秘」的追随者才人辈出，「谜语人」更是个中翘楚。

他们曾是殿堂诗人、光影画家、变相师或秘学僧侣，在各自的领域栩栩生辉，却在接触了星神之后，变为一群口出胡言、书写妄语的莫名其妙之徒。

## 与虚构史学家分工

虚构史学家致力于历史的神秘化，而「谜语人」醉心于破坏语言的确定性。

用来言词表意的文字在「谜语人」的口中逐渐模糊。他们解构文本，创造喻象，变换语序，篡改含义，将原本精确的语言变得面目全非。

## 潜移默化的后果

谜语人虽不如虚构史学家那样大张旗鼓，但其所作所为仍然对现实宇宙造成了潜移默化而巨大的影响。

如今银河中已难寻纯粹精准的语言，原因何在？这是谜语人留下的又一个谜语。
