# 悲悼伶人

> 即便没有观众，他们也义无反顾地坚持排练。这就是他们的生物钟，他们的悲剧美学。

## 伶人

悲悼伶人是一群以悲剧为职业的人。

他们在地下剧场排练到凌晨四点，哪怕没有观众也照常开演。在他们看来，喜剧让人发笑，悲剧让人记住；被记住的东西，才配叫艺术。

## 与幻月

远古时代，八位悲悼伶人向幻月献上惊世骇俗的故事，求一个谒见星神的资格。

幻月游戏由此诞生。每届八位谒者，或许正是从这八位伶人开始计数。

## 虚照

虚照曾是悲悼伶人。

她后来转行画漫画，理由是：画漫画也经常画到凌晨四点，作息一样，不如选个更赚钱的。

## 与假面愚者

悲悼伶人与假面愚者互相看不上。

愚者嫌伶人的哭戏没技术含量，伶人嫌愚者的笑话太吵。两边都靠「欢愉」吃饭，却谁也不肯承认对方也是同行。
