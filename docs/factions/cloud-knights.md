> 「裂天柝星，挽弓逐狼」
>
> ——云骑军题词

## 名字是怎么来的

仙舟联盟的军队不叫「军」，叫「云骑」。这个名字来自一场交易。

「火劫」时期，为击退丰饶民，帝弓不顾劝阻进入朱明仙舟深处的牢狱，说服了被囚困的岁阳领袖「燧皇」，与它做了夺舍交易——**用自己的躯壳换取岁阳之力的协助**。

各艘仙舟上许多人为了响应英雄的献身，选择与英雄做同样的交易。他们加入敢死部队，与岁阳结伴行军，誓「如云翳障空，卫蔽仙舟，永不落地」。

这就是「云骑军」之名的起源。

一句话概括：这支军队的成员，从一开始就是把自己的身体借出去的人。

## 职衔

| 职衔 | 职责 |
|------|------|
| **元帅** | 全军最高职务，其上另设统帅 |
| **将军** | 六艘仙舟各一位，节制本舰军队。须经「天虹封典」「帝弓垂眸」「受赐威灵」三道仪式方能接掌符节 |
| **骁卫** | 骁勇善战的高级军官 |
| **士兵** | 能征能战，云骑军最重要的成员 |
| **策士** | 负责战争策略的智囊 |
| **司库** | 负责后勤军需 |

一个残酷的细节写在将军条目里：在血火厮杀的战争中，**鲜有云骑将军能在履任后撑过百年的大关**。仙舟人本该活上九百年。

舰队名多取自星象与神鸟，和「云骑」这个意象连在一起：云、鹤、虹、乌、毕方——都是天上会动的东西。

## 他们打的仗

云骑军的对手主要是丰饶孽物。这不是一场能赢的战争：丰饶的力量会让敌人不断再生、增殖，杀不完，也灭不掉。

所以他们的目标写得极重：「以一个近乎不可能的任务——终结星海之间的不死污染为己任。」

罗浮的云骑军还要处理另外两类事：

- **魔阴身**：堕入魔阴身的长生种就是孽物，需要被清剿（监管归十王司）。
- **内部叛乱**：药王秘传、饮月之乱这类，也得他们出手。

## 与六司的关系

云骑军是六司之一，但它的地位特殊：其余五司管的是「怎么活」（历法、贸易、医药、制造、庶务），云骑军管的是「还能不能活」。

这也是为什么将军在仙舟政治里的话语权远大于其职级——战争状态是仙舟的常态。
