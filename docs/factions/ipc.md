# 星际和平公司

> 「恕我直言，这个宇宙里还有比克里珀更开明的董事长吗？祂默许我们的一切经营决策，从不质疑，从不过问——这是偌大的荣幸，偌大的信任！」
>
> ——奥斯瓦尔多·施耐德，市场开拓部主管，P47 级

## 三重身份

官方对公司性质的界定是三条并列的，不是一句口号：

- **对外宣传**：一家倡导自由贸易的巨型企业财团；
- **运作方式**：发行货币并垄断资源的商界独裁；
- **创业初心**：为「存护」的星神奉献一切的无私后援。

大多数星际公民谈到公司时，想到的是无所不在的商品与醒目标识——「只要存在交易之处，就存在星际和平公司」。银河中几乎所有的商业行为都建立在公司的「信用点」体系之上。若把星际贸易比作运动比赛，公司既是顶尖的运动员，又是各种运动项目，既是比赛场地，同时还是规则本身。

对财富的绝对统治力，加上从未停止过的扩张，让公司背上了「阴谋独裁者」的大众印象。但公司对这类评价并不在意，因为企业精神自诞生之初就没变过：**将一切奉献给「琥珀王」克里珀**。

## 起源

公司的前身是追随克里珀的<strong>「琥珀王后援队」</strong>——一支为筑墙工程筹集材料、组织人力、维持后勤的动员体系。

距今七百七十余琥珀纪前，路易斯·弗莱明与东方启行宣布将后援队改组，成立星际和平公司。东方启行的手笔是构筑「信用点」体系——把筑墙的奉献换算成可以流通、可以计息、可以继承的数字。

从那以后，墙还在筑，但筑墙本身也成了一门生意。这是公司最核心的矛盾：它用「存护」的名义积累权力，而积累权力的过程，往往并不存护任何人。

## 七部门

公司设七个部门。字面意义的「部门」早已无法概括这家泛银河企业的尺度——现实中的每个部门往往掌握着数十到上百个规模不一的文明世界，世代为其效力的员工以亿万计。

| 部门 | 主管 | 职级 | 职能与特征 |
|------|------|------|------------|
| 市场开拓部 | 奥斯瓦尔多·施耐德 | P47，董事会理事候补 | 前往更多星系宣传克里珀的使命，把新世界拉入宇宙商业体系。施耐德曾是无名客，加入公司后仍带着强烈的「开拓」意愿，被视作「存护」狂热分子与扩张主义者 |
| 业务巩固部 | 疤眼夫人 | P48，董事会理事 | 接管建交后的后续商业，统管超距传输网络、清点特色物资并定价，长期维护下属设施与货品清单。公司最庞大的部门，员工数占总部总数 **45%** |
| 战略投资部 | 「钻石」 | P47，董事会理事候补，「存护」令使 | 投资周期以数十甚至数百琥珀纪计，以完全的星系掌控为结果。下设精英团队「不良资产清算专家」，即石心十人 |
| 筑材物流部 | 塔拉梵·基恩 | P48，董事会理事，「存护」令使 | 公司历史最悠久的部门，前身即「琥珀王后援队」，在路易斯崛起后改组。担负向克里珀运送筑材的任务，地位稳固 |
| 技术研发部 | 亚婆离 | — | 与博识学会深度合作，把学会的研究成果转化为商业项目。亚婆离同博识学会「庸众院」的联系引人遐想 |
| 人才激励部 | 姆托尤因·拉杰·扎扎德、阎世罗 | — | 招募、培养、输送人才，同时是跨星系项目沟通协作的媒介。两位主管共同掌握一张遍布银河的情报网络；阎世罗出身仙舟联盟 |
| 传统项目部 | 在田 | 董事会理事 | 承接从业务巩固部剥离的低占比产业。业绩平平、不受重视，被嘲笑为「养老院」，但也有观点认为真正的精英都在其中 |

七个部门之上是**董事会**。董事长的位置官方标注为克里珀——一位从不质疑、从不过问的董事长。

### 战略投资部的业绩

「钻石」上台后，战略投资部达成过几笔令星海瞩目的业绩：

- 消除伽伦德星区的虫灾，完成新生态圈的商业化运行；
- 星核事件后，对戈尔康达矿业世界联合体注资，为筑材运输贸易带来新矿源；
- 重新回收失联世界雅利洛-Ⅵ，并注资其复兴工程；
- 与流光忆庭达成合作，进行对死灭世界忆质的打捞计划。

这些事件的背后，石心十人异常活跃。

### P 级序列

员工实行 P 级序列。P45 以上是干部层，P46、P47、P48 逐级递增，每一级对应的资源调动权限与场合准入都不同。

已公开的高位：

| 职级 | 人物 |
|------|------|
| P48 | 疤眼夫人（业务巩固部）、塔拉梵·基恩（筑材物流部） |
| P47 | 奥斯瓦尔多·施耐德（市场开拓部）、「钻石」（战略投资部） |
| P46 | 翡翠、欧泊、龙晶、砂金（2.3 后） |
| P45 | 真珠；砂金（2.3 前） |
| P44 / P44.1 | 托帕（由 P45 降级，后「上调」至 P44.1） |

职级不是荣誉称号，是可以被下调的。托帕的 P44 与砂金的失格，都是这套序列在执行；而 P44 到 P44.1 的「晋升」，则是这套序列开的一个玩笑。

## 石心十人

**石心十人**是战略投资部下设的精英团队，正式岗位名为「不良资产清算专家」，直属「钻石」，十人各持一枚**基石**。

十人名单、基石权能、处罚决议与「叛徒」清查的经过，见 [石心十人](/factions/stonehearts)。

## 武装与执行力量

- **公司安保部队**：在「商业纠纷」中具备实际威慑力，可对特定人物实施预防性拘留。
- **千星戍卫**：千星城的治安力量，4.5 曾以「公司有权对家族通缉犯实施预防性拘留」为由，要求带走星期日。
- **特殊债务纠察小组**：托帕领导，专责追讨坏账。

## 业务与影响

- **货币发行**：信用点是公司体系内的通用结算单位；星琼因其稀缺性成为跨星际硬通货。
- **航线控制**：掌握大量星际航道与补给站，任何跨星系势力都绕不开。
- **标准制定**：从度量衡到合同格式，公司把自己的习惯推成了银河标准。
- **传媒**：「星际和平娱乐」总部设在千星城，艾普瑟隆星系的明珠，传媒精英荟萃之地。
- **金融衍生**：银河大乐透、星际大乐透等博彩业务，以及舒俱名下那家常年亏损的保险公司。

## 二相乐园与千星城

4.0 起，战略投资部的真珠接任二相乐园首席执行官，以公司资源介入幻月游戏。

公司用朋克洛德的以太编辑技术把画中世界打捞回现实，又在千星城用职级制度管理高层员工。

4.5，围绕二相乐园的「贪饕」危机，公司内部出现两套方案：市场开拓部主张「兽蜕武器化」，得到技术研发部与筑材物流部支持；战略投资部的「存护」方案得到业务巩固部与人才激励部支持。**六位部长投出平票**，关键一票握在传统项目部的在田手里。

翡翠在指针塔为星穹列车准备了一处办公室，给了他们五个系统时，在部长会议前争取这一票。

在田的养子**肯尼斯·在田**——千星城的实际「管家」——起初不留情面地拒绝了游说，只留下一句「贸易的核心在于尊重」。列车组随后选择用舆论施压：释放「兽蜕苏醒」的消息，让公司不得不重视。
