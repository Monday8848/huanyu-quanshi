# 星际和平公司

> 银河最大的经济体。名义上为琥珀王克里珀筑墙，实际上握着大半个宇宙的贸易、金融与物流。

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 存护 |
| 信奉 | 克里珀（琥珀王） |
| 总部 | 庇尔波因特 |
| 核心机构 | 战略投资部、市场开拓部等七个部门 |
| 权力核心 | 董事会，以及战略投资部下属的「石心十人」 |
| 通用货币 | 信用点（公司发行）；星琼为跨星际硬通货 |

## 起源：从筑城者到商业帝国

公司的前身是追随克里珀的筑城者组织。克里珀在宇宙边缘筑墙，抵御某种尚未言明的「终末」，追随者负责为这项工程筹集材料、组织人力、维持后勤——这套动员体系，就是公司最早的骨架。

随着时间推移，筑墙的宗教意义逐渐淡化，商业逻辑占了上风。今天的公司仍然宣称自己服务于琥珀王，但它的实际业务是贸易、金融、物流、能源与军工。墙还在筑，只是筑墙本身也成了一门生意。

这也是公司最核心的矛盾：它用「存护」的名义积累权力，而积累权力的过程本身，往往并不存护任何人。

## 组织架构

### 七部门

公司设七个部门，各管一摊：

| 部门 | 职能 |
|------|------|
| 战略投资部 | 投资、并购、风险处置；石心十人隶属此部 |
| 市场开拓部 | 新市场开发、新星球接入 |
| 业务巩固部 | 存量业务维护、客户关系 |
| 技术研发部 | 科技研发与专利运营 |
| 人才激励部 | 人事、考核、晋升 |
| 传统项目部 | 与「筑墙」直接相关的传统业务 |
| 筑材物流部 | 星际物流与建材供应 |

### P 级序列

员工实行 P 级序列，P35 以上进入干部层，P45 是公开可见的最高一级。级别决定了能调动的资源、能进入的场合，以及在谈判桌上有没有资格开口。

### 石心十人

**石心十人**是战略投资部的十位核心干部，各持一颗公司配发的「石心」。已知成员包括钻石（部门主管）、砂金、托帕、翡翠、真珠等。石心既是力量的来源，也是公司对个人的绑定——拿到它的人，很难再离开这套体系。

十人各有分工，也各有算盘。公司对石心的态度很实用：给最强的执行者最大限度的自主权，只要结果对得上账，过程不问。这套安排让石心十人成为公司扩张中最锋利的一把刀，也让他们成为最容易失控的一群人。

## 业务与影响

- **货币发行**：信用点是公司体系内的通用结算单位；星琼则因其稀缺性成为跨星际的硬通货。
- **航线控制**：公司掌握大量星际航道与补给站，任何跨星系势力都绕不开它。
- **标准制定**：从度量衡到合同格式，公司把自己的习惯推成了银河标准。
- **武装力量**：公司拥有自己的安保与执行部队，在「商业纠纷」中具备实际威慑力。

## 与其他势力的关系

| 势力 | 关系 |
|------|------|
| 仙舟联盟 | 长期贸易伙伴，签有互市协定，但双方都清楚对方在算计自己 |
| 家族 | 房东与业主。匹诺康尼的产权在公司手里，家族只有经营权 |
| 星核猎手 | 公开通缉，悬赏金额极高 |
| 博识学会 | 资助关系，公司出钱，学会出人 |
| 反物质军团 | 敌对，但公司的应对以「止损」为主，不主动开战 |


## 二相乐园与千星城

4.0 起，战略投资部的真珠接任二相乐园首席执行官，手握三张「欢愉假面」。

公司用朋克洛德的以太编辑技术把画中世界打捞回现实，又在千星城用职级制度管理高层员工。真珠在 4.6—4.7 维持愿力循环，并打通二相乐园与千星城的通路。
