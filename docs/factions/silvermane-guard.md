# 银鬃铁卫

贝洛伯格的官方武装。他们的名字出现在每一份阵亡名单上，也出现在每一道被放弃的防线上。

## 基本信息

| 项目 | 内容 |
|------|------|
| 外文名 | Silvermane Guard |
| 性质 | 贝洛伯格官方武装 |
| 职责 | 城防、清剿裂界造物、维持治安 |
| 已知兵种 | 银鬃近卫、银鬃射手、银鬃炮手、银鬃尉官 |
| 效忠对象 | 大守护者 |
| 关联地点 | 贝洛伯格 |

## 一支被写进绝境里的军队

贝洛伯格的军事结构不是为进攻设计的，是为拖延设计的。永冬封住了地表，裂界在城市外围不断生成敌人，铁卫的任务是守住城墙、清出通道、把裂界的推进速度压到城市还能喘气的程度。

这意味着三件事：

1. **他们打的是一场不会赢的仗**。裂界清完还会再长，铁卫的胜利只是「今天还在」。
2. **他们的资源永远不够**。可可利亚把大量资源投入对裂界的战事，代价是下层区被放弃——这是铁卫必须背负的账。
3. **他们的忠诚是向职位而非向人**。铁卫效忠大守护者，但当大守护者的决定危及城市本身时，个人必须自己选边。

## 兵种

| 兵种 | 定位 |
|------|------|
| 银鬃近卫 | 近战主力，持盾推进 |
| 银鬃射手 | 远程压制 |
| 银鬃炮手 | 重火力，对付大型造物 |
| 银鬃尉官 | 指挥单位，率队清剿 |

模拟宇宙里还有「银鬃尉官（完整）」「银鬃尉官（错误）」等变体——被演算重构过的铁卫，攻击逻辑与本体不同。

## 三个人，三种立场

| 人物 | 位置 | 选择 |
|------|------|------|
| **布洛妮娅** | 戍卫官、继承人 | 第一次领兵就失去一名替她挡刀的列兵；后来站到母亲对面 |
| **杰帕德** | 城防负责人 | 忠于职守，不讲政治。他的盾是给城市用的，不是给某个人用的 |
| **佩拉** | 情报与文书 | 用记录与情报支撑决策，是铁卫里最像参谋的人 |

## 与地火的关系

两套系统并行：铁卫守城门，地火守街巷。官方从不承认地火的合法性，但铁卫的基层知道，下层区如果塌了，城墙也守不住。

这种默契在 1.0 之后变成了合作——布洛妮娅需要一个能落地执行的基层组织，地火需要有人在上层签字。

## 与可可利亚

铁卫效忠大守护者，可可利亚也确实带着他们打了十几年。问题出在她引入星核之后：当守护者本人成为城市最大的风险，铁卫的忠诚就失去了对象。

终局里，铁卫没有集体倒戈，也没有集体效忠——他们各自做了选择。这比任何一方全军出击都更真实。
