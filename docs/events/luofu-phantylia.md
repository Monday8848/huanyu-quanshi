# 幻胧之乱

::: tip 名称说明
「幻胧之乱」是本站为便于索引所拟的概括性名称，不是官方章节标题。官方将该段剧情分布在 1.2 版本「仙骸有终」与 1.3 版本「天镜映劫尘」两个开拓任务章节中。
:::

## 概述

| 项目 | 内容 |
|------|------|
| 时间 | 1.2–1.3 版本（2023 年 7 月–9 月） |
| 地点 | 仙舟罗浮（丹鼎司、鳞渊境） |
| 官方章节 | 1.2 系列「云树百丈蔽重楼」→ 1.3 系列「劫波渡尽战云收」 |
| 主要参与方 | 星穹列车、仙舟联盟、星核猎手、绝灭大君幻胧 |
| 结果 | 幻胧被击退，星核被封印；停云生死未卜 |

## 背景

绝灭大君幻胧是毁灭星神纳努克的令使之一。它的行动方式不是正面进攻，而是渗透：寄生、替换、挑动。

数千年前，持明族以鳞渊境洞天为容器，封印了建木的玄根。星核猎手把一枚星核送入仙舟——将星核带入仙舟并启动的另有其人，这其中既有内忧，也有外患。枯朽死灭的神木开始重新生长，而星核猎手将列车组引至仙舟的用意，也在此刻崭露。

## 停云的空缺

幻胧以停云的样貌混入仙舟，掀起灾祸、荼毒众生。真正的停云在乱局中遇害——她样貌、名字、身份皆被人夺去。

没有人察觉这具「停云」是空的。八面玲珑的狐人少女成为这场灾祸最完美的伪装，直到幻胧亮出真身。

## 不死的神实

幻胧的最终形态「不死神实•幻胧」，是自建木中生成的躯壳——兼具「毁灭」与「丰饶」之力、生灭循环的肉体，也是建木复生后结出的第一颗「果实」。

它攫取建木的力量为己所用，用赐予仙舟长生的力量带来「毁灭」：操纵藤萝囚笼困住众人、召唤陨星碾压、豢养幻花。在决战中，它宣布下一步计划——把仙舟将军变成一名虚卒，让「毁灭」的力量侵蚀其血肉，铸成纳努克的棋子，看看罗浮会不会再来一次内乱。

## 决战

景元正面对抗幻胧，请丹恒照看自己的后背。幻胧试图将「毁灭」之力注入景元的身体——就在此时，丹恒拿枪刺向景元，这一枪重创了与景元紧密连接的幻胧，切断了她和建木的联结。

景元补上最后一击：「毁灭的小卒子。告诉军团：『巡猎』的复仇，必将来临。」

战后，瓦尔特判断幻胧短时间内无力兴风作浪，但封印星核的工作还需要时日——这些事留给了符玄。

## 结果与影响

- 幻胧被击败，其「随手捏制的肉身」被毁，本体暂退；建木星核被封印。
- 丹恒的「不朽」龙裔身份在众目睽睽下公开。
- 停云之死成为罗浮朝野的定论——直到 2.7，阮•梅救下的「忘归人」归来，人们才知道幻胧夺走的不只是她的性命，还有她的一段人生。幻胧对她意志的折磨，也并未随肉身的胜利而结束。
- 仙舟联盟对「令使级渗透」的防御漏洞被暴露。

## 后续

幻胧之乱结束得很干脆，但它留下的问题没有结束。

一个令使能渗透到这程度，说明仙舟的防线并非无懈可击；而在 3.7，幻胧的箴言出现在翁法罗斯的囚室里——「一位同僚的加冕或陨落，真有那么重要？我期盼的，是『开拓』带来的：一、出、好、戏。」
