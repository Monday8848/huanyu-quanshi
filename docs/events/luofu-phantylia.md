# 幻胧之乱

::: tip 名称说明
「幻胧之乱」是本站为便于索引所拟的概括性名称，不是官方章节标题。官方将该段剧情分布在 1.2 至 1.3 两个版本中。
:::

## 概述

| 项目 | 内容 |
|------|------|
| 时间 | 1.2–1.3 版本 |
| 地点 | 仙舟罗浮 |
| 主要参与方 | 星穹列车、仙舟联盟、绝灭大君幻胧 |
| 结果 | 幻胧被击败，罗浮秩序恢复，内部裂痕被暴露 |

## 背景

绝灭大君幻胧是毁灭星神纳努克的令使之一。它的行动方式不是正面进攻，而是渗透：寄生、替换、挑动。

罗浮是仙舟联盟中对外的窗口，人员往来复杂，防线上天然有缝隙。幻胧选择了这里。

## 经过

幻胧寄生并替换了罗浮的关键人物，以对方的身份活动，逐步操纵局势。

它没有直接引爆战争，而是让罗浮自己走向内乱：制造误判、激化矛盾、让不同机构互相怀疑。等罗浮反应过来时，问题的性质已经从「外敌入侵」变成了「不知道还能信谁」。

列车组在此期间停靠罗浮。丹恒被迫直面自己的过去，饮月君的传承被重新唤醒；云骑军与十王司在混乱中各自行动；而幻胧真正的目的，直到最后才被看清。

## 结果与影响

- 幻胧被击败，罗浮的秩序恢复。
- 丹恒的身份公开，与刃的旧怨被摆上台面。
- 仙舟联盟对「令使级渗透」的防御漏洞被暴露。
- 罗浮与星穹列车的关系进一步加深。

## 后续

幻胧之乱结束得很干脆，但它留下的问题没有结束。

一个令使能渗透到这程度，说明仙舟的防线并非无懈可击；而被寄生者留下的空白，也不是一句「已经解决」就能填上的。
