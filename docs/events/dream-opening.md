# 记忆是梦的开场白

> 你在匹诺康尼与众人告别时，曾有一些记忆遭到焚毁。在大丽花的帮助下，你开始寻回失却的记忆。
>
> ——3.8 版本主线系列任务官方简介

## 过程

### 流萤潜入

在银狼的帮助下，流萤从原始忆域潜入了匹诺康尼的梦境。据银狼所说，家族拥有一个在匹诺康尼近乎全知全能的情报网络——想要无声无息地进入梦境，必须避开它的耳目。

### 太一之梦的余波

在被星期日卷入太一之梦后，你在黑天鹅的帮助下苏醒，并与其他同伴会合。黑天鹅向你讲述了太一之梦足有三层构造——匹诺康尼的「美梦」从未真正结束，只是换了形式继续。

### 遭遇「死亡」

遭遇忆域迷因「死亡」，并与开拓者失散后，流萤并未返回现实，而是见到了星核猎手的合作者——焚化工「大丽花」。焚化工能够焚烧并保管记忆，这份能力正是解开一切谜团的钥匙。

### 被焚毁的记忆

你在匹诺康尼与众人告别时，曾有一些记忆遭到焚毁。大丽花独自来到列车，在意识的领域引导你恢复匹诺康尼的记忆。在每一段回忆结束后，她都会试着为你拼合那段被抹去的时间。

### 知更鸟的调查与死亡

在迎接你入梦后，知更鸟尝试调查梦境中的「不协和音」，发觉其源头在流萤身上——此时对方被认为是偷渡犯，正被通缉。被花火杀死后，知更鸟到达了流梦礁，并在米凯的帮助下熟悉了这里——死亡在匹诺康尼的梦中，不是终点。

### 橡木之梦的律令

按照花火的提示，流萤独自来到了橡木之梦，与梦主留下的「律令」之一相遇，与其一同调查梦主的阴谋。这条线与同期爆发的 [橡木鸣蛀之梦](/events/oak-borer-dream) 灾变合流。

### 终将实现的

记忆寻回的尽头，你找到了流萤——以及那段被焚烧的时间的真正意义。有些愿望被偷偷保存了下来，等待实现的时机。
