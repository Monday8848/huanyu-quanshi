# 明霄竞武试锋芒

> 群狼环伺，猎手挽弓。高天之上，竞锋舰中，罗浮仙舟的演武仪典即将展开血之角逐……

## 过程

### 故客重游

在尚未踏入下一站旅程前，列车接到了来自罗浮仙舟的通讯——景元向暂无去向的众人发出邀请，参加演武仪典。不同世界的宾客纷至沓来，但他们所瞩目的并不只有演武本身。

### 三月七得剑

在怀炎半是玩笑、半是试探的邀请下，三月七意外得到了登上演武仪典的机会——受学于罗浮与朱明两大将军的高足，有机会一窥仙舟剑术的堂奥。「授剑传行，腾然流星」，三月七的仙舟剑术修行自此开始。

### 呼雷脱困

演武仪典进行中，「潜迹狼烽，兽骇鸟惊」——被判囚的大敌呼雷趁乱潜逃，仙舟各舰戒备。天击将军飞霄调度云骑展开对呼雷的追猎：「围三阙一」，这是猎人的战术。但在潜伏的呼雷看来，猎人又何尝不是一种猎物。

### 椒丘入狼爪

落入呼雷狼爪，椒丘犹如俎上块肉，在劫难逃。除却自保之外，他仍有想要从呼雷身上获得的答案。

### 竞武云巅

竞武云巅，孺子问剑——三月七的演武在追猎战的阴影下如期展开。「敛魂血轮，率兽食人」的呼雷节节败退，最终「解裂残躯，独狼负隅」，被「挽澜扶危，舍我其谁」的飞霄与诸将合力镇伏。「欃枪烈烈，心兽灭却；射浪偃潮，旧恨云消」——呼雷之乱平息。

### 玉阙黄钟

终章「玉阙黄钟，天外归鸿」：演武仪典落幕，仙舟各舰重归安宁，这场盛会也在仙舟的编年史中记下了一笔。
