# 橡木鸣蛀之梦

> 时间在灰烬中等待苏醒——去拨转命运的指针吧。

| 项目 | 内容 |

| 结果 | 蝗灾被阻止，太一未复生 |

## 梦主的计划

梦主没有肉身。他在不久之前，把自己的意识也彻底杀死，化成四条功能各异的「律令」。

他要做的，是在美梦中再造寰宇蝗灾：让入梦者在混乱中渴求秩序，借此复活星神太一。

## 流萤的愿望

梦主知道格拉默铁骑行于「繁育」命途，也深知星核的本质。

他营造出「死灭之茧」的假象，诱使流萤在星核面前许下「想要活下去」的愿望。星核把愿望扭曲地实现——寰宇蝗灾在梦境中诞生。

## 大丽花

大丽花以星核猎手合作者的身份接近流萤，又暗中替梦主办事。

她与黑天鹅交手，又把黑天鹅带进橡木鸣蛀之梦。两人心照不宣，借交手烧掉梦主种在她身上的「律令」。

## 结局

蝗灾被阻止，星期日没有扬升为太一。

大丽花替开拓者找回被焚毁的记忆，然后在结局独自离开。她说，希望还能再见。
