# 橡木鸣蛀之梦

> 时间在灰烬中等待苏醒——去拨转命运的指针吧。

## 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 3.8 版本 |
| 地点 | 匹诺康尼·流梦礁 |
| 关键人物 | 梦主、大丽花、流萤、黑天鹅、知更鸟、砂金、星期日 |
| 结果 | 蝗灾被阻止，星期日未扬升为太一 |

## 梦主

梦主没有肉身。他在不久之前，把自己的意识也彻底杀死，化作**四条功能各异的「律令」**，以此完成最终计划——于美梦中再造寰宇蝗灾。

他的动机链条：很久以前，梦主曾从家族特使处得知星核的真相；又从历史得知——由于人们会在混乱中渴求秩序，「秩序」命途曾在寰宇蝗灾肆虐时**反倒达到鼎盛**。于是他要再造一场蝗灾，让入梦者在混乱中呼唤秩序，借此复生星神太一。梦主还认定：作为首选者，星期日将会因此扬升为太一。

## 星核猎手线

流萤与知更鸟的追查是本线主轴：

- 被花火杀死后，知更鸟到达流梦礁，在米凯的帮助下熟悉了这里；流萤将她邀至星核猎手隐秘据点——考虑到梦境中确实存在不谐和音，两方暂时合作；
- 大丽花展示从忆域打捞的历史：**AR-214 正是被梦主亲手加害**，据他所说，这是为了用「繁育」的力量造就乐园；
- 黑天鹅赶到，揭晓大丽花的真实身份：**她并非星核猎手，而是梦主的合作者**，一直在梦境中借助忆者的能力伪装成各势力的同伴；
- 大丽花先一步在知更鸟的意识中种下焚化工的火苗，使她遗忘这段经历——但她随即与黑天鹅演了一出双簧：两人的交手正是大丽花借机烧毁身上「律令」的戏码。因为在匹诺康尼，梦主通过律令分享力量，使她远比过去强大，只有以焚化工的技艺自焚，才能挣脱禁制。

## 流萤线

按照花火的提示，流萤独自来到橡木之梦，与梦主留下的「律令」之一同行调查。在道路尽头，她发现了正在孕育寰宇蝗灾的「死灭之茧」——这颗「死灭之茧」曾捏造出一张悬垂的丝网，如愿诱捕到了寻觅而至的飞萤。

梦主的最后一环是：四条律令的其中之一是他的至强一击，足以使茧中蝗灾提前破壳。流萤决心独自挡下这一击——**但这正中梦主的算计**：茧中只有一颗星核而已。

梦主深知星核的本质，也知晓格拉默铁骑行于「繁育」命途、与虫群的力量共生同死。此前种种都是假象，真正的目的是：**诱使流萤在星核面前许下「想要活下去」的愿望**。星核将愿望以极其扭曲的形式实现——寰宇蝗灾在梦境中诞生。

## 其他视角

- **砂金**：在迎来死亡后，因无名客拉扎莉娜的遗产进入了橡木鸣蛀之梦；理清梦主的阴谋后，他在银枝的帮助下离开，向公司传递情报并进行下一步布置。
- **列车组**：在见证米哈伊尔一生的同时，流萤因并非行于「开拓」未能同行——这条缺席的注脚，正是梦主选中她的原因。

## 结局

蝗灾被阻止，星期日没有扬升为太一。大丽花替开拓者找回被焚毁的记忆，然后在结局独自离开——她说，希望还能再见。
