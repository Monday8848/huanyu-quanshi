# 血涂游戏

> 你哭泣的样子，真像个笑话。

## 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 乐园历 1984 年 |
| 地点 | 绘世学院、鸽川区 |
| 凶手 | 告死魔 |
| 伤亡 | 146 人死伤 |
| 相关人物 | 满愿、姬子、不死途 |

## 惨案

乐园历 1984 年 7 月 22 日，一名谒者进入绘世学院。

他杀害了准备校庆的 22 名学生，随后向鸽川区行进，共计造成 146 名无辜市民死伤。媒体称他为「告死魔」，称那届幻月游戏为「血涂游戏」。

## 满愿

满愿躲在柜子里，亲眼看见同学被当作颜料涂在墙上。

有人打开柜子，递给她一个小木匣——她的双亲就在里头。后来她走出柜子，却发现一切都是一档实境秀：二相乐园是娱乐至死的社会，电视台要播「告死魔受害者走出阴霾」。

她成了大明星，也成了电视台的盈利工具。真相被记者说漏嘴后，她收到一张愚者面具，上面写着：「你哭泣的样子，真像个笑话。」

## 姬子

姬子是告死魔事件的幸存者，有同学在事件中遇难。

她后来修复了坠毁的星穹列车，成为领航员。这件事她很少提，但 4.4 中，归寂把它翻了出来。

## 余波

乐园历 1994 年 7 月 22 日，异常防御部宣布对「告死魔」执行死刑。

十五年后，共愿帮总部出现同样手法的惨案。血涂游戏没有结束，它只是换了一个舞台。
