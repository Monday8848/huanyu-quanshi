# 匹诺康尼危机

::: tip 名称说明
「匹诺康尼危机」是本站为便于索引所拟的概括性名称。官方第三幕系列任务分布在 2.0 至 2.3 四个版本：**喧哗与骚动** → **鸽群中的猫** → **在我们的时代里** → **再见，匹诺康尼**。
:::

| 项目 | 内容 |

## 喧哗与骚动（2.0）

> 「梦想之地」匹诺康尼，无数逐梦客梦寐以求的享乐主义天堂——准备好加入「钟表匠」的盛宴了吗？

家族借「谐乐大典」向全银河发出邀请。星穹列车受已故「钟表匠」米哈伊尔遗产的牵引抵达，入住[白日梦酒店](/locations/dreamjolt-hotel)红心十二区。

梦境里接连发生「死亡」事件，但不符合现实规则——本该死去的人重新出现，记忆被篡改，连「死亡」的定义都变得可疑。[砂金](/characters/aventurine)以公司代表身份登场，公开身份是宾客，实际任务是处理公司搁置已久的产权纠纷；[流萤](/characters/firefly)以「萨姆」的机甲形态几次出手，又在闭幕后以少女的样貌与开拓者约定「白日梦酒店的日出」——随后「死」在了梦境的钟摆之下。

## 鸽群中的猫（2.1）

> 两起凶案揭示了「不可能之事」的关键，两位无意争夺遗产的来宾也将意外揭晓「钟表匠」之谜……

「钟表匠」遗产成为全场赌局。猎犬家系治安官[加拉赫](/characters/gallagher)在凶案之间穿针引线；[黄泉](/characters/acheron)以「巡海游侠」名义行走梦中，在「行过死荫之地」里与砂金对赌——砂金让开拓者引爆体内的星核，在梦境中制造一场盛大的死亡，以此给公司介入的理由。他赢了每一把牌，最终死在了自己的赌局里。

## 在我们的时代里（2.2）

> 宴会已近尾声，我们奋力前进，却如同逆水行舟，注定要不停地随浪潮退入过去。

梦境的层数向下坍塌，时间开始倒流。真相在更深处：橡木家系十万七千三百三十六名成员早已背弃[希佩](/concepts/aeon-xype)，暗中信奉被吞并的[太一](/concepts/aeon-ena)；梦主歌斐木把自身化作四条「太初律令」，其中一条正是当年点拨[知更鸟](/characters/robin)的临别赠礼。

加拉赫把米哈伊尔的遗愿带到——他是钟表匠笔下写出的「虚构人物」，任务完成便向列车组告别。谐乐大典上，时任橡木家主的[星期日](/characters/sunday)召唤出「谐乐众弦」之一「齐响诗班」众愿之多米尼克斯，「秩序」的力量使其展现出不同以往的面貌。列车组在梦境最深处击碎了这场「无梦的梦」。

## 再见，匹诺康尼（2.3）

> 美梦舞台的最后安可就要奏响，众人也回到故事起点，奔赴各自的下一站……

「齐响诗班」被阻止，星期日没有扬升为太一。橡木家系倒台，猎犬家系接管追捕；美梦重开——如今「死亡」已并非不可能之事。列车组在白日梦酒店再赴日出之约，随后启程。

2.7 的「在第八日启程」回到匹诺康尼：有人将会归来，有人正欲离去——若想看清前路，必当回望往昔。

## 结果与影响

- 橡木家系失势，家族权力结构重组；「秩序」的暗流被公开。
- 匹诺康尼的梦境规则被改写，梦境居民与宾客的关系出现新的可能。
- 公司与家族的产权纠纷暂时没有解决，只是被推迟。
- 歌斐木的四条律令没有全部消散——3.8 的「橡木鸣蛀之梦」证明，他在梦里留下的东西仍在等待苏醒。
