## 收录标准

- **收**：有独立场景、多个势力参与、改变某个地区格局的主线章节级事件。
- **不收**：角色个人支线、活动剧情，信息并入相关人物或地点条目。
- 历史事件如果只有零散文本记载，条目会明确标注「官方记载有限」。
