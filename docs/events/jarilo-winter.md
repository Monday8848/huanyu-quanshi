# 雅利洛-VI 永冬

::: tip 名称说明
「雅利洛-VI 永冬」是本站为便于索引所拟的概括性名称。官方第一幕系列任务为**「于枯索的冬夜里」**与**「于曈昽的骄阳下」**两部分。
:::

## 开拓之道

> 「探索」、「了解」、「建立」、「连结」——这就是无名客一直以来贯彻的「开拓」之道。

作为列车组新成员，开拓者的第一个目的地名叫雅利洛-VI：一颗被冰雪覆盖的星球。轨道影像里看不到城市，只有一道横贯冰原的巨大围墙——贝洛伯格，雅利洛-VI 仅存的城市。

## 死结

星核降临后，星球气候系统崩溃，地表冰封，文明收缩进这座城市。贝洛伯格的供暖依靠被封在炉心的星核——这形成了一个死结：星核正在杀死这颗星球，而离开星核，所有人会立刻冻死。

大守护者[可可利亚](/characters/cocolia)的选择是把星核的力量请进城市——敌方档案称她为「祂所承诺的『新世界』的代言人」。这个计划表面上是为了城市，实际上是把整座城市的命运交给了星核；被放弃的下层区，则在裂界的侵蚀中自生自灭。

## 上下层

列车组抵达时，这座城市被一道封闭的通道切成两半：

- **上层区**：银鬃铁卫的防区，秩序井然，每个人都相信「寒潮终会过去」的官方叙事。
- **下层区**：被上层放弃的世界，由地火维持秩序，娜塔莎的诊所是那里唯一的暖光。

在[史瓦罗](/characters/swarog)设置的牢笼里，下层区的人们被「保护」了几十年。列车组的介入打破了僵局：下层区的人们挣脱了牢笼，为了「存护」贝洛伯格的自由，也为了列车的星辰之旅能够继续，所有人回到上层，向这个世界的统治者宣战。

## 决战

可可利亚的计划被摊开在所有人面前时，她已经被星核同化——「虚妄之母」降临在核心区域。这场战斗的对手不是一位大守护者，而是星核借她的身体说出的话：冻结、毁灭、重新开始。

可可利亚被击败，星核被取出，贝洛伯格迎来了十几年里第一个没有星核的冬天。

## 结果与影响

- 星核危机解除，供暖系统开始改造，永冬出现终结的可能。
- [布洛妮娅](/characters/bronya)接任大守护者，承诺重新打通上下层区。
- 下层区的地位被正式承认，地火从地下组织变成谈判桌上的一方。
- 列车组与贝洛伯格建立长期联系。

## 后续

永冬没有在一夜之间结束。星核取走之后，气候恢复需要时间，城市重建需要资源，上下层区的和解更需要耐心。贝洛伯格的故事没有停在胜利那一刻——这也是它比其他主线更耐看的地方。
