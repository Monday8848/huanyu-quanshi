# 雅利洛-VI 永冬

::: tip 名称说明
「雅利洛-VI 永冬」是本站为便于索引所拟的概括性名称，不是官方章节标题。
:::

## 概述

| 项目 | 内容 |
|------|------|
| 时间 | 1.0 版本 |
| 地点 | 雅利洛-VI、贝洛伯格 |
| 主要参与方 | 星穹列车、贝洛伯格、银鬃铁卫、下层区 |
| 结果 | 星核被取出，贝洛伯格开始重建，永冬出现终结的可能 |

## 背景

星核降临雅利洛-VI 后，星球气候系统崩溃，地表冰封，文明收缩到唯一还能供暖的城市贝洛伯格。

贝洛伯格的供暖依靠被封在炉心的星核。这让整座城市陷入一个死结：星核正在杀死这颗星球，而离开星核，所有人会立刻冻死。

## 经过

列车组抵达时，贝洛伯格正处在大守护者可可利亚的统治下。

可可利亚与星核做了交易，试图用全城人的记忆换取一个「永远安稳」的未来。这个计划在表面上是为了城市，实际上是把整座城市的命运交给了星核。

列车组介入后，局势迅速恶化：上层区与下层区的矛盾被引爆，银鬃铁卫内部出现分裂，可可利亚的计划被摊开在所有人面前。

最终的战斗发生在星核所在的核心区域。可可利亚被击败，星核被取出，贝洛伯格迎来了十几年里第一个没有星核的冬天。

## 结果与影响

- 星核危机解除，供暖系统开始改造。
- 布洛妮娅接任大守护者，承诺重新打通上下层区。
- 下层区的地位被正式承认，地火从地下组织变成谈判桌上的一方。
- 列车组与贝洛伯格建立长期联系。

## 后续

永冬没有在一夜之间结束。星核取走之后，气候恢复需要时间，城市重建需要资源，上下层区的和解更需要耐心。

贝洛伯格的故事没有停在胜利那一刻，这也是它比其他主线更耐看的地方。
