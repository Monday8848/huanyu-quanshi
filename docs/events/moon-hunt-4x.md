# 新一届幻月游戏

> 这场星神游戏，赌注是整个乐园。

## 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 4.0—4.7 版本 |
| 地点 | 二相乐园、千星城 |
| 谒者 | 开拓者、星期日、火花、满愿、归寂等 |
| 结果 | 贪饕被镇伏，阿哈重生 |

## 开幕

4.0，星穹列车婉拒翡翠的结盟邀请，驶向姬子的故乡二相乐园补给。

幻月满盈，新一届幻月游戏开幕。真珠手握三张面具，火花抢先「唱名」，爻光把面具授予星期日，开拓者从绯英手中接过浣熊面具。

## 中段

4.1，珠星大厦与观览云岛成为机铠与漫展的战场，不死途加入游戏维持秩序。

4.2，满愿以「幸福语法」操纵海原市，激活体内的倏忽细胞。刃把倏忽血肉吸进自己体内，银狼修改现实参数，将其压缩。

4.3，渡画泉隐揭开绘世的过去；4.4，归寂以谒者身份参赛，把二相乐园变成末日妖都。

## 归寂

归寂杀害姬子之父无量塔隆介，假扮他数十年。

4.4 中，姬子直面他，列车合力将他击败。但他没有彻底消亡，4.7 再度现身，宣称阿哈早已死亡。

## 钓猎贪饕

4.6，虚照在千星城生研院寻找饵料，亚婆离因过量古兽源质堕落为疯兽，被合力击败。

4.7，虚照在点星船公布三步计划，八位谒者钓猎「贪饕」。归寂推动「欢愉」与「贪饕」融合，催生「哲学的胎儿」。

虚照与谒者施展「神的四个魔术」，汇聚寰宇众生的愿力，镇伏贪饕，促成阿哈重生。

## 尾声

星穹列车前往千星城，出席「反毁灭同盟」发布会。

开拓者以「阿基维利」之名向全银河发出同盟号召。乐园的假期结束，更大的棋局开始。
