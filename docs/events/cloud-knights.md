# 云上五骁旧事

::: tip 名称说明
「云上五骁旧事」是本站为便于索引所拟的概括性名称。官方相关信息分散在角色故事、遗器文案与剧情对话中，没有集中的章节讲述。
:::

## 概述

| 项目 | 内容 |
|------|------|
| 时间 | 数百年前（罗浮纪年不详） |
| 地点 | 仙舟罗浮 |
| 主要人物 | 丹枫（饮月君）、镜流、应星、白珩、景元 |
| 结果 | 五人分道扬镳，丹枫与应星身死或转生，镜流堕入魔阴，景元独守罗浮 |

## 五个人

云上五骁是罗浮历史上最出名的一组人物：五位实力顶尖的战士，在一场又一场战事里并肩作战，被并称为「五骁」。

- **丹枫**：持明族的饮月君，龙尊，五人中身份最特殊的一个。
- **镜流**：剑术通神，被称为「剑首」。
- **应星**：短生种工匠，擅长锻造，与丹枫关系最近。
- **白珩**：狐人，五人中的调和者。
- **景元**：五人中最年轻的一个，后来成为罗浮的将军。

## 裂痕

五人的关系不是在一场战斗里破裂的，而是在一系列选择中慢慢磨掉的。

核心矛盾围绕「长生」与「代价」展开：丹枫试图用持明族的力量做一件超出界限的事，应星参与其中，镜流反对，白珩试图调和，景元选择了立场。

这件事的后果极其惨烈：丹枫与应星付出了生命的代价（前者以转生收场，后者下落成谜），镜流堕入魔阴，白珩死去，只有景元留了下来，守着罗浮和这段没人愿意再提的历史。

## 余波

数百年后，五人的转世、残念与债务陆续回到罗浮：

- 丹恒作为丹枫的转世，被迫承接饮月君的传承与罪名。
- 刃（应星）以不死之身归来，追着丹恒讨一笔旧账。
- 镜流以另一种形态重现，与景元、刃之间的关系依旧尖锐。

## 为什么重要

云上五骁旧事是理解罗浮的钥匙。

它解释了丹恒为什么回避过去、刃为什么执着于复仇、景元为什么对所有人都保持一种疲惫的宽容，也解释了仙舟社会对「长生」的警惕——五骁的悲剧，本质上是一群强者试图突破界限，最后被界限反噬的故事。

## 未解之处

官方对这段历史的叙述始终是碎片化的。谁对谁错、丹枫当年究竟想做什么、应星的结局到底是什么，都没有完整答案。

玩家中较有影响力的一种推测是：五骁的分裂不只是理念之争，还牵扯到丰饶与巡猎的规则冲突。这个说法能解释部分细节，但目前仍属推测。
