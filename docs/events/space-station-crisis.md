# 空间站危机

::: tip 名称说明
「空间站危机」是本站为便于索引所拟的概括性名称。官方序幕系列任务名为**「今天是昨天的明天」**。
:::

## 开场

> 系统时间 23 时 44 分 59 秒，一个陌生的女人来到空间站「黑塔」……

序幕的官方描述只有这一句。这个「陌生的女人」是[卡芙卡](/characters/kafka)——星核猎手成员、天衣五的猎人。她和骇客银狼突入空间站，是为了送来一样东西：一名体内嵌着星核的「实验体」，也就是后来被称为「开拓者」的人。

## 各方入场

- **星核猎手**：以「夺取星核」为业的小规模组织，其目的不为外人所知。星际和平公司的通缉令上写着：「刃、银狼、萨姆……以上四人，死活不论；不得伤害『命运的奴隶』，或使其失去自主思考能力。」——所谓「命运的奴隶」，正是这具装着星核的身体。艾利欧的剧本要它保持完整、保持清醒。
- **反物质军团**：毁灭的徒众紧随其后涌入空间站。对军团而言，空间站的价值只有一个：它足够重要，毁掉它能造成足够大的影响。
- **星穹列车**：停靠在空间站附近。姬子决定介入，瓦尔特、丹恒、三月七先后进入空间站。战斗的核心不是消灭军团——那不可能——而是拖住它们，让空间站的人撤出去。
- **空间站方**：名义站长艾丝妲组织科员撤离。这位出身名门的大小姐在危机后与列车组结下情谊，成为空间站与列车之间的联络人。

## 开拓者苏醒

星核在混乱中苏醒。开拓者睁开眼时，收容区失控、舱段损毁，局势已滑向不可收拾。

在列车的掩护下，开拓者穿过沦陷的舱段，最终站到命运的岔路口——选择「毁灭」或「存护」的命途。这是开拓者故事真正的起点。

## 结果与影响

- 军团被击退，空间站保住了主体结构，但损伤严重。
- 开拓者加入星穹列车，获得第一张星穹列车的「车票」。
- 星核猎手的目的达成——「命运的奴隶」完好无损地醒了过来。这场危机的真正剧本，要到很久之后才被翻开。
- 空间站的星核收藏（包括模拟宇宙的关联实验）在这场危机后进入黑塔视野，成为后续诸多事件的暗线。
