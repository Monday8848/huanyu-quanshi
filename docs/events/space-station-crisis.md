# 空间站危机

::: tip 名称说明
「空间站危机」是本站为便于索引所拟的概括性名称，不是官方章节标题。官方将该段剧情作为 1.0 版本的主线开端。
:::

## 概述

| 项目 | 内容 |
|------|------|
| 时间 | 1.0 版本 |
| 地点 | 黑塔空间站 |
| 主要参与方 | 星穹列车、反物质军团、黑塔空间站 |
| 结果 | 军团被击退；开拓者苏醒并加入列车组 |

## 背景

黑塔空间站的收容舱段存放着大量危险造物，其中也包括一个被植入星核的实验体。

空间站的安保等级很高，但反物质军团的入侵方式绕过了大部分防线——它们不是来抢夺，而是来破坏的。对军团而言，空间站的价值只有一个：它足够重要，毁掉它能造成足够大的影响。

## 经过

军团入侵后，空间站迅速失守。收容区失控、舱段损毁、人员撤离，局势在很短时间内滑向不可收拾。

与此同时，那名实验体苏醒了。

列车组此时停靠在空间站附近，姬子决定介入。瓦尔特、丹恒、三月七先后进入空间站，与军团正面交手。战斗的核心不是消灭军团——那不可能——而是拖住它们，让空间站的人撤出去。

## 结果与影响

- 军团被击退，空间站保住了主体结构，但损伤严重。
- 开拓者被列车组带走，成为无名客。
- 星核的存在被确认，成为后续一系列事件的引线。
- 星穹列车与军团之间结下了第一次正面冲突。

## 后续

空间站危机是整个故事的起点，也是很多线索的埋设点：星核为什么会出现在实验体体内、卡芙卡为什么要把星核植入一个没有过去的人、军团为什么选择在这个时候入侵。

这些问题在当时都没有答案，之后的旅程才一点点把它们摊开。
