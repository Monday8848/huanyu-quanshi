# 狐斋志异

> 洪炉破碎，岁阳逃逸，罗浮仙舟上十王司判官们行动起来。今夜，被遗弃许久的废园里妖氛弥漫，却有两位陌客不请自来。
>

## 过程

洪炉破碎，囚于炉中的岁阳逃逸，罗浮妖氛骤起。十王司判官行动起来缉拿妖异——而列车组以「不请自来的陌客」身份卷入其中。

### 绥园聚首

夜半的绥园，判官与列车组结成临时的「缉妖小队」。他们手中先扣留了一名岁阳犯人，并决定充分利用——争取将它转作污点证人，为缉妖行动提供情报。

### 诸妖异闻

废园中的妖异接连现形：

- **双生**——一体两魂的岁阳异类；
- **剑精**——「云骑失控」的求助帖把众人引到丹鼎司：若非堕入魔阴身，便是有岁阳妖异作乱，一柄不肯认主的剑在此成精；
- **犀照**——燃犀照渊，照见的是人心里的旧影；
- **狐梦**——散场之前，最难醒的是执念编织的梦。

（各妖异的具体收服经过详见游戏内对应章节。）

### 终章·狐梦

缉妖收官，绥园的妖氛散去。岁阳一一归案，废园的故事以一场「狐梦」收束——志异之笔，写的终究是人。
