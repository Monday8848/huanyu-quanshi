# 音律狩猎忍法帖

> 音律盛典暗藏祸害，缭乱•忍侠坐镇演台——狩猎再开！乐队演出即将启幕，超绝精彩！；折纸大学的校庆正在进行中，其中最为盛大的活动——「音乐派对」即将开启。经由知更鸟引荐，你成为了舞台演出乐队的经理，而乐队的核心位置将由乱破担任。召集你的乐队成员，共同享受这场音乐庆典吧！；首场演出顺利结束，现场观众对乐队的热情高涨——稍作休息，继续为第二场演出做准备吧！

## 音律狩猎•前序

> 折纸大学的校庆正在进行中，其中最为盛大的活动——「音乐派对」即将开启。经由知更鸟引荐，你成为了舞台演出乐队的经理，而乐队的核心位置将由乱破担任。召集你的乐队成员，共同享受这场音乐庆典吧！

## 音律狩猎•起始篇

> 首场演出顺利结束，现场观众对乐队的热情高涨——稍作休息，继续为第二场演出做准备吧！
