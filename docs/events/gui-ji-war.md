# 归寂之战

> 哀切的鸣笛响彻，唯有开拓之人才能寻得跨越死境的生路。

## 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 4.4—4.7 版本 |
| 地点 | 二相乐园、千星城 |
| 对手 | 绝灭大君「归寂」 |
| 结果 | 归寂败退，贪饕被镇伏 |

## 末日妖都

4.4，归寂以谒者身份加入幻月游戏。

他把二相乐园变成末日妖都，作为自己宣扬的「奇迹」。哀切的鸣笛响彻，废墟成为舞台，死者成为观众。

## 姬子

归寂杀害姬子的父亲无量塔隆介，假扮他数十年。

在末日妖都，姬子直面他。她早就知道父亲被调包，却没算到最坏的可能：那个「父亲」，真实身份是绝灭大君。

## 败退

列车组赶来支援，姬子试图以牺牲捍卫列车逃离的可能。

星核回应了开拓者「延续开拓之路」的愿望，让一切回到无法挽回之前。众人合力击败归寂。

## 未结束

归寂没有彻底消亡。大地深处，被封印许久的「贪饕」兽蜕正在苏醒。

4.6，千星城生研院成为新的战场；4.7，归寂再度现身，宣称阿哈早已死亡，并推动「欢愉」与「贪饕」融合。

最终，虚照与谒者们用「神的四个魔术」镇伏贪饕，促成阿哈重生，归寂的证明失败。
