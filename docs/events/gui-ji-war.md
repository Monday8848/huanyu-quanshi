# 归寂之战

> 哀切的鸣笛响彻，唯有开拓之人才能寻得跨越死境的生路。

## 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 4.4—4.7 版本 |
| 地点 | 二相乐园、千星城、点星船 |
| 对手 | 绝灭大君「万色返空主」归寂 |
| 结果 | 归寂败退，贪饕兽蜕被镇伏，阿哈重生 |

## 对手是谁

归寂不是普通的大君。

他是假面愚者「未抵」，是星穹列车领航员「观星者」我见，也是绝灭大君「万色返空主」。三段人生，三张面具。

他极少正面作战，而是如棋手般观望，在后方排布军团。他沉溺于不同世界的角色扮演，带给人们绝望，也给予他们挑战自己的机会——只为欣赏人类在漫长时光中的抗争。

> 唯有在面对恶毒的玩笑与挑战时，他们才能从归寂深恶痛绝的兽性中挣脱出来，展现出片刻属于人的光辉，带着尊严死去。

## 前史：一个假父亲

姬子的父亲无量塔隆介为寻找解除风化诅咒的方法四处奔走，查到诅咒的源头就是归寂。

他被归寂杀害，随后被取代。归寂假扮成隆介，只因为「扮演一个爸爸很好玩」。

母亲葬礼那天，女儿与「父亲」初次见面——那时站在她面前的，已经是绝灭大君。此后数十年，归寂一直是姬子人生里的「父亲」。

而姬子的母亲绘世，正是当年归寂在哈托彼亚拾到的弃婴：他把毁灭之力交给这个婴儿，教她毁灭自己的母星，「只是因为觉得这更好笑」。绘世后来改姓无量塔，为守护哈托彼亚而反抗他。

## 4.4：末日妖都

归寂以谒者身份加入幻月游戏。

他把二相乐园变成末日妖都，作为自己宣扬的「奇迹」。哀切的鸣笛响彻，废墟成为舞台，死者成为观众。

姬子直面他。她早就知道父亲被调包，却没算到最坏的可能：那个「父亲」的真实身份，是绝灭大君。

列车组赶来支援。姬子试图以牺牲捍卫列车逃离的可能；星核回应了开拓者「延续开拓之路」的愿望，让一切回到无法挽回之前。众人合力击败归寂。

## 4.6：千星城

归寂败退，但真正的威胁浮出水面：大地深处，被封印许久的「贪饕」兽蜕正在苏醒。

千星城生研院成为新的战场。虚照在此寻找钓猎贪饕的饵料；生研院主管亚婆离因过量古兽源质堕落为疯兽，被合力击败。

## 4.7：点星船

归寂再度现身。他宣称阿哈早已死亡，并推动「欢愉」与「贪饕」融合，催生新命途的雏形——「哲学的胎儿」·阿呜。

他想要的从来不是赢，而是证明「欢愉」也是假的。

终局在点星船上。虚照与八位谒者以「神的四个魔术」汇聚寰宇众生的愿力，镇伏贪饕。阿呜被魔术吸引，舔舐着糖果发出笑声，消失于无人知晓、无人抵达的终点。

阿哈重生。归寂的证明失败。

## 为什么这一战重要

| 层面 | 意义 |
|------|------|
| 对姬子 | 她必须亲手否定自己人生里的「父亲」，才能让列车继续往前 |
| 对归寂 | 他用毁灭逼人闪光，最终被「欢愉」本身否定 |
| 对乐园 | 幻月游戏第一次不以「胜者分享权柄」收场，而是把权柄还给神 |
| 对银河 | 反毁灭同盟的号召由此发出，4.x 的棋局扩至全银河 |

## 归寂留下的东西

离去前，他在每一颗死亡星球的表面烙印下巨大的笑脸——像是在嘲笑所有存在的逝去，又像是在悼念曾存在过的一切。

二相乐园的那一张，最后被留了下来。
