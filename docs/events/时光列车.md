# 时光列车

> 希露瓦以蹩脚的借口邀请你一同前往歌德宾馆共进下午茶。可正所谓「天下没有免费的咖啡」——机智的你立刻察觉到此事并不单纯。 但无论如何还是前往歌德宾馆与希露瓦聊聊吧——毕竟有谁能拒绝免费的咖啡呢？就算退一万步讲，希露瓦可是你在贝洛伯格为数不多的朋友之一，不是吗？

> **场景**：来到机械屋，你发现希露瓦恐怕不能如愿以偿了——坐镇克里珀堡的新任大守护者布洛妮娅正召唤她返回军队，为铁卫建设贡献力量。 希露瓦拗不过你与杰帕德二人，悻悻地独自前去与大守护者交涉，而她那爱操心的弟弟显然有些担心她的状况。 不妨跟着杰帕德一同前往克里珀堡，看看两人交涉得如何了吧。
> **场景**：交涉过后，你们才明白布洛妮娅的真实意图——她将可可利亚的某样遗物转交给了希露瓦。 这把看起来十分浮夸的电吉他似乎与希露瓦和可可利亚的过去有关。至于具体的联系，只有回到机械屋再听她娓娓道来了。
> **场景**：机械屋总给人以家的温暖感。而当你准备收拾行李、头也不回地离开这里时，这种温暖的感觉更是尤甚。 不过这只是你的个人揣测…希露瓦是怎么想的？恐怕只有她自己清楚。 但这毕竟与你无关，眼下还是先陪她一起收拾行李吧。
