# 翁法罗斯逐火之旅

> 击落众神，归还神火，予以几近覆灭的翁法罗斯新生。

## 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 3.0—3.7 版本 |
| 地点 | 翁法罗斯 |
| 主力 | 黄金裔、星穹列车 |
| 结果 | 铁墓被覆写成「空白」，权杖衰亡 |

## 第一次逐火

刻律德菈把「击落泰坦、回收火种」从神谕变成国策。

她率军攻破神悟树庭，夺得浪漫火种；讨伐吉奥里亚，逼出大地火种；围攻雅努萨波利斯，拿下命运三泰坦的神殿。

3960 年，她献祭五百名黄金裔完成律法试炼，随后自杀。阿格莱雅接任统领，第二次逐火之旅开启。

## 第二次逐火

第二次逐火持续了数百年。

阿格莱雅战死，万敌裂魂，遐蝶永居冥界，缇里西庇俄丝逝世，风堇成为最后一个人类。黄金裔几乎全灭。

## 永劫回归

昔涟与白厄借岁月之力，把翁法罗斯回退了一次又一次，制造死循环「永劫回归」。

实验停在 99%，已中断。开拓者到来时，是第 33550336 次循环。

## 3.6

长夜月的威胁解除后，星穹列车着手组建讨伐铁墓的联军，黑塔、螺丝咕姆与仙舟联盟都愿助力。

再创世的所有条件达成。开拓者回到大墓深处的德谬歌矩阵前，归还十二枚泰坦的火种，完成再创世的仪式。庞大数据涌向《如我所书》，翁法罗斯的命运翻开新页。

新世界到来。但铁墓还没有解决。

## 3.7

白厄的残躯在时光归墟化作封印，以怒火镇压着铁墓的恨意。开拓者与昔日的黄金裔、如今的泰坦同行深入归墟，消融卡厄斯兰那的执念，铁墓才破土而出。

决战分作两处：黑塔率银河联军在天外战场对抗铁墓，开拓者与昔涟在权杖中枢直面它。铁墓的恨意一瞬间烧尽寰宇文明的生命数据，黑塔抢先一步完成加冕，昔涟护住银河众生的记忆；开拓者踏上「记忆」命途，完成了一次银河范围的「再创世」，把「毁灭」的方程式覆写成「空白」。

铁墓陨落，权杖衰亡。来古士走到命运的终点，请螺丝咕姆把他的遗体带往亚德丽芬。

因浮黎缺席，因果并不稳固。昔涟以自我为代价回望过去，闭合翁法罗斯的因果，让旅途的起点成为故事的句号。
