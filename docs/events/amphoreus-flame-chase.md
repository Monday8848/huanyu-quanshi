# 翁法罗斯逐火之旅

> 「一众英雄踏上弑神的旅途，摘得十二枚火种，实现再创世的伟业。」
>
> 逐火，是不断失却的旅程。

## 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 3.0—3.7 版本（游戏外），光历 4931—4932 年（游戏内主线） |
| 地点 | 翁法罗斯全域、创世涡心 |
| 主力 | 黄金裔、星穹列车、昔涟 |

| 结果 | 铁墓被覆写成「空白」，权杖衰亡，翁法罗斯闭合因果 |

## 起因

刻法勒献出火种，留下创世神谕：十二位英雄将击落失神的泰坦、回收火种、拯救翁法罗斯。

神谕没有说的是：集齐十二枚火种之后要做什么。答案在 3.4 版本——集齐，然后付之一炬，等待再世的重启。逐火之旅只有一人能活到最后，见证「再创世」。

## 第一轮（3.0—3.4）

**3.0**：开拓者与丹恒降临翁法罗斯，恰逢尼卡多利袭击奥赫玛。众人一路杀入悬锋城，发现它早已炼成不死神躯；五瓣神魂归位后，尼卡多利失去不死之身，被击败，火种带回奥赫玛。

**3.1**：万敌通过试炼，以纷争半神之姿归来。缇宝三人前往命运重渊寻找欧洛尼斯，发现它已死、火种被夺；缇安牺牲。逐火小队在悬锋城围猎盗火行者，夺回岁月火种。万敌告别众人，返乡抗击黑潮；悬锋千年王朝终结。

**3.2**：开拓者接受岁月试炼，被告知自己早在进入翁法罗斯时就已经「死去」。为寻回被夺走的未来，遐蝶赶往斯缇科西亚，炼成死龙玻吕刻斯，回到冥界见到塞纳托斯，把火种与未来一并带回，自己永居冥界。那刻夏归还理性火种，肉身归殁，灵魂在冥界完成创世猜想的证明。

**3.3**：逐火小队讨伐天空泰坦。阿格莱雅借元老院与清洗者之手，以自己的落幕为逐火扫清前路；赛飞儿被盗火行者杀害，黎明机器静默，奥赫玛陷入永夜。风堇登上空中堡垒，直面先祖塞涅俄丝的谎言，众人击败「人神合一」的天空泰坦。

**3.4**：再创世即将完成前，来古士通过一齣沉浸式戏剧向开拓者揭露真相：翁法罗斯是「权杖」创造的世界，黄金裔的逐火之旅，实际是用来催生绝灭大君「铁墓」的轮回实验。

白厄接过负世火种，在末章剑指纳努克，燃尽自身，换来星神脸上一道转瞬即逝的伤口。一滴净世金血熔进卡厄斯兰那的身躯，他化作「神厄」，与纳努克对撞，压制住下一轮回的黑潮。开拓者与昔涟准备进入下一轮回。

## 第二轮（3.5—3.7）

第二轮的起点不是「继续」，是「回到过去」。

由于白厄的牺牲，循环中「负世」出现漏洞，原白厄的救世主身份由开拓者接手，「岁月」半神的权能易主给长夜月。这一世的翁法罗斯不再出现黑潮——白厄一个人把它挡在了世界之外。

但代价是：开拓者被踢出翁法罗斯，而翁法罗斯内外时间流速差别巨大。等他回来时，已是光历 4931 年。

中间的九百七十一年，是黄金裔用命换的：

| 年份 | 事件 |
|------|------|
| 3960 | 刻律德菈献祭五百名黄金裔，完成律法试炼，冻结来古士六成权限；同年命海瑟音刺杀自己 |
| 4029 | 阿格莱雅战死，与奥赫玛九万民众同死 |
| 4123 | 遐蝶完成死亡试炼，化为死龙守护密道；缇宝开凿通道 |
| 4259 | 最后一个缇里西庇俄丝燃尽 |
| 4284 | 万敌裂魂为五，以无限复活独抗来古士两百年 |
| 4510 | 风堇成为半神，照顾残存人类 |
| 4534 | 那刻夏化作贤者之石，与赛飞儿联手将来古士封入创世涡心 |
| 4602 | 最后一个普通人死去 |
| 4931 | 开拓者归来 |

**3.5**：开拓者沿昔涟留下的记忆指引重返翁法罗斯，见证黄金裔与来古士的千年博弈，接过仪式剑，沿彩虹桥走向创世涡心。

**3.6**：长夜月的威胁解除。丹恒与荒笛共鸣，接过大地神权，定位并救出被困的开拓者。星穹列车着手组建讨伐铁墓的联军，黑塔、螺丝咕姆与仙舟联盟都愿助力。再创世的所有条件达成，开拓者回到大墓深处的德谬歌矩阵前，归还十二枚泰坦的火种。

**3.7**：铁墓破土而出。决战分作两处：黑塔率银河联军在天外战场对抗铁墓，开拓者与昔涟在权杖中枢直面它。铁墓的恨意一瞬间烧尽寰宇文明的生命数据；黑塔抢先一步完成加冕，昔涟护住银河众生的记忆，开拓者踏上「记忆」命途，完成了一次银河范围的「再创世」，把「毁灭」的方程式覆写成「空白」。

铁墓陨落，权杖衰亡。因浮黎缺席，因果并不稳固；昔涟以自我为代价回望过去，闭合翁法罗斯的因果，让旅途的起点成为故事的句号。

## 永劫回归

在开拓者到来之前，翁法罗斯已经循环了三千万次。

卡厄斯兰那（白厄的前世）与昔涟得知世界真相后，借「毁灭」的力量将 PhiLia093 的存在从翁法罗斯抹除，令「岁月」路径出现逻辑漏洞，又以「记忆」为触媒注入十二火种，回退演算进程——这就是「永劫回归」。

实验记录显示：第 1 次，卡厄斯兰那成功说服十二黄金裔，以非暴力方法回收十二枚火种；第 15 次，他首次尝试对黑潮进行反编译；第 133 次，系统判定他的策略趋近于第 42 次，出现「过拟合风险」，心智函数可能受损。

第 33550336 次，开拓者到来。这一轮，永劫回归被突破。

## 主题

逐火之旅是一个关于「失却」的故事。

每一枚火种都对应一次告别：告别一位泰坦、一位同伴、一段记忆，或者一个「本来可以」的结局。黄金裔不是靠变强赢的，是靠把能失去的都失去之后，还剩一口气。

最后他们把火还给世界，自己变成记忆。
