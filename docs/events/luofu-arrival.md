# 乘槎驭风仙窟游

> 「我希望你们改变目的地。」不速之客说。在离星穹列车不远之处，联盟的仙舟「罗浮」在此停泊……

## 过程

### 不速之邀

雅利洛-Ⅵ的开拓之旅告一段落。一段旅程落幕，另一段旅程即将开启——然而在列车离开贝洛伯格后，卡芙卡留下的通讯要求众人改变目的地：仙舟「罗浮」。

列车之上，遥望不容踏足的故土。丹恒曾以为此生再也不会见到罗浮「玉界门」的景色——这位自称「无名客」的青年与仙舟之间，藏着他自己都不愿提起的往事。

### 空无一人的港口

抵达仙舟「罗浮」，等待列车的只有空无一人的港口。卡芙卡声称一颗星核降临此间，即将横生灾变。眼前闭锁的港口与失控的魔阴身士卒印证了她的说法——罗浮正处于多事之秋，魔阴身灾变使云骑军自顾不暇。

### 六司与将军

仙舟之上，六司各掌其职。停云（天舶司持钥人）邀请众人前往司辰宫通传来意。在敏感时刻，想在罗浮行动，就必须得到将军的准许——神策将军景元听完陈述，定下对策。

### 猎手与猎物

自截获的通讯中，天舶司找到了卡芙卡下落的蛛丝马迹。猎手与猎物的追逐开始：在引路人青雀的带领下，众人深入太卜司——此间飞阁连云，悬圃冲霄。符玄以「穷观阵」全力运转，阐演卡芙卡所历旧事，以揭示她的来意。

穷观阵得到了一个难以置信的结果：**星核猎手与仙舟上的星核灾难之间存在关联**——卡芙卡并非第一次踏上罗浮。

### 迴星港与丹恒

抵达「迴星港」，展开搜索行动。猎物总会不自觉留下痕迹，而分辨痕迹是否属于猎物，则是考验猎人技巧的时候。

而另一边，有一个名字反复被推到台前：丹恒。他在罗浮的每个角落都被旧识认出、被旧事缠绕——他为什么离开仙舟、又为什么改名换姓登上列车，是贯穿这段旅途的最大悬念。

### 尾声

符玄将卡芙卡解往太卜司，却要求列车组暂作等候。趁休整的机会，众人在长乐天四处游历，结识新朋。工造司入口处人头攒动——覆巢之灾，难有完卵。

这一系列事件在 1.2 版本「云树百丈蔽重楼」中急转直下：绝灭大君幻胧登场，罗浮迎来真正的存亡之劫。参见 [幻胧之乱](/events/luofu-phantylia)。
