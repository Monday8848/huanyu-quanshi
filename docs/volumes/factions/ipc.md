# 星际和平公司

::: info 速览
- **定位**：银河最大的经济体，名义上为「存护」琥珀王克里珀筑墙，实际上掌控着大半个银河的贸易、金融与物流。
- **命途**：存护
- **总部**：庇尔波因特
- **核心人物**：钻石（战略投资部主管）、砂金、托帕、翡翠、真珠
- **一句话**：它不统治世界，它只是拥有世界。
:::

## 一、起源与历史

### 从商会到帝国

公司的前身是一批**为筑墙工程提供物资的商会**。克里珀以光年为单位铸造障壁，需要海量的材料、运输与人力——有人嗅到了生意，于是组织起来，把"支援琥珀王"做成了一门产业。

这门产业后来膨胀成了帝国。

关键转折点是**边星贸易战争**。战争本身在游戏里着墨不多，但结果清晰：公司从"供应商"变成了"规则制定者"。战后，它掌握了跨星系贸易的通道、结算体系与信用网络——你可以不认同它，但你很难不用它的货币。

### 匹诺康尼的旧账

匹诺康尼在成为"梦境乐园"之前，是公司名下的**流放地**。这一点很关键：家族今天经营的每一寸梦土，地契上都写着公司的名字。

2.x 主线里，公司与家族的关系之所以微妙，根子就在这里——家族是业主，公司是房东，而房客们（全银河的富豪）只认乐园不认债主。

### 二相乐园

4.0 版本开启的「二相乐园」（哈托彼亚）同样在公司旗下，由首席执行官**真珠**管理。这说明公司的资产版图已经从"贸易与工业"伸向"体验与娱乐"——它不只卖东西，还卖**快乐**。

## 二、组织架构与关键人物

### 七大部门

| 部门 | 职能 | 备注 |
|------|------|------|
| **战略投资部** | 投资、并购、资本运作 | 权力核心，石心十人所在 |
| **市场开拓部** | 新市场开发、星际扩张 | 最激进，常与本地势力冲突 |
| **业务巩固部** | 存量业务维护 | 低调但掌握现金流 |
| **传统项目部** | 长期工程、基建 | 与筑墙工程关系最深 |
| **人才激励部** | 人事、考核、晋升 | P 级体系的守门人 |
| **筑材物流部** | 材料与运输 | 公司的血管 |
| **技术研发部** | 技术开发 | 被真理医生吐槽"野心大、脑子少" |

### P 级职级

公司用 **P 级**标定员工层级。P45 已经是能独当一面的高层——砂金、托帕都在这一级；再往上 P46、P47 是各部门部长；而战略投资部主管**钻石**，是存护星神的令使。

这套职级体系是公司最精妙的设计之一：它把"权力"量化成了可以攀爬的阶梯，让每个员工都相信，只要够努力，就能往上走一格。

### 石心十人

战略投资部的最核心圈层，由**钻石**统领。成员各怀绝技，也各怀鬼胎——石心十人内部并非铁板一块，这一点在匹诺康尼的剧情里已经露了端倪。

## 四、未解之谜与推测

::: warning 推测区（社区讨论汇总）
1. **公司真的信克里珀吗？** 高层大概率不信。对他们来说，琥珀王是"品牌图腾"——一个让所有员工和客户相信"我们在做崇高事业"的故事。但底层员工里，虔诚者不少。这种分裂本身就是公司的缩影。
2. **石心十人的真实目的。** 十个人各有算盘，钻石的立场也不完全透明。有假说认为，石心十人内部存在"忠于克里珀"与"利用克里珀"两派，匹诺康尼事件是一次内部清洗。
3. **公司在为"第四时刻"准备什么？** 博识尊确认第四时刻已至，指向列神之战。公司作为存护的最大受益者，不可能没有预案。翡翠提出的"反毁灭同盟"被列车拒绝，说明公司已经在布局。
4. **真珠与欢愉假面。** 二相乐园的 CEO 手握三张假面，意图掌控幻月游戏。一个公司高管为什么要插手欢愉星神的游戏？这是 4.x 最大的悬念之一。
5. **P 级之上还有什么？** P47 是已知的顶点，但公司的真正所有权结构从未公开。董事会？创始人后裔？还是某个更古老的存在？
:::

## 五、编者按

公司是这本书里最难写的一章，因为它**太大**——大到任何一个切面都只能看到局部。

写它的时候，我一直在想一个问题：一个以"筑墙"为名义的组织，最后变成了银河最大的扩张者，这算不算一种讽刺？

克里珀筑墙是为了**隔绝**，公司扩张是为了**连接**。两者用的名义是同一个，方向却相反。

也许这正是存护命途的悖论：**你要保护什么，就得先控制什么；你要控制什么，就得先拥有什么。** 拥有到最后，保护的对象已经不重要了，重要的是"拥有"本身。
