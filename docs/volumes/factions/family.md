# 家族

::: info 速览
- **定位**：匹诺康尼的统治者，「同谐」希佩的追随者，把"梦"做成了全银河最赚钱的产业。
- **命途**：同谐
- **核心地盘**：匹诺康尼（白日梦酒店、十二梦境）
- **核心人物**：星期日、知更鸟、加拉赫、米沙
- **一句话**：欢迎来到梦境——代价是，你得把"自己"交出来一点。
:::

## 一、起源与历史

### 从流放地到乐园

匹诺康尼的黑历史，公司从来不提：它曾经是公司的**流放地**。罪犯、欠债者、政治失败者被送到这里，在荒芜的星球上自生自灭。

转折点是"家族"的到来。希佩的追随者看中了这颗星球——具体看中了什么，官方没有明说。有人猜是地理位置，有人猜是地脉里的"忆域"资源，也有人猜，是因为这里聚集了太多**被放逐者的执念**。

无论原因是什么，结果很清楚：家族把流放地建成了乐园。白日梦酒店拔地而起，十二重梦境层层铺开，全银河的富豪权贵蜂拥而至，只为在梦里做一回"更好的自己"。

### 钟表匠的传说

匹诺康尼的奠基者被称为**「钟表匠」**。他的真实身份、他与米沙的关系、他为什么要把整颗星球做成一场梦——这些是 2.x 主线最核心的谜题。

钟表匠留下了一句近乎遗嘱的话：**"愿你们在梦中，找到醒来的理由。"**

这句话后来成了整个匹诺康尼篇的题眼。

### 星期日之乱

2.x 的结局是一场未遂的"升格"：星期日试图借「齐响诗班」汇聚的众愿，让「秩序」太一的残响借体重生——他想给所有人一个"没有痛苦的梦"，代价是抹掉所有人的自由意志。

他失败了。但失败的代价是匹诺康尼的梦被撕开了一道口子，家族的内部裂痕彻底暴露。

## 二、组织架构与关键人物

### 五大家族

| 家系 | 特征 | 代表人物 |
|------|------|---------|
| **橡木家系** | 最核心的一支，掌控梦境秩序 | 星期日、知更鸟 |
| **苜蓿草家系** | 商业与酒店经营 | — |
| **猎犬家系** | 治安与执法 | 加拉赫 |
| **鸢尾花家系** | 艺术与娱乐 | — |
| **隐夜鸫家系** | 情报与隐秘事务 | — |

五大家族共同治理匹诺康尼，但权力并不均衡。橡木家系长期占优，这也是星期日能调动如此多资源的原因。

### 谐乐众弦

希佩的令使级存在，家族最高权力的象征。星期日试图通过「齐响诗班」——谐乐众弦之一——汇聚众愿完成升格。这条线说明：**家族的权力结构直接挂在星神身上**，不是单纯的世俗组织。

## 四、未解之谜与推测

::: warning 推测区（社区讨论汇总）
1. **钟表匠到底是谁？** 最主流的假说认为钟表匠与米沙是同一存在的两个面向，但具体机制（记忆投射？分身？升格失败？）没有定论。
2. **星期日还有后手吗？** 他在匹诺康尼失败后并未消失，4.x 又出现在二相乐园并拿到一张假面。一个曾经的"神主日"混进欢愉的游戏，动机绝不简单。
3. **匹诺康尼的梦建立在什么之上？** 十二重梦境需要海量"忆质"。这些忆质从哪来？有假说认为，乐园的繁荣本身就建立在某种**记忆剥削**之上。
4. **希佩对家族的态度。** 同谐要求个体融入整体，但家族内部五系争权、各怀私心。希佩为什么容忍这种"不和谐"？是默许，还是在等一个更彻底的整合时机？
5. **"醒来"的代价。** 钟表匠说"找到醒来的理由"，但剧情里大量角色选择留在梦里。如果醒来意味着失去一切，梦是否也是一种正当的活法？这是匹诺康尼篇留给玩家的伦理题。
:::

## 五、编者按

家族这一卷，写起来最不舒服。

因为它的核心命题太扎人了：**如果有一个没有痛苦的世界，你愿意用自由去换吗？**

星期日的答案是"愿意"，而且他不是为自己——他是真的想替所有人免除痛苦。这种"善意的暴政"比纯粹的恶更难反驳，因为你没法说他的出发点错了，你只能说：**人有权选择痛苦。**

知更鸟的答案相反：把人叫醒，哪怕醒来是荒野。她的歌之所以有力量，不是因为她唱得多好，而是因为她承认了"活着本来就疼"。

匹诺康尼的梦很美。但梦最美的地方，是它总会醒。
