## 每个单元怎么读

固定五段，顺序不变：

1. **速览** —— 三分钟建立印象
2. **起源与历史** —— 它怎么变成今天这样
3. **组织架构与关键人物** —— 谁说了算
4. **关系网** —— 朋友、敌人、以及不好说的
5. **未解之谜与推测** —— 社区在争什么

::: tip 编者按
如果你只有五分钟，读每个单元的「速览」和「推测区」就够了——前者给你事实骨架，后者给你这个势力最要命的悬念。
:::
