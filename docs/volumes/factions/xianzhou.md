# 仙舟联盟

::: info 速览
- **定位**：由多艘巨型仙舟组成的古老同盟，以追杀丰饶孽物为立国之本。
- **命途**：巡猎
- **核心座舰**：罗浮、曜青、朱明、方壶、玉阙、虚陵（六舰）
- **核心人物**：景元、符玄、彦卿、丹恒、镜流、刃（应星）
- **一句话**：一艘船追着一个神，追了几个琥珀纪。
:::

## 一、起源与历史

### 求药时代：一切错误的开始

仙舟人原本也是短寿的凡人。为了摆脱"短寿"的诅咒，他们向宇宙发出祈愿——回应他们的是「丰饶」药师。

药师从不拒绝祈愿。祂赐下了不死。

不死带来了什么，历史写得很清楚：**魔阴身**。长生种的肉身不会衰老，精神却会先一步崩坏；血肉畸变、理智消解，最终变成只知道增殖的孽物。仙舟人求来了永生，也求来了永生的地狱。

### 帝弓司命：从受害者到猎手

在仙舟文明行将陨落的岁月里，「巡猎」岚出现了。仙舟称祂为**帝弓司命**——那道光矢为他们指明了方向。

从此仙舟转向：不再求长生，转而追杀丰饶孽物。这不是复仇，是**赎罪**——他们曾经求来的东西，现在要亲手清理干净。

### 联盟与六舰

仙舟不是一艘船，是一支舰队。六座座舰各自承载一个世界，联合成盟。联盟经历过数次大劫——丰饶之民的侵袭、帝皇战争的波及、寰宇蝗灾的余波——每一次都险些灭族，每一次都撑了下来。

### 十王司

独立于六司之外，掌管**生死判定**。仙舟人对"何时该活、何时该死"有一套严格的制度，十王司就是执行者。魔阴身者被判定"不再是本人"时，由十王司处置。

这是仙舟最沉重、也最容易被忽视的机构：它处理的不是敌人，是**曾经的同胞**。

### 帝弓七天将

巡猎令使的集群，仙舟最高军事领袖。已知景元是其中之一（罗浮将军）。七天将全员名单与各自镇守的仙舟，官方尚未完全展开。

### 云上五骁

仙舟历史上最耀眼的一代：**丹枫、镜流、应星、景元、白珩**。五个天才，一段传奇，以及一场分裂。

白珩之死是裂痕的起点。此后丹枫因"化龙妙法"之乱被问罪、转世为丹恒；应星堕入魔阴、成为刃；镜流堕魔、离开仙舟；只剩景元留在罗浮，守着所有人的残局。

::: tip 编者按
云上五骁的故事是仙舟线的**情感内核**。它讲的不是"英雄如何成功"，而是"英雄如何彼此亏欠"。仙舟的宏大叙事底下，埋着五个人的私账。
:::

## 四、未解之谜与推测

::: warning 推测区（社区讨论汇总）
1. **魔阴身能治好吗？** 丹鼎司研究了几千年，答案仍是"控制"而非"治愈"。白露的龙尊之力、持明族的轮回，是否藏着解药？这是仙舟线最大的悬念。
2. **帝弓七天将还有谁？** 景元之外，六位将军镇守何处、是什么状态，官方只给了碎片。有假说认为其中已有陨落者。
3. **岚的终局是什么？** 巡猎追杀丰饶，追到宇宙尽头会怎样？如果药师被杀，巡猎命途会不会随之失去意义——甚至消失？这是"命途悖论"最锋利的一个案例。
4. **持明族的轮回是不是另一种魔阴身？** 持明族死后蜕生、记忆不全，与魔阴身的"人格崩解"在现象上有相似之处。有考据认为两者同源，都是丰饶之力的变体。
5. **停云到底死没死？** 罗浮事件后停云的下落一直模糊，社区至今在争。官方没有正面确认。
:::

## 五、编者按

仙舟是我最偏爱的一卷。

它的悲剧不在于"打不过敌人"，而在于**它求错了东西**。仙舟人求长生，得到了；代价是永远活在"长生"的诅咒里。他们后来的全部历史，都是在替祖先的那个愿望擦屁股。

这让我想到一个很朴素的道理：**你向宇宙要什么，宇宙就会给你什么——以你没想到的方式。**

帝弓司命给了他们方向，但方向不等于答案。追杀丰饶孽物几千年，仙舟依然没有解决"人该如何面对死亡"这个问题。他们只是把它推迟了，推给了下一代，推给了十王司的判词。

也许仙舟真正的敌人不是药师，是**不肯认输**这件事本身。
