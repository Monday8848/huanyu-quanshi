# 附录卷 · 未证实档案

::: danger 阅读须知
本卷收录的内容**全部未经官方证实**。

它们来自社区传闻、匿名爆料、拆包碎片与大胆假说，可信度参差不齐。把它们单独成卷，是为了让正文保持干净——**请不要把本卷内容当作事实引用，也不要当作剧透依据**。

每条都标了可信度：

- **C 级**：有多个独立来源提及，但无实证
- **D 级**：单一来源，或明显带有推测成分
- **E 级**：纯假说，社区自娱自乐
:::

## 四、本卷的收录原则

1. **不收具体拆包数据**（角色技能数值、未上线模型等）。那类内容变动太快，且容易误导。
2. **不收人身攻击与社区节奏**。考据归考据，吵架归吵架。
3. **每条必须能追溯到至少一个公开讨论**。编者自己编的，标 E 级并注明。
