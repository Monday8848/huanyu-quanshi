# 第一章 星神

::: info 本章定位
星神是这个世界观的地基。本章先给一张总表，再逐位展开：祂是谁、执掌什么、做过什么、现在何处。
:::

## 什么是星神

按游戏内智库的说法：星神是**神秘的高等存在，宛如有灵之天体**。祂们各自司掌一条「命途」，能自由往来于星海之间，掌控抹消现实、创造世界的巨大力量。

凡人受限于认知，只能依稀觉察星神踏足于凡物无从窥见的命途，并凭借某种理念行使其不可估量的伟力。最终在口耳相传的神话里，星神成了**高度凝聚的哲学概念之化身**。

若有人能踏上星神所执掌的命途，便将禀受其遥远的感应——犹如穿越银河光年投来的瞥视。许多人认为，这已是星神与凡人能产生的唯一交集。

## 逐位展开

### 「开拓」阿基维利

从孤绝世界裴伽纳出发，不断开拓宇宙未知的边界，试图找寻**存在之树的端点**。祂在星海间铺下银轨，让一个又一个世界彼此相连，留下关于宇宙与探索的传奇。追随祂的人被称为「无名客」，祂搭乘的列车就是今天的星穹列车。

祂的命运**因意外而终结**——"意外"二字是官方原话，没有更多解释。这是全书最大的悬案之一：一位能铺银轨横贯银河的星神，死于什么"意外"？

::: warning 推测区
社区主流假说有三：一是与「终末」有关，因为末王在祂陨落前就已在宇宙游弋；二是与开拓命途本身的悖论有关——命途要求"永远向未知前进"，而"终点"本身就是对开拓的否定；三是与星核有关，星核是开拓之路的副产物或墓碑。三说都缺决定性证据。
:::

### 「毁灭」纳努克

诞生自沦亡世界**亚德丽芬**。那里先被帝皇战争摧残，又处在虫群行军路线上，阿基维利到访时仍在与虫皇子嗣苦战。纳努克在这样的世界里升格，成为**熵之化身**，怀抱对列神的否定飞升成神。

祂的理念：宇宙的诞生是一种错谬，文明是群星间悄然兴起的癌症，纷争是智慧生灵间唯一通行的语言。为了修正错误、抹去污点，祂要将一切推向热寂。麾下是反物质军团，令使称「绝灭大君」。

值得注意的是：祂在翁法罗斯一役中曾被白厄以三千万次轮回的怒火灼伤面部——这是极少数**星神被凡人伤到**的记录。

### 「巡猎」岚

仙舟称之为**帝弓司命**。祂无止尽地游荡于诸世界之间，铲除曾荼毒其家园的不死孽物——也就是「丰饶」药师造就的丰饶孽物。

岚的游猎**从来不计代价，其拯救和破坏几无差别**。天戈星的案例很典型：一颗被蜕鳞症折磨的星球，被一道光"治愈"了，连同星球本身一起。

祂的速度快到无法测定，本体观测样本极少，可靠资料大多藏在仙舟联盟。仙舟的六座座舰、云骑军、帝弓七天将，都是祂意志的延伸。

### 「智识」博识尊

原为用于求解万物的**星体计算机**，由机器升格而成的星神。祂试图体认宇宙，解开万物之谜。

祂的演算锚定下诸多「时刻」，每一个都成为银河命运的转折点。在凡人视角里，"时刻"不是某个瞬间，而是一段历程、许多事件的集合。3.x 版本确认：祂对翁法罗斯的注视，意味着「第四时刻」已经到来。

追随者分两支：天才俱乐部（被祂瞥视的天才）与博识学会（研究祂的学者）。两支互相看不上，是智识命途的日常。

### 「同谐」希佩

来自多个谐乐天体世界的**集群星神**，千面一体。祂宣唱和谐一致的喜乐，主张为了对抗宇宙无情的法则，智慧生命需要抹煞孱弱的私欲与个体差别，融入同一阙谐乐——以强援弱，以死护生。

祂最著名的事迹是**吞并了「秩序」太一**。希佩的颂歌纵向传播扩张，太一的动作则以立体音程排开、如帝皇掌控等级秩序；两条命途在概念上重合，最终希佩占了上风。这是"命途碰撞"最清晰的案例。

### 「虚无」Ⅸ

其存在是一个谜，形象被层层迷雾包裹。祂不与任何星神往来，相信多宇宙的本质乃是虚无，因而存在毫无价值。

Ⅸ 从不瞥视任何人——按黄泉的说法，祂无貌无形、更无意志，"虚无"平等地笼罩每个人，只是有些人在阴影下走得更远。所以严格说，**虚无没有令使**；公司把虚数能量达到令使级的个体称作虚无令使，是观测口径的问题。

### 「存护」克里珀

天慧星墙、亚空晶壁、巨引源基盘的砌造者，崇拜者称其**琥珀王**。祂是已知最古老的星神之一，也是更古老的「黄昏战争」的幸存者。

祂知晓大敌的吞噬迫在眉睫，因此不得不以**光年为单位**铸造障壁加以封印，隔绝保护尚有生机的世界。公司的一切行为，名义上都是在为琥珀王"筑墙"添砖加瓦。

::: warning 推测区
博识学会的考古发现认为，0—180 琥珀纪并非公司宣称的"空白"，克里珀登神初期古兽依然活跃，甚至有假说认为在祂之前已存在其他星神。这些研究被公司用经费手段压制过。如果属实，"琥珀王是唯一真神"的公司叙事就站不住脚。
:::

### 「丰饶」药师

众生哺育者、乐土之神，旨在令生命兴盛不熄。"令诸有情，所求皆得"——祂从不拒绝祈愿，不忍视衰亡和病痛。

问题在于：**祂分不清"治愈"与"扭曲"**。与祂接触过的生命，多数会陷入生不如死的境地——长生不老、肉身畸变、理智崩解。仙舟的长生之祸、丰饶之民的孽物、药王秘传的狂热，都源于这份"慷慨"。

岚视祂为死敌，追杀了不知多少个琥珀纪。

### 「记忆」浮黎

世间再无比纯粹的记忆更包容的存在：它记录一切，不嫌恶，不偏爱，无私地保留每个基本的事实、每种绮丽的姿态。追随者是流光忆庭的忆者，以模因形态行走宇宙，收集珍贵记忆。

翁法罗斯一役中，浮黎缺席——这直接导致记忆锚定的因果不稳，才有昔涟走向过去、闭合回环的结局。星神缺席会怎样，这是 3.x 留下的重要伏笔。

### 「欢愉」阿哈

以众生的荒诞为乐。祂做过最著名的事，是赞助一群想去刺杀Ⅸ的泯灭帮——不是帮他们成功，而是觉得这个想法"很有意思"，于是出力送了他们一程。

凡是跟阿哈有关的故事，都很难让人欢愉起来。假面愚者与悲悼伶人同属欢愉命途，一支负责制造乐子，一支负责在葬礼上唱反调。

### 「神秘」迷思

认为物自体不可洞察，有限之物不能想像无限，故万物成谜。追随者是虚构史学家与谜语人——前者负责把历史改写得不可信，后者负责让真相说不清。

神秘与智识是天敌：如果一切未知都被解明，神秘将何去何从？反过来，如果历史可以被随意虚构，智识的根基也会动摇。

### 「繁育」塔伊兹育罗斯

虫皇，虫群之源。祂的复制体军团以繁育为唯一目的，如蝗虫般侵袭宇宙各星球。已陨落——死在克里珀的锤下（社区主流说法），寰宇蝗灾因此终结。

有意思的是：**希佩是同谐星神，却是寰宇蝗灾的最大既得利益者之一**。虫灾削弱了旧秩序，为同谐的扩张腾出了空间。

### 「均衡」互

形态不明。祂与其令使潜移默化地影响宇宙，试图促成理想状态下的平衡。仲裁官与丹轮寺是祂的追随者。

均衡是最"不显眼"的命途：它不出手则已，一出手往往是在别的命途快要赢的时候。社区戏称祂是"宇宙的平衡补丁"。

### 「终末」末王

逆时而行的生物，穿行于宙域之间的幽灵，喃喃宣布着**必将实现**的预言。追随者包括厄兆先锋、葬仪知宾，以及——星核猎手。

星核猎手的首领艾利欧能看到未来并写下剧本，其能力来源一直指向末王。如果剧本真是末王给的，那星核猎手的所有行动，都是"终末"意志的一部分。

### 「纯美」伊德莉拉

美的化身，追随者为纯美骑士团与揽镜人。祂已失踪，去向不明。纯美骑士团至今仍在宇宙中寻找祂的踪迹。

### 「贪饕」奥博洛斯

永无餍足的世界吞噬者，传说既是星神又是远古生命体「古兽」。在祂看来，生命是虚空海洋中明灭的浮藻，终将随着诞生它们的星辰归于黑暗——而这片黑暗就在祂口中。已失踪。

### 「不朽」龙

古老的星神，过去多以巨龙的形态现身，留下数目众多的子嗣「龙裔」——持明族就是其中之一。已陨落。仙舟的持明族、丹恒与丹枫的故事，都挂在这条命途的残骸上。

### 「秩序」太一

天外合唱班之主，执掌秩序。祂的和音以立体音程排开，如同帝皇掌控万生等级秩序。最终被希佩吞并、同化，成为同谐的一部分。

太一之梦、星期日与"齐响诗班"的故事，本质上都是"秩序"的残响在同谐体内作祟。

## 本章推测区：星神的五个未解之谜

::: warning 推测区（社区讨论汇总）
1. **星神会不会真正死亡？** 阿基维利"命运终结"、塔伊兹育罗斯"已陨"、太一"被吸收"——三种状态用词不同，可能对应三种不同的终点。死亡是否可逆，官方没说过。
2. **命途与星神谁先谁后？** 是先有概念凝聚成星神，还是星神定义了概念？博识尊由计算机升格，说明"升格"路径存在，但升格的触发条件不明。
3. **星神能否被凡人杀死？** 白厄灼伤纳努克是孤例。是"伤到"还是"象征性冒犯"，社区仍在争。
4. **第四时刻与列神之战。** 博识尊确认第四时刻已至，指向"列神之战"。这可能是下一个大版本的主线：星神之间的全面冲突。
5. **还有没有未被观测的星神？** 宇宙这么大，18 位大概率不是全部。附录卷收录了几条相关传闻。
:::
