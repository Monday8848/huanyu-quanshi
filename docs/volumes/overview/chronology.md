# 第三章 宇宙纪年

::: info 本章定位
这一章解决一个很实际的问题：**当有人说"这事发生在琥珀 2152 纪"，你到底该把它放在时间轴的哪里？**
:::

## 三套历法

星穹铁道的宇宙里没有统一的"公元"。不同文明各记各的，主要有三套：

| 历法 | 使用者 | 基准 | 特点 |
|------|--------|------|------|
| **琥珀纪** | 星际和平公司、银河通用 | 琥珀王克里珀的锤击 | 数字极大，常用于历史事件断代 |
| **开拓历** | 星穹列车、无名客 | 列车启程与航线记录 | 与列车行程绑定，适合记"第几站" |
| **仙舟历** | 仙舟联盟 | 仙舟启航 | 与仙舟内部事件严格对应 |

### 琥珀纪的换算难题

公司以克里珀筑墙的"锤击"为纪年基准。问题是：**锤击的间隔并不固定**。

社区常见换算有"一纪约 76 年"说，也有"百余年"说，官方从未给出确定值。所以看到"琥珀 2152 纪"时，**不要直接乘 76 去算年份**——那个数字只能用来排序，不能用来精确换算。

::: tip 编者按
这是本书处理时间线的基本原则：**只保证先后顺序，不保证绝对年数**。任何给出精确年份的考据，都需要打一个问号。
:::

## 三次寰宇级灾难

在列车启程之前，宇宙经历过三次足以改写格局的大灾：

### 帝皇战争

机械帝皇掀起的战争，具体起因与过程在游戏中只有碎片。已知后果：大量世界沦为废墟，亚德丽芬就是受害者之一——纳努克的诞生地，先被帝皇战争摧残，又撞上虫群行军路线。

### 寰宇蝗灾

「繁育」塔伊兹育罗斯的虫群以指数级扩张，席卷银河。最终虫皇陨落（社区主流说法是死于克里珀的锤），虫灾终结。

这场灾难的**最大既得利益者是同谐**：旧秩序被虫灾撕碎，希佩的颂歌趁虚而入。

### 边星贸易战争

公司崛起的背景板。战争的具体过程官方着墨不多，但结果是明确的：星际和平公司从一家"为筑墙提供物资"的商会，变成了银河最大的经济体。

## 时间线的三个陷阱

读星铁的时间线，有三件事会把你带沟里：

### 陷阱一：记忆会被抹除

匹诺康尼的梦境、翁法罗斯的轮回，都涉及**大范围记忆修改**。你记得的事，可能没发生过；你没见过的事，可能发生过很多次。

### 陷阱二：有人逆着时间走

末王逆时而行的设定意味着：**因果顺序不等于时间顺序**。一个"未来"的预言可能先于它的原因出现。星核猎手的剧本就是典型——艾利欧写下的事，往往在发生前就已注定。

### 陷阱三：有些世界是模拟的

翁法罗斯的真相是"帝王权杖"内部的演算世界，内部循环了三千万次，外部时间几乎没动。

::: warning 推测区
如果翁法罗斯是模拟世界，那其他世界呢？"虚假之天"式的设定在米哈游宇宙里不是第一次出现。社区有假说认为，整个银河可能处在某种更高层的演算或观测之中——目前没有任何实证，但这类假说与「智识」「神秘」两条命途的设定高度自洽。
:::

## 本章推测区

::: warning 推测区（社区讨论汇总）
1. **琥珀纪的锚点到底是什么？** 如果锤击间隔不固定，那"纪"就不是时间单位，而是"事件单位"——每一次锤击代表一次筑墙工程完成。这个假说能解释为什么不同史料里的换算对不上。
2. **三次灾难是否有共同推手？** 帝皇战争、虫灾、贸易战争，背后都有"秩序崩塌→同谐扩张"的影子。有人怀疑希佩在下一盘很大的棋。
3. **列车启程的准确时间？** 官方只给了相对顺序。有考据认为列车在阿基维利陨落后很久才启程，也有认为几乎紧接着。这个问题不解决，整条时间线都无法绝对定位。
:::
