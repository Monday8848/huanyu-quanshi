# 第二章 命途

::: info 本章定位
如果说星神是"谁"，命途就是"以什么方式"。这一章讲命途的运作规则——它怎么选中人、怎么互相吞并、为什么游戏里的命途不能直接当设定用。
:::

## 命途是什么

命途是星神所执掌的**哲学概念**，也是祂们力量的形态。星神踏足于命途之上，凡物只能窥见其投影。

一个常见的误解是"命途是一条路，走上去就能变强"。更准确的理解是：命途是**一种被星神锚定的存在方式**——你信什么、为什么而活、愿意为此付出什么，这些问题的答案如果与某条命途共振，你就会"踏上"它。

## 星神与命途的关系

三句话概括：

1. **星神执掌命途，但不等同于命途**。星神陨落后，命途不会立刻消失——「开拓」的阿基维利已陨，开拓的道路仍有无名客在走。
2. **命途会互相吞并**。希佩吞并太一，是"概念近似"导致的碰撞结果：同谐与秩序在"集体意志"上重合，弱的一方被强的一方吸收。
3. **命途也可以共存**。存护与记忆、丰饶与繁育，都出现过或长或短的共存状态。共存不等于友好，更像两条河暂时并行。

::: tip 编者按
游戏内智库对命途碰撞有个很妙的说法：凡人对命途的总结终归是"眼界落了下乘"，命途真正的意义，用简单一个词并不能完全概括。换句话说，**"毁灭""巡猎"这些名字都是凡人起的**，星神自己未必认。
:::

## 令使：星神的代行者

令使是获得星神**完整赐福**的存在，能代行星神的部分权柄。

已知的令使谱系：

| 星神 | 令使 / 代行者 | 备注 |
|------|--------------|------|
| 毁灭 | 绝灭大君 | 军团最高战力，翁法罗斯的铁墓即其一 |
| 巡猎 | 帝弓七天将 | 仙舟最高军事领袖，景元为其一 |
| 同谐 | 谐乐众弦 | 家族最高权力的象征 |
| 存护 | 石心十人 / 钻石 | 公司战略投资部核心 |
| 智识 | 天才俱乐部成员 | 被博识尊瞥视者 |
| 丰饶 | 倏忽等 | 丰饶之民的顶端 |
| 繁育 | 各王虫 | 虫群的核心节点 |
| 虚无 | 无（黄泉说） | Ⅸ 从不瞥视任何人 |

注意最后一行：**虚无没有令使**。公司观测到黄泉的虚数能量达到令使级，就把她定义为虚无令使——这是观测口径，不是神学事实。黄泉自己明确否认过。

## 命途碰撞：三个案例

### 同谐吞并秩序

希佩的颂歌纵向传播扩张，时而以意识态支配；太一的和音以立体音程排开，如同帝皇掌控万生等级秩序。两者在"集体意志"上重合，最终希佩占了上风，太一成为祂的一部分。

这是**唯一一次被官方明确记录的命途吞并**。它证明了一件事：命途之间不是并列关系，而是有食物链的。

### 存护与记忆

两条命途长期共存，边界模糊——都在"保存"某种东西，一个保存文明，一个保存记忆。社区有人认为这是"同一底层需求的两个面向"，也有人认为只是暂时没打起来。

### 丰饶与繁育

一个追求个体不死，一个追求种群扩张，在"生命增殖"上高度重合。虫灾期间两者是否有过接触，官方没有正面写。

## 踏上命途：命途行者

凡人可以踏上命途，获得力量，但不等于成为令使。

- **命途行者**：与命途共振、能调用部分力量的人。开拓者、黄泉、镜流都属于此类。
- **令使**：获得星神完整赐福，是命途的"正式员工"。
- **星神**：命途的锚点本身。

三者的差距不是努力能弥补的——这是设定上的硬边界。

## 游戏机制命途 vs 世界观命途

这是新人最容易踩的坑，必须单独说清楚：

| | 游戏机制 | 世界观 |
|---|---------|--------|
| 含义 | 角色战斗定位（输出/辅助/生存等） | 星神执掌的哲学概念 |
| 数量 | 随版本增加（毁灭、巡猎、智识、同谐、虚无、存护、丰饶、记忆、欢愉等） | 已知 18 条 |
| 归属 | 由角色设计决定 | 由角色的信念与行为决定 |
| 关联 | **无直接关联** | 与星神、派系强相关 |

举例：景元是"巡猎"命途角色，同时是巡猎令使，这是少数对得上的；但大量角色卡上的命途只是战斗定位，与信仰无关。**别拿角色卡去推设定**。

## 本章推测区

::: warning 推测区（社区讨论汇总）
1. **命途有意志吗？** 如果命途只是概念，为什么它会"选择"人？如果是意志，那星神陨落后命途的意志又是什么？社区倾向认为命途本身无意志，但会像水流一样"倾向于"某些行为模式。
2. **开拓的命途会不会消失？** 阿基维利已陨，但银轨还在、列车还在跑。如果有一天所有无名客都停下，开拓命途会不会随之熄灭？
3. **虚无是不是所有命途的终点？** Ⅸ 认为一切终归虚无。如果祂是对的，其他十七条命途的努力是否都只是延迟结算？这是设定层面最黑的一个问题。
4. **玩家角色的命途会不会影响剧情？** 目前明确"无直接关联"，但开拓者本人同时踏上多条命途（存护、记忆等），这是特例还是普遍现象，尚无定论。
:::
