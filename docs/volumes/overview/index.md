# 总论卷 · 星神与命途

> 在讲任何势力之前，得先讲清楚这个宇宙的"物理法则"。
>
> 星穹铁道的世界里，神不是信仰对象，而是**宇宙现象**。祂们诞生、行走、陨落，各自执掌一条命途，像天体一样运行，不因凡人的祈祷而改变轨迹。所有势力——公司、仙舟、家族——本质上都是在**揣测某位星神的意图**，并以此为自己立法。

本卷三章：

| 章 | 内容 | 解决什么问题 |
|----|------|-------------|
| 第一章 | [星神](/volumes/overview/aeons) | 祂们是谁，各自要什么，现在什么状态 |
| 第二章 | [命途](/volumes/overview/paths) | 命途如何运作，令使是什么，为什么命途会互相吞并 |
| 第三章 | [宇宙纪年](/volumes/overview/chronology) | 琥珀纪、开拓历、仙舟历怎么换算，大事怎么排 |

## 读之前的三句话

1. **星神不等于神明**。祂们更像"高度凝聚的哲学概念之化身"，多数对凡人毫无兴趣，少数以戏赏蝼蚁为乐。
2. **命途不等于职业**。游戏里角色卡上的"命途"是战斗定位，与世界观里的命途是两套东西——这一点第二章会展开。
3. **本书的星神条目以"已知"为限**。宇宙里大概率还有未被观测的星神，附录卷里有相关讨论。

::: tip 编者按
本章的星神排序按**命途首字**排列，不按强弱。星神之间没有公认的实力榜——硬要排，多半会变成"谁的神话更能吹"的比赛。
:::
