# 利衡币

> 塔兰顿翻转天平，将砂砾转为神力砝码，设立为统一货币「利衡币」。

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 货币 |
| 设立者 | 律法泰坦塔兰顿 |
| 流通 | 翁法罗斯各城邦 |
| 首次登场 | 3.x 版本 |

## 起源

黄金世初期，塔兰顿翻转天平，把砂砾变成神力砝码。

砂砾有了重量，重量有了价格，价格有了名字——利衡币。翁法罗斯第一次有了统一货币。

## 意义

利衡币不只是钱。

它是律法泰坦对「公平」的定义：同样的重量，换同样的东西；同样的罪，付同样的代价。

## 3.x

在奥赫玛、悬锋城、斯缇科西亚，利衡币都是硬通货。

在奥赫玛的云石市集，交易用利衡币结算。半神之间谈的是火种，凡人之间谈的是利衡币。
