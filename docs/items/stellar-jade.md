# 星琼

> 游戏内用于「跃迁」的货币。至于它在世界观里到底是什么，官方没有说。

## 说明

星琼是《崩坏：星穹铁道》的**游戏内货币**，主要用途是「跃迁」（获取角色与光锥）以及兑换其他资源。

需要说明的是：官方从未在世界观层面解释星琼的成因、产地或流通方式。剧情中没有人用星琼买东西，也没有哪个势力把星琼当作储备资产。本站只记录可确认的部分，不为它补设定。

## 游戏机制

| 项目 | 内容 |
|------|------|
| 用途 | 跃迁、兑换星轨专票／通票、补充开拓力 |
| 兑换 | 160 星琼 = 1 枚星轨专票或星轨通票 |
| 获取 | 开拓任务、活动、每日实训、模拟宇宙、忘却之庭、混沌回忆、虚构叙事、末日幻影等 |
| 性质 | 付费货币（可由古老梦华兑换）与免费货币的统一计价单位 |

## 与信用点的区别

信用点是世界观里的通用结算货币，剧情中真实流通；星琼是游戏机制里的资源，剧情中不流通。

两者常被玩家混为一谈，是因为它们都以「钱」的形态出现。但在设定层面，它们属于两套系统：一套写给角色，一套写给玩家。

## 相关概念

- 跃迁：使用星琼或星轨票获取角色、光锥的机制。
- 古老梦华：付费获得的货币，可按比例兑换为星琼。
- 信用点：世界观中的通用货币，由星际和平公司发行。
