# 光锥

> 光锥是角色的属性与机制来源之一。每个角色都可佩戴一枚光锥。

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 装备 |
| 数量 | 每名角色一枚 |
| 稀有度 | 3 星、4 星、5 星 |
| 分类 | 按命途划分 |
| 主要来源 | 跃迁、星芒兑换、模拟宇宙商店、活动 |

## 三项效果

每个光锥提供三个效果：

1. **基础数值**：生命值、攻击力、防御力。
2. **额外数值提升**：百分比攻击力、暴击伤害、效果命中等，会出现在角色面板上。
3. **特殊机制**：例如「但战斗还未结束」的终结技恢复战技点；部分机制附带满足条件才触发的数值提升，会出现在战斗时的角色面板上。

与遗器不同，光锥的数值属于基础数值，因此会影响其他效果的百分比提升。

> 比如「余生的第一天」基础防御力为 463，「制胜的瞬间」为 595。对于两者提供的相同 24% 防御力提升效果，后者天然比前者多出约 32 点。

## 命途之分

光锥有命途之分。

特殊机制仅在命途与佩戴者一致时生效，而基础数值对所有角色都有提升。

这条规则决定了配装的基本逻辑：跨命途的光锥不是完全无用，但只能用它的白值，用不到它的灵魂。

## 获取

| 途径 | 说明 |
|------|------|
| 跃迁 | 可获得大部分光锥，其中部分 5 星仅可通过限定光锥跃迁获得 |
| 星芒兑换 | 600 枚「未熄的星芒」换取常驻 5 星光锥 |
| 模拟宇宙商店 | 使用模拟宇宙产出的代币兑换 |
| 活动 | 版本活动赠送，通常可叠影至 5 阶 |

## 设定层面

在世界观里，光锥记录的不是「一件东西」，而是一段命运：一个人的选择、一场战斗、一次诀别。

装备光锥的人，从中借用那段命运留下的力量。光锥有命途之分，也可以理解为：只有走在同一条路上的人，才听得懂那段命运在说什么。
