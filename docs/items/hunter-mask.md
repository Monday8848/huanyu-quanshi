# 谒者面具

> 面具一旦被佩戴，即与谒者绑定，呈现其灵魂的形状。

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 神赐道具 |
| 数量 | 每届八张 |
| 作用 | 参赛资格、增强能力 |
| 来源 | 阿哈 / 幻月 |
| 首次登场 | 4.0 版本 |

## 作用

面具是幻月游戏的入场券。

海选中夺得面具的八位玩家，才能正式成为「谒者」。面具一旦佩戴，就与谒者绑定，呈现其灵魂的形状，并增强谒者原本的能力。

## 代价

面具放大能力，也放大欲望。

戴久了的人，很难说清哪一面才是自己。归寂戴上面具后，把整座乐园变成末日妖都——那或许就是他灵魂的形状。

## 4.x

4.0 中，真珠手握三张面具，火花抢先唱名，爻光把面具授予星期日，绯英把浣熊面具借给开拓者。

4.7 结尾，谒者们归还面具。游戏结束，面具留下。
