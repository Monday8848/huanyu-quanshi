# 谒者面具

> 面具一旦被佩戴，即与谒者绑定，呈现其灵魂的形状。

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 神赐道具 |
| 数量 | 每届八副 |
| 初始形态 | 无特征的空白面具 |

| 首次登场 | 4.0 版本 |

## 作用

面具是幻月游戏的入场券。

海选中夺得面具的八位玩家，才能正式成为「谒者」。面具一旦佩戴，就与谒者深度绑定——像注册账号那样。

绑定之后，面具会依佩戴者灵魂的形状改变特征，并增强谒者原本的能力。

## 空白面具会挑主人

这是《谒者面具的三两事》里被反复批注的一条：

> 空白面具似乎有着选择主人的意识，它们总是会在机缘巧合下「逃离无趣」，落入那些更具「欢愉」潜质的人手中。或许这也是「欢愉」混沌性的一种体现。

所以面具不是被找到的，是被「选中」的。

## 可以被击碎

面具并非不可毁。足够的外力冲击或命途能量都能击碎它。

失去面具的谒者在游戏中视为出局。而无论有多少面具在游戏中被摧毁，下届游戏开始前，总会出现八副空白面具。

那些被毁面具里搜集的愿力去了哪里？现有线索只支持两种猜测：

1. 直接逸散到哈托彼亚的大气中，无法被搜集利用（或许是野生尘灵的愿力来源）；
2. 转移去某个不可知的地方，或被用于支付重塑面具的花费。

> 若是后者，如此多届幻月游戏下来，其积攒的愿力必然是个天文数字。

## 游戏结束之后

每场幻月游戏结束后，面具会褪去颜色，重归空白，以洗去谒者留下的信息。

被摧毁的面具也一样，只是回归得慢一些：一般会在三至五年内逐渐出现在二相乐园各地，引发小范围的面具哄抢潮——但通常只是在争夺赝品。

也不乏例外。某一届结束后，天上的幻月像吐瓜子一样把八张面具射向大地，造成了部分公共设施损坏。

未损毁的面具会留在佩戴者手中，但谒者不能二度参赛，空白面具对他们本人毫无用处。而且因为「逃离无趣」的原理，它们往往会在下次游戏前与旧主失之交臂。

一些谒者会把面具传给下一代，这已是好结果。更多时候，失去欢愉赐福的谒者必须想办法把面具转赠出去，以防招来抢夺乃至杀身之祸。

> 上上届幻月游戏的谒者泽莫被发现于家中惨死，妻儿亦未能幸免。其所留的空白面具不翼而飞……怀璧其罪啊。

## 代价

面具放大能力，也放大欲望。

戴久了的人，很难说清哪一面才是自己。归寂戴上面具后，把整座乐园变成末日妖都——那或许就是他灵魂的形状。

## 4.x

4.0 中，真珠手握三张面具，火花抢先唱名，爻光把面具授予星期日，绯英把浣熊面具借给开拓者。

4.7 结尾，谒者们归还面具。游戏结束，面具留下。
