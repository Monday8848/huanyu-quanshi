# 物品

分两层：**有来历的物件**单独开条（能写出一整页故事），**成体系的大量物品**逐条开词条并按集合分组。

## 收录边界

- **进条目的**：有独立背景叙述、与剧情或设定强相关的物件（星核、星琼、星轨通票、开拓者的车票），以及全部光锥——每条光锥的「光锥故事」都是官方原文收录。
- **进总表的**：遗器、行迹材料、通用素材——数量大、信息结构统一，用表格承载比开几百个页面更实用。
- **不收的**：纯数值道具（经验书、信用点）、限时活动道具。
