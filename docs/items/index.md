# 物品

分两层：**有来历的物件**单独开条（能写出一整页故事），**体系类物品**收在总表（只列名称与基本属性）。

## 已收录

- **[星核](./star-core)** —— 被称作「万界之癌」的东西，也是雅利洛-VI 活下来的唯一原因。

星琼、光锥、遗器、星轨通票，以及光锥／遗器的全量总表。

## 收录边界

- **进条目的**：有独立背景叙述、与剧情或设定强相关的物件（星核、星琼、星轨通票、开拓者的车票）。
- **进总表的**：光锥、遗器、行迹材料、通用素材——数量大、信息结构统一，用表格承载比开 400 个页面更实用。
- **不收的**：纯数值道具（经验书、信用点）、限时活动道具。
