# 星核

> 被称作「万界之癌」的东西。它寄生在星球上，扭曲现实，也常常成为某些文明活下去的唯一指望。

## 定义

星核是散落在宇宙中的高密度能量体，来源不明，官方文本只给出「与星神有关」这一层模糊关联。它的运作方式更接近寄生：落在一颗星球上，就地扎根，改变周围的物理规则，然后缓慢地把整颗星球变成它的养料。

被星核寄生的世界，通常会出现三种症状：环境剧变、空间裂隙、以及某种「愿望成真」的异常现象。这也是它最危险的地方——它给的东西太像恩赐，以至于很多文明明知代价，还是选择用它。

## 已知星核

| 位置 | 状况 |
|------|------|
| 雅利洛-VI | 被贝洛伯格用作热源，城市因此得以在寒潮中存续 |
| 黑塔空间站 | 被收容研究 |
| 开拓者体内 | 由星核猎手植入，是开拓者能行走星际的原因之一 |

## 特性

- **扭曲现实**：星核周围的物理规则不稳定，空间裂隙与异常现象是常态。
- **提供能量**：它能输出远超常规能源的力量，这是文明愿意冒险使用它的原因。
- **带来灾变**：使用它的代价通常是环境崩溃。雅利洛-VI 的永冻，就是最直接的例子。
- **吸引注意**：星核的存在会引来反物质军团等势力的觊觎，也会引来星核猎手。

## 与星核猎手的关系

星核猎手的目标就是收集星核。他们为什么收集、收集之后要做什么，官方至今没有给出完整答案。已知的是：他们愿意为此付出极大代价，甚至不惜与星际和平公司为敌。
