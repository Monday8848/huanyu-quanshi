# 星核

> 这一现象极富侵略性，它以神秘物体「星核」的形式不断侵染相邻的世界——如同癌细胞一般在宇宙各处扩散。

| 项目 | 内容 |
|------|------|
| 别称 | 万界之癌 |
| 本质 | 扰乱虚数能量流向的高密度凝聚体 |

## 万界之癌

从某个时刻开始，诸派系开始关注同一种现象——在「开拓」创造的星际航路上，某些晦暗难明的物质扰乱了虚数能量的流向。

就像登山遇上峭壁悬崖、远航遇上海啸漩涡，原本通畅的星际旅途变得危机重重、前途未卜。

这一现象极富侵略性，它以星核的形式不断侵染相邻世界，如同癌细胞在宇宙中扩散。星际和平公司将其称为「万界之癌」，并警告星际旅客决不能心存侥幸：身陷万界之癌的世界早已迷途难返，鲜有人绝境逢生。

## 来源：同谐之癌

3.8 版本给出了目前最明确的答案：橡木鸣蛀之梦中，梦主「很久以前曾从家族特使处得知了星核的真相——**它源于希佩，实为『同谐之癌』**」。

「同谐之癌」这个命名与「万界之癌」形成了互文：以强援弱、融众为一的同谐命途，走到极端便是吞噬个体的癌症。这与星核总是伴随毁灭军团出现的现象并不矛盾——癌变的谐乐，正是毁灭最肥沃的土壤。

## 实现愿望

星核还有一个此前不为人知的特性——**它会实现愿望，但只以扭曲的形式实现**：

- 3.8 主线中，梦主诱使流萤在星核面前许下「想要活下去」的愿望。星核知晓格拉默铁骑行于「繁育」命途、与虫群共生同死，于是把愿望扭曲成：**寰宇蝗灾在梦境中诞生**；
- 开拓者体内的星核同样具有意志层面的交互——它回应过开拓者的愿望（2.x 剧情暗示），方式同样是扭曲的。

「许愿-扭曲实现」的机制解释了星核为什么被称作癌：它不是许愿机，而是把渴望放大成病灶的东西。

## 裂界

万界之癌蔓延之时，名为「裂界」的侵蚀现象也在悄然滋生。

博识学会认为两者存在因果关系：裂界由星核催生，将接触到的事物与空间转变为特殊的裂界造物。

裂界造物普遍以侵蚀的形式存在。它似乎保有原型的记忆与习惯，但外在表现大相径庭，往往表达出强烈的排他性。研究裂界的学者警告：被裂界侵蚀的物件与其原型应视为毫无关联的两种存在，对其抱有的一切幻想皆会引致严重后果。

除侵蚀以外，裂界还会记录被接触事物的以太信息，与自身保存的数据混合，产出经过嫁接的裂界造物。于是在每个被侵蚀的世界里，无数遗器、裂界怪物、甚至被神秘分隔的异空间诞生在各个角落。

## 特性

- **扭曲现实**：星核周围的物理规则不稳定，空间裂隙与异常现象是常态。
- **提供能量**：它能输出远超常规能源的力量，这是文明愿意冒险使用它的原因。
- **带来灾变**：使用它的代价通常是环境崩溃。雅利洛-Ⅵ 的永冻，就是最直接的例子。
- **扭曲实现愿望**：星核会对愿望做出回应，但总以扭曲的方式实现（见上文流萤事件）。
- **吸引注意**：星核的存在会引来反物质军团等势力的觊觎，也会引来星核猎手。

## 与星核猎手的关系

星核猎手的目标就是收集星核。他们为什么收集、收集之后要做什么，官方至今没有给出完整答案。

已知的是：他们愿意为此付出极大代价，甚至不惜与星际和平公司为敌；而开拓者体内的那一枚，正是他们计划的一部分。
