# 愿宝

> 愿力凝结成愿宝，成为乐园的通货。

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 通货 |
| 本质 | 凝结的愿力 |
| 相关协议 | 《愿宝与信用点兑换协议》 |
| 首次登场 | 4.0 版本 |

## 本质

愿宝是愿力的固体形态。

在二相乐园，心愿是一般等价物。人们对某件事的关注与相信，会凝结成愿宝，成为可以交易、储存、兑换的东西。

## 制度

乐园历 1855 年，公司颁布《灵物保护法》与《愿宝与信用点兑换协议》。

愿宝被纳入信用体系，与信用点挂钩。从此，想象也可以标价，幻造种也可以破产。

## 4.x

4.0 中，开拓者在二相乐园的日常交易、任务奖励，都以愿宝或乐园纪念币结算。

4.6 中，千星城的愿力循环崩溃，愿宝的供应随之紧张。灯塔献出自身愿力，才让幻造种暂时存续。
