# 遗器

> 「它就像是一种遗器，只不过更庞大……也更浓缩。」

## 基本信息

| 项目 | 内容 |
|------|------|
| 类型 | 装备 |
| 数量 | 每名角色六件 |
| 分类 | 隧洞遗器（四件套）、位面饰品（两件套） |
| 部位 | 头部、手部、躯干、脚部；位面球、连结绳 |
| 稀有度 | 2—5 星（无 1 星） |
| 主要来源 | 侵蚀隧洞、模拟宇宙、差分宇宙、战利品、历战余响 |

## 两套体系

遗器分两类，来源与原理都不同。

### 隧洞遗器（四件套）

外围的四件：头部、手部、躯干、脚部。

通过刷取「侵蚀隧洞」副本获取，地图中的战利品与「历战余响」也会掉落特定套装。

### 位面饰品（两件套）

中间的两件：位面球、连结绳。

位面饰品不是从遗迹里挖出来的，而是造出来的——黑塔利用裂界原理制造的人工遗器，数据来自「模拟宇宙」。

> 模拟裂界原理的人工遗器。理论中存在的世界将被封装在球状位面饰品中。

获取方式为模拟宇宙副本或差分宇宙的「位面饰品提取」，领取沉浸奖励。

## 功能

遗器的属性对角色最终属性的影响非常之大，因此为队伍选择契合的遗器是至关重要的。

每套遗器有自己的套装效果：装到指定件数，触发对应加成。玩家需要在「套装效果」与「主副词条」之间做取舍，这也是配装的核心乐趣。

## 解锁

遗器功能随主线推进解锁：

- 开拓任务「他们有多少人已掉进深渊」期间解锁遗器套装；
- 完成开拓任务「时不我待，我的朋友」后解锁位面饰品。

## 设定层面的意味

从世界观看，遗器是「过去的人留下的东西」。

隧洞遗器来自被裂界侵蚀的遗迹——裂界会记录被接触事物的以太信息，与自身数据混合，产出经过嫁接的造物。所以遗器往往带着原型的记忆与习惯，却不完全是原来那件东西。

位面饰品则更极端：它封装的不是实物，而是一个「理论中存在的世界」。黑塔把模拟宇宙里演算出的位面压缩成球，戴在人身上。

一个是挖出来的过去，一个是算出来的可能。
