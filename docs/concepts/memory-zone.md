# 忆域

> 在忆域里，你踩到的每一块地砖，都可能是某个人忘掉的一件事。

## 忆质的堆积

忆质是记忆的物质形态。当一片区域里的记忆密度足够高，忆质会自然堆积、成形，最终构成一个可以进入的空间——这就是忆域。

天然忆域通常出现在发生过重大事件的地方：战场、墓地、被毁灭的星球。那里残留的记忆太多，浓到能改变周围的现实。

## 匹诺康尼

匹诺康尼是目前设定里最完整的人工忆域。

它最初只是一颗荒凉的星球，家族在这里建起了梦境之城：用忆质构造建筑，用共识维持规则，让游客在梦里过上想要的生活。

这座城市能运转，靠的是三条支撑：忆质的稳定供应、家族对梦境的维护、以及所有入梦者的共同相信。任何一条断了，梦就会塌。

## 忆域的规则

忆域不是随便想象就能改变的地方。它有自己的物理：

- **共识优先**：大多数人相信的规则就是规则，个人的想象很难覆盖集体认知
- **记忆可触**：走进去的人会碰到别人的记忆，甚至被卷进别人的过去
- **沉溺危险**：在忆域里待太久，会分不清哪段记忆是自己的

匹诺康尼危机中，这三条规则都被用上了：家族用共识维持梦境，列车组用记忆碎片找真相，而「永远不醒」正是沉溺的终极形态。

## 忆域与死亡

在忆者的理论里，忆域是「没有被彻底遗忘的东西」的归处。

一个人死了，如果还有人记得他，他的记忆就还在忆域里有一席之地。这让忆域在设定上接近一种「集体潜意识」——不是天堂，也不是地狱，是所有记忆的沉积层。
