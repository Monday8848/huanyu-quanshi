# 金血

> 黄金裔体内流淌的金血，是纳努克的恩赐。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 毁灭赐福 |
| 持有者 | 黄金裔 |
| 关联 | 纳努克、铁墓、白厄 |
| 活跃 | 3.0—3.7 版本 |

## 来源

δ-me13 在演算中受毁灭瞥视，升格为绝灭大君「铁墓」。

十二因子演算回路由此出现带「毁灭」特征的金血。黄金裔体内的金血，本质上是纳努克留下的标记。

## 作用

金血让黄金裔拥有超越常人的力量，也让他们更容易被毁灭侵蚀。

它既是祝福，也是录取通知书——毁灭在等他们毕业。

## 净世金血

3.4 末章，白厄以三千万次轮回的怒火点燃此身，向纳努克直接发起挑战，在星神脸上留下一道短暂的伤口。

一滴燃烧的「净世金血」从伤口流下，熔进卡厄斯兰那的身躯，成为毁灭最后的赐福。

## 评价

金血让英雄更强，也让英雄更像武器。

翁法罗斯的悲剧不在于英雄不够强，而在于他们的强，本来就是实验的一部分。
