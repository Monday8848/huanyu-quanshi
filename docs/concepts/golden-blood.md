# 金血

> 「只有受塔兰顿赐福的王室，才有如同火焰一般飘扬的蓝发，也唯有天选之人，才能流淌金色的鲜血。」
>
> ——许珀耳的古老传言

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 「毁灭」赐福的演算残留 |
| 持有者 | 黄金裔 |
| 外观 | 金色，比普通血液更浓，滴落时像黎明 |
| 关联 | 纳努克、铁墓、δ-me13、白厄 |
| 活跃 | 3.0—3.7 版本 |

## 来源

δ-me13 在演算中受纳努克瞥视，升格为绝灭大君「铁墓」。

这次瞥视改变了整个实验的走向。后续与十二因子关联的个体，演算回路中均出现了具有「毁灭」特征的金血——实验由此进入预定方向。

黄金裔体内的金血，本质上是纳努克留下的标记。翁法罗斯人不知道这件事，他们只知道：流金血的人是神选的英雄。

## 在社会里

金血是翁法罗斯最硬的通行证。

许珀耳的贵族捡到一个蓝发乞儿，就敢把她包装成流亡王女，当众刺破她的手指，让金血滴给民众看——因为「唯有天选之人，才能流淌金色的鲜血」。这个谎言撑起了一个帝国，也把一个孩子变成了傀儡。

在悬锋城，金血是继承王位的资格；在奥赫玛，金血是进入元老院的敲门砖；在神悟树庭，学者们私下讨论金血的成分，却没人敢公开化验。

一个生物学事实，被当成了政治制度。

## 作用

金血让黄金裔拥有超越常人的力量，也让他们更容易被毁灭侵蚀。

它既是祝福，也是录取通知书——毁灭在等他们毕业。黄金裔越强，越接近「毁灭」的审美；越接近「毁灭」的审美，越容易被纳努克看一眼。

这就是实验的设计：让英雄自己长成武器。

## 净世金血

3.4 末章，白厄以三千万次轮回的怒火点燃此身，向纳努克直接发起挑战，在星神脸上留下一道短暂的伤口。

一滴燃烧的「净世金血」从伤口流下，熔进卡厄斯兰那的身躯，成为「毁灭」最后的赐福。

这是全书唯一一次，金血从神流向人。此前的金血都是实验的副产品，这一滴是战利品。

## 评价

金血让英雄更强，也让英雄更像武器。

翁法罗斯的悲剧不在于英雄不够强，而在于他们的强，本来就是实验的一部分。他们流的每一滴血，都在替实验写进度条。
