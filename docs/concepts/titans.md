# 泰坦

> 「泰坦自火中降生，三者开辟天地，三者编织命运，三者捏塑生命，三者引渡灾祸。」

## 基本信息

| 项目 | 内容 |
|------|------|
| 数量 | 十二位（另有第十三位「德谬歌」） |
| 分组 | 支柱三、命运三、创生三、灾厄三 |
| 标志 | 各持一枚火种 |
| 本质 | 维系天地的力量、从古至今的命运、世间万物的规则 |
| 人称 | 官方中文文案用「它」，英文文案与星神同用 They |
| 活跃 | 3.0—3.7 版本 |

## 起源

泰坦自火中降生。

它们不是被谁创造的，也不是从某个神系里分裂出来的。它们就是翁法罗斯的物理法则本身——天为什么亮、地为什么稳、人为什么死，这些问题的答案在泰坦身上。

十二位泰坦分四组，每组三位，各司一类根本问题：

| 组 | 成员 | 管什么 |
|----|------|--------|
| 支柱三泰坦 | 艾格勒（天空）、吉奥里亚（大地）、法吉娜（海洋） | 开辟天地，撑起世界的物理框架 |
| 命运三泰坦 | 欧洛尼斯（岁月）、塔兰顿（律法）、雅努斯（门径） | 编织命运，规定时间、秩序与通路 |
| 创生三泰坦 | 墨涅塔（浪漫）、刻法勒（负世）、瑟希斯（理性） | 捏塑生命，赋予情爱、形体与思考 |
| 灾厄三泰坦 | 扎格列斯（诡计）、尼卡多利（纷争）、塞纳托斯（死亡） | 引渡灾祸，处理混乱、暴力与终结 |

## 神体

泰坦的神体往往不是「一个身体」：

- **艾格勒**是百眼巨鸟，天幕就是它的眼睑。
- **吉奥里亚**是所有山脉，你无法为它画一张脸。
- **法吉娜**是所有水体，海、河、酒杯都是它。
- **欧洛尼斯**是独眼发光的巨人。
- **塔兰顿**是一具悬空的天平，无形支柱。
- **雅努斯**是双面神明，一面看去路，一面看来路。
- **墨涅塔**是金色蝴蝶，也可以化作人形。
- **刻法勒**是四臂巨人，坐在全世之座上。
- **瑟希斯**是一棵巨圣树。
- **扎格列斯**是一枚翻飞的硬币，一张笑、一张哭。
- **尼卡多利**是身着洁白圣甲的高贵武者。
- **塞纳托斯**是紫色巨龙。

神体的大小决定了权柄的边界：占满天空的管天空，铺满大地的管大地，而「无形」的那一位，管的是所有看得见的东西背后的规则。

## 泰坦与星神

泰坦不是星神，但它们与星神之间存在一种「共轭」关系。

第十二组因子演算出的泰坦与黄金裔，是对星神与命途行者的模拟：泰坦对应星神，黄金裔对应令使或命途行者；火种对应命途，试炼对应「瞥视」。

第十二组因子的目的，是让「毁灭」的方程式完成自我迭代。所以泰坦的兴衰不只是翁法罗斯的神话，它是一场实验的中间变量。

欧洛尼斯称记忆星神浮黎为「天父」，是这种关系最直白的一次泄露。

## 泰坦之死

泰坦不是不死的。

它们会失神、会发疯、会被黑潮侵蚀，也会被黄金裔击落。死后留下火种，火种被带回奥赫玛，等待下一个继承人。

已确认的泰坦结局：

| 泰坦 | 结局 | 版本 |
|------|------|------|
| 尼卡多利 | 不死神躯被破，3.1 被万敌击落 | 3.0—3.1 |
| 欧洛尼斯 | 3.1 被盗火行者杀死，火种被夺后夺回 | 3.1 |
| 塞纳托斯 | 3.2 火种由遐蝶归还，泰坦不复存在 | 3.2 |
| 瑟希斯 | 3.1 失去神体，3.2 火种归还 | 3.1—3.2 |
| 艾格勒 | 3.3 被逐火小队击败 | 3.3 |
| 吉奥里亚 | 黄金战争期间陨落，地坼之灾 | 背景 |
| 刻法勒 | 主动献出火种，3.4 由白厄接过 | 3.4 |

## 第十三位

最初智种「德谬歌」是翁法罗斯的第十三位泰坦，被称为「创世之泰坦」「翁法罗斯之心」，却在演算中被剔除。

昔涟的忆灵以它为名。被删掉的那一位，最后成了记忆的容器——这是整个翁法罗斯最残酷的一个双关：世界删掉了自己的创世神，然后把那个位置留给了记忆。
