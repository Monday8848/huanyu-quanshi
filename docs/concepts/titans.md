# 泰坦

> 泰坦自火中降生，三者开辟天地，三者编织命运，三者捏塑生命，三者引渡灾祸。

## 基本信息

| 项目 | 内容 |
|------|------|
| 数量 | 十二位（另有第十三位） |
| 分组 | 支柱、命运、创生、灾厄 |
| 标志 | 各持一枚火种 |
| 活跃 | 3.0—3.7 版本 |

## 支柱三泰坦

- **艾格勒**：天空之泰坦，晨昏之眼。掌天空、天体、昼夜循环。
- **吉奥里亚**：大地之泰坦，磐岩之脊。掌大地、耕作、历史。
- **法吉娜**：海洋之泰坦，满溢之杯。掌大海、风暴、蜜酿与宴会。

## 命运三泰坦

- **欧洛尼斯**：岁月之泰坦，永夜之帷。掌岁月、夜幕、记忆。
- **塔兰顿**：律法之泰坦，公正之秤。掌律法、公正、边界。
- **雅努斯**：门径之泰坦，万径之门。掌门径、道路、隔绝与监禁。

## 创生三泰坦

- **墨涅塔**：浪漫之泰坦，黄金之茧。掌美与爱。
- **刻法勒**：负世之泰坦，全世之座。掌全知全能、创生。
- **瑟希斯**：理性之泰坦，裂分之枝。掌理性、智慧、植物荣枯。

## 灾厄三泰坦

- **扎格列斯**：诡计之泰坦，翻飞之币。掌谎言与机运。
- **尼卡多利**：纷争之泰坦，天谴之矛。掌纷争、竞技、鲜血与献祭。
- **塞纳托斯**：死亡之泰坦，灰黯之手。掌死亡、湮灭、引渡亡魂。

## 第十三位

最初智种「德谬歌」是翁法罗斯的第十三位泰坦，被剔除在演算之外。

昔涟的忆灵以它为名。被删掉的那一位，最后成了记忆的容器。
