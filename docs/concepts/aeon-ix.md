# Ⅸ

> 「你尽可仰望璀璨的繁星，但切忌凝视虚无的深渊……那片黑雾中空无一物，仅一瞥便足以令凡人摒弃理智。」
>
> ——混沌医师慕榕

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 虚无 |
| 形态 | 沉眠于深渊的黑色神体 |
| 交往 | 不与任何星神往来 |
| 主张 | 宇宙的本质是虚无，因而存在毫无价值 |
| 派系 | 混沌医师、第Ⅸ机关、自灭者 |

## 一个谜

「虚无」的存在是一个谜，祂的形象被层层叠叠的迷雾包裹着。

Ⅸ不与其他星神往来。祂相信多宇宙的本质乃是虚无，因而存在毫无价值。

## 一瞥的两种后果

当某个存在无意中产生「存在是虚无的」这一思想并引之为箴，就会踏上Ⅸ的命途，接受来自虚空的一次无意义瞥视。

- 一者自此颓唐，成为[自灭者](/factions/self-destroyers)；
- 一者被神性倾倒，产生反抗之心，成为[混沌医师](/factions/chaos-doctors)。

## 一个未解的问题

天才俱乐部#64「原始博士」失踪前曾问：倘若Ⅸ真的对宇宙视若无睹，「虚无」的命途何以存在至今？

也许当自灭者茫然行于星海，同时也是在将祂的阴影投向宇宙各地。
