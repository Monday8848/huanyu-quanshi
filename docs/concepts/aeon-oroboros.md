# 奥博洛斯

> 「虫蚁之于飞禽，野兔之于狼犬，星尘之于黑洞，诸界之于贪饕。」
>
> ——仙舟，《寰宇通鉴》

| 项目 | 内容 |

| 命途 | 贪饕 |
| 形态 | 会思考的黑洞 |
| 身份 | 星神／古兽（双重存在） |
| 习性 | 吞噬诸界，永无餍足 |

## 双重存在

诸界渴饮者，永无餍足的吞噬者，会思考的黑洞。既是星神，又是古兽的双重存在。

## 生命是浮藻

在奥博洛斯看来，生命是虚空海洋中明灭的浮藻，终将随着诞生它们的星辰归于黑暗——这片黑暗就在祂的口中。

## 与存护的关系

克里珀知晓「大敌」的吞噬迫在眉睫，因此以光年为单位铸造障壁，封印并保护尚有生机的世界。

这个「大敌」是否就是奥博洛斯，智库未给出明证；但银河中能与「吞噬诸界」对应的存在，只有这一位。
