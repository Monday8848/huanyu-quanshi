# 墨涅塔

> 「黄金之茧。」
>
> 它与它的眷属们追逐着世间的美好，编入金丝，织作世间的浪漫，令翁法罗斯的众生拥有情爱。

## 权柄

墨涅塔掌管的不是「恋爱」，是让世界值得被爱的那部分。

- **美**：它把世间的美好编入金丝，织成可以被看见、被触摸的形。
- **爱**：它让众生拥有情爱。这不是恩赐，是诅咒——有了爱，就有了失去。
- **情**：欢喜、嫉妒、眷恋、不甘，所有说不清的东西都归它管。

## 神体与金丝

墨涅塔的形象是金色蝴蝶，也可以化作人形。它的神体是一枚茧——不是把自己包起来，是把整个世界包起来。翁法罗斯人相信，「浪漫」的信徒死后若被塞纳托斯送入残茧，就会蜕生为蝶，继续伴于泰坦左右。这是独属于浪漫一脉的葬礼。

它的权能落在金丝上。金丝不是线，是命运的可视化：一根丝连着一个名字，丝断了，人就散了。阿格莱雅被称为「黄金的织者」，正是因为她在奥赫玛的政坛上，用金丝把众人的命运彼此连缀。

## 墨涅塔与瑟希斯

墨涅塔与理性的瑟希斯是爱侣。

瑟希斯因意外失去神体后，墨涅塔无法接受爱人负伤的事实，搜集它四散的身躯，想用丝线把碎片收拢、令它回归。二人曾经的眷属也自发加入这场搜集，它们就是「创生若虫」。

这场缝补没有成功。瑟希斯最终以圣树的形态重新立在神悟树庭，墨涅塔则把剩下的丝留给了人间——所以翁法罗斯的浪漫总带着一点缝补的痕迹：花是接上去的，情是补过的，爱是明知道会断还要织的。

## 历史

**3.0 版本**，阿格莱雅已是「浪漫」的半神，也是逐火之旅的领导者。她身为织者，亲自穿针引线，召集世间英雄再度踏上漫长的征途。

**3.3 版本**，阿格莱雅借元老院与清洗者之手，以自己的落幕为逐火扫清前路。她在奥赫玛政坛的最后一步，是把自己的死织进「团结」这件战袍里——以自身之死为丝线，为圣城留下最后一道护佑。

**第二轮回（3.5 版本之后）**，阿格莱雅接过刻律德菈留下的统领职责，率众抵抗来古士。光历 4029 年，她与奥赫玛九万民众一同赴死。那些曾经刺杀她的刺客，最后也站在了她身边。

## 火种与半神

| 环节 | 内容 |
|------|------|
| 火种 | 「浪漫」 |
| 归还 | 逐火之旅早期已回收 |
| 继承 | 阿格莱雅，「黄金的织者」 |
| 结局 | 3.3 陨落；第二轮回 4029 年战死 |

浪漫火种是十二枚里最早被回收的一批。它没有经历惨烈的弑神战——墨涅塔把火种交出去的时候，大概觉得这是它写过的最好的一个故事：把「爱」交给一个愿意为它死的人。
