# 伊德莉拉

> 「美，是值得献祭一切的唯一。」
>
> ——纯美骑士团的信条（转述）

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 纯美 |
| 别称 | 妙见天君（太卜司《星神论》）、恩·德芮（某些国度）、司美之神 |
| 信徒 | 纯美骑士团、揽镜人 |

## 司美之神

「纯美」命途之主，纯美骑士团与揽镜人称其为「伊德莉拉」。在某些国度，也有智慧生命称其为「恩·德芮」——《星神论》留下了这个罕见的异名。

## 殒落与遗物

《星神论》对祂的现状给出双重证据：

- 纯美骑士团四分五裂；
- 揽镜人流浪诸界寻找祂的圣物。

这些都足以证明祂已殒落。但本座与博识学会交换的卷宗提及：**若能将妙见天君的遗物寻获完整，便可重现其绝美之姿。**

殒落的星神能被「复原」——这个说法意味着伊德莉拉留下的不是尸体，而是散落的碎片；也意味着揽镜人的流浪与骑士团的分裂，都是一场没有尽头的拼图。

## 将美归于一尊

在更古老年代的神话里，伊德莉拉一度将众多星域的「美」归于一尊，祂向英雄、凶徒和凡人们展现宇宙图景中蕴藏的意义和美学，并驱使他们为取悦自己而完成惊人（但往往也是毁灭性的）功业。

《星神论》由此给出了对「纯美」命途意义的判断：**意识、见解与价值的统合。**

美不是装饰——在伊德莉拉的命途里，美是一种把散乱心智统一到同一处的东西。祂的殒落，也就是这场统合的崩解。
