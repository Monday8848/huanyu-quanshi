# 令使

> 若将凡人禀受星神感应、掌握命途力量的行动看作激起一朵碎裂的飞沫；那么「星神」长驱伟力驾驭命途的壮举，就如同推动跨越峰峦的海啸。

## 定义

在这天悬地隔之间，少数蒙受星神垂青的凡人，也可在星神应许下汲取命途能量，卷起侵蚀海岸的巨浪——这种存在被称为「令使」。

尽管他们并非完全听令于星神指派，但在世人看来，令使就是星神意志的代言使徒。

「令使」不是一个可以修炼到的境界，而是一种任命。没有星神的认可，再强的凡人也成不了令使。

## 不同星神，不同态度

不同的星神对于令使的态度并不一致，因此力量分享的程度也天差地别：

| 态度 | 结果 |
|------|------|
| 视作长臂延伸 | 慷慨地将命途对令使完全开放 |
| 无意创造令使 | 对世间争斗毫无兴趣，不设令使 |
| 随心所欲 | 肆意而为，据说阿哈会随机给予凡人命途之力，并随着心情将其玩弄于股掌之中 |

## 已知的令使

### 绝灭大君

毁灭星神纳努克的令使。纳努克为各个世界上萌生毁灭冲动的强大生物投去一瞥，烙下印记、赐予力量。这些生物被由内向外反转，投身「战争洪炉」重新锤炼，以反物质补足其缺损，最终成为军团一员。

绝灭大君既是星神令使、毁灭意志的执行人，也是战争的艺术家、至臻化纯的毁灭兵器。每位大君都抱持独特的「毁灭」理念——这正是他们被拔升为使徒的原因：那绝对尖锐、绝对强烈的毁灭美学。

已知者：焚风、星啸、光逝、铸王、幻胧、铁墓、归寂。

### 钻石

星际和平公司的最高领袖之一，P47，存护令使。石心十人的基石由他授予——他是授予者，不是十人之一。

### 谐乐众弦

家族的同谐令使。同谐的反对者称，「谐乐众弦」不跟随某位具体凡人，而是希佩自身的一道道侧面，且在需要的时候化为家族中的任何一人。

已知的化身名号包括：「无限夫长」众命之阿伊里涅夫、「齐响诗班」众愿之多米尼克斯、「万籁剧院」众唱之康斯坦汀娜、「至福舞会」众乐之比雅特丽丝。

### 其他

官方陆续提到过若干位，但大多没有正面登场，身份与能力仍不完整。

## 力量与代价

令使的力量来自星神，因此也受制于星神。

这种制约不一定是命令式的，更像是存在层面的绑定：令使做什么，往往就是星神意志的延伸，哪怕它自己不这么认为。幻胧在罗浮的所作所为，就是这种「延伸」最直接的例子。

代价同样存在。成为令使意味着放弃一部分自我——至于放弃多少，取决于星神，而不取决于令使自己。

## 与命途行者的区别

| | 命途行者 | 令使 |
|---|----------|------|
| 力量来源 | 自行踏入命途，禀受遥远感应 | 星神应许，直接分享命途能量 |
| 门槛 | 靠信条、欲望与修炼 | 星神的一瞥与任命 |
| 上限 | 取决于自己 | 取决于星神愿意分享多少 |
| 归属 | 仍属于自己 | 从此不完全属于自己 |

## 争议

关于令使，最大的争议是：他们还有没有自由意志。

有人认为令使只是星神的工具，所有行为都可以追溯到星神的意志；也有人认为，令使在执行意志的过程中保留了判断空间——归寂在二相乐园的种种「角色扮演」，就不像纯粹的执行。

这个问题官方没有给出答案，也可能永远不会给。
