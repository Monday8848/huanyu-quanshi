# 忆灵

> 记忆命途行者把记忆凝成实体，让它替自己战斗。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 记忆实体 |
| 使用者 | 记忆命途行者 |
| 代表 | 衣匠、死龙、小伊卡、德谬歌、长夜、龙灵 |
| 活跃 | 3.0—3.7 版本 |

## 什么是忆灵

忆灵是记忆命途行者用记忆召唤出的战斗伙伴。

它不是宠物，也不是武器，而是一段被凝固的记忆：某个人、某件事、某个不愿忘记的瞬间。

## 翁法罗斯的忆灵

翁法罗斯的不少黄金裔拥有忆灵：

- 阿格莱雅的「衣匠」，由金线织成。
- 遐蝶的「死龙·玻吕刻斯」，以生命为代价作战。
- 风堇的「小伊卡」，负责治疗，也负责打人。
- 昔涟的「德谬歌」，以第十三泰坦为名。
- 长夜月的「长夜」，替她承受忘却。
- 丹恒·腾荒的「龙灵」，替队友挡下伤害。

## 代价

忆灵会替主人战斗，也会替主人记住主人想忘的事。

召唤忆灵不是免费的。每一次召唤，都是在提醒自己：有些东西，你还没放下。
