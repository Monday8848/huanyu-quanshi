# 雅努斯

> 万径之门。

## 权柄

雅努斯掌门径与道路。它让旅人相遇，也让命运分岔；门既是通道，也是牢笼。

## 神体与信仰

它既是通道，也是牢笼。门径之神让人相遇，也让人分开；它赐予道路，也赐予禁令。雅努萨波利斯是它的圣地，也是翁法罗斯地理意义上的中心。缇里西庇俄丝穿过万径之门，把自己分成千名信使，把救世的神谕送往各地。3.1 版本，缇宝接过门径火种。

## 与黄金裔

缇宝（缇里西庇俄丝）是它的火种继承者。击落泰坦、回收火种、通过试炼——这是黄金裔成为半神的唯一路径，也是泰坦退场的方式。
