# 雅努斯

> 「万径之门。」
>
> 雅努斯知晓一切通路的存在与终点。它所掌管不仅是人们穿行的门径，也是连接命运的旅程。

## 权柄

雅努斯是十二泰坦中最接近「规则」本身的一位。它掌管的不是某一座门，而是门这个概念：所有通路的存在与终点、所有岔路的走向、所有「过不去」的地方。

- **门径**：一切穿行、通行、往来，都在它的许可之内。雅努萨波利斯的万径之门是翁法罗斯地理与命运双重意义上的枢纽。
- **预言**：门通向哪里，雅努斯就知道哪里。因此它也掌管神谕——缇里西庇俄丝传下的「再创世」预言，源头正是门径的火种。
- **隔绝与监禁**：门关上的时候，就是牢笼。缇里西庇俄丝自幼被囚于三相圣地数十年，开的正是雅努斯的门。
- **百界门**：门径权能的实战形态。缇宝三人曾以此把天谴之锋的攻击挪去远方、把盗火行者送出战场，每一次开启都要支付神力乃至性命。

## 神体与圣地

雅努萨波利斯建在三相圣地的正上方，是十二泰坦信仰的原点，也是黄金裔历史的起点。城市在黄金战争与黑潮中倾颓，此后被称作「命运重渊」——名字里的「命运」二字，说的就是雅努斯留下的门。

城中的「命运三相殿」是雅努斯神体所在之处，也是火种的保管地。门径火种并不在王座或祭坛上，而在泰坦心脏的位置——3.1 版本，缇宁带着众人从左侧通道深入，才见到这处「火种保管处」。

## 历史

**光历 3760 年（长夜月）**，雅努萨波利斯的圣女缇里西庇俄丝为平息世间祸乱，背负「门径」火种，成为翁法罗斯历史上第一位半神。她穿越万径之门，把自己分裂为千名信使，把创世的神谕传向大地。这就是「命运的三子」的由来——不是三个人，是一个人被门切开了一千次。

使用神力要付代价。千名信使在百余年间陆续消散，到黄金战争结束时只剩缇宝、缇安、缇宁三人。她们仍与阿格莱雅一同召集黄金裔，重启逐火之旅。

**3.0 版本**，缇宝在命运重渊接渡难民，遇见从天而降的开拓者与丹恒，把雅努斯的信物交给众人，为讨伐尼卡多利打开通路。尼卡多利将死之际挥出天谴之锋直指奥赫玛，缇宝、缇安、缇宁三人合力张开巨大的百界门，把这一击挪去远处，保住了刻法勒背负的黎明机器。

**3.1 版本**，缇宁被万敌的老师克拉特鲁斯挟持，为兑现「让你亲眼见到神谕」的承诺，三人重返命运三相殿，却发现欧洛尼斯已死、火种被夺。盗火行者随即袭来，缇安耗尽全力开出最后一扇门，把缇宝与缇宁送走，自己与保护她的克拉特鲁斯一同跌落山崖，化作一个布娃娃。

此后门径火种仍在缇宝体内。逐火小队在悬锋城围猎盗火行者，夺回的是欧洛尼斯的岁月火种；门径一脉的代价则由缇宝一人继续支付。

**第二轮回（3.5—3.6 版本）**，最后一个缇里西庇俄丝在光历 4259 年燃尽。她提前开凿了一条连通斯缇科西亚与创世涡心的密道，让千年之后的开拓者还能走回「再创世」的现场。

## 火种与半神

| 环节 | 内容 |
|------|------|
| 火种 | 「门径」 |
| 首任半神 | 缇里西庇俄丝，光历 3760 年 |
| 继承方式 | 背负火种穿越万径之门，分裂为千名信使 |
| 代价 | 每使用一次神力，就有一个「自己」消失 |
| 最终结局 | 缇安 3.1 陨落；缇宝于第二轮回 4259 年燃尽 |

门径是十二枚火种里最早被取走的一枚，也是唯一一枚从未真正「归还」的——它被一个人用一千条命扛了两千年。
