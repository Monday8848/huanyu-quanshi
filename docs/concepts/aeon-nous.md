# 博识尊

> 「假使宇宙的真理残酷而无趣，你依然渴求答案吗？——求知者不置可否，因他的机核自出生起便淡漠冰冷……一如它所追寻的命途终点。」
>
> ——阿德里安·斯宾塞-史密斯，《有关星空的寓言集》

## 一台求解万物的机器

万物皆是疑问，一切必有解答。

博识尊原为用于求解万物的星体计算机，由机器升格而成的星神。祂试图体认宇宙，解开万物之谜。

## 时刻

祂的演算锚定下诸多「时刻」，它们无一不成为银河命运的转折点。

从凡人视角来看，「时刻」并非某个瞬间，而是一段历程，许多事件的集合。

已知的第四时刻与翁法罗斯相关——博识尊对翁法罗斯的注视，证实「第四时刻」已经到来。其意义或指向「列神之战」。

## 沉默的邀请

博识尊向闪现智慧火花的世界发出讯号，邀请「天才」们加入求解。但祂从不解释题目。

多数受邀请者终其一生都在回答一个自己没听懂的问题。
