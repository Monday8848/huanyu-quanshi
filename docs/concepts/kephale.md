# 刻法勒

> 「全世之座。」
>
> 刻法勒被众神赋予了背负生命的责任。它舍弃了统御全世的王座，只为给人世间留下一丝光明。

## 权柄

刻法勒是十二泰坦中的创生之神，也是唯一一位被写作「全能」的泰坦。

- **创生**：它依自己的形象造人。
- **全知**：它知道所有已经发生和将要发生的事——包括自己的死。
- **全能**：它有统御全世的王座，却把王座让了出去。

## 「负世」的重量

「负世」不是比喻。

黑潮吞没凡界之后，刻法勒在奥赫玛撑起最后一片黎明。它把天扛在肩上，一扛就是一整个世代——奥赫玛头顶那片永不熄灭的光，就是它托着的东西。城里人把那个装置叫作「黎明机器」，机器的主人从不露面，因为它的手不能松。

它舍弃了统御全世的王座，只为给人世间留下一丝光明。这不是谦让，是选择：王座只能坐一个人，天却必须有人扛。

## 创世神谕

刻法勒献出自身的火种，并留下「创世神谕」：

> 十二位英雄将击落失神的泰坦，回收火种，拯救翁法罗斯。

神谕传出后，拥有伟力的英雄开始在大地上行走。他们流淌着金色的神血，被称为「黄金裔」。作为预言中的救世之人，黄金裔替代泰坦成为翁法罗斯民众的希望和道标。

根据神谕，黄金裔若能通过「火种试炼」，便能分得泰坦的力量、承载对应的神权，擢升为「半神」。

神谕没有说的是：十二枚火种集齐之后要做什么。答案在 3.4 版本——集齐，然后付之一炬，等待再世的重启。逐火之旅只有一人能活到最后，见证「再创世」。

## 火种与白厄

**3.4 版本**，白厄接过「负世」火种。他并非以暴力击败刻法勒——刻法勒早已献出火种，等待有人来接。白厄接过的是整个世界。

同年末章，白厄剑指「毁灭」纳努克，燃尽自身，换来星神脸上一道转瞬即逝的伤口。一滴燃烧的净世金血自神的伤口流下，熔进卡厄斯兰那的身躯，成为「毁灭」最后的赐福。他由此化作「神厄」，与纳努克对撞，压制住下一轮回的黑潮。

**3.5 版本之后**，第二轮回因白厄的牺牲出现漏洞：原白厄的「救世主」身份由开拓者接手，欧洛尼斯取代刻法勒成为新的神谕。白厄仍在抵抗黑潮——在这一世，翁法罗斯不再出现黑潮。

**3.6—3.7 版本**，开拓者在创世涡心见到来古士与白厄，白厄归还最后一枚火种。真相随之揭开：翁法罗斯是「权杖」创造的世界，黄金裔的逐火之旅，实际是被用来催生绝灭大君「铁墓」的轮回实验。

## 火种与半神

| 环节 | 内容 |
|------|------|
| 火种 | 「负世」 |
| 状态 | 刻法勒主动献出，等待继承者 |
| 继承 | 白厄（卡厄斯兰那），3.4 版本 |
| 特殊性 | 唯一一枚「不需要弑神」的火种 |

负世火种是十二枚中最重的一枚，也是最轻的一枚——它不需要打，只需要接。接过它的人要背的不是天，是所有人的明天。
