# 纳努克

> 「在宇宙的中心有一团火种。它愈烧愈旺，直到燃尽了整片星河——只为在一切现实的终点迎来壮美的埃灭。」
>
> ——阿德里安·斯宾塞-史密斯，《有关星空的寓言集：结局及其四行尾注》

## 破坏之神

《星神论》的评述直截了当：虽然出现最晚，但纳努克及其爪牙已可称得上银河首恶了。祂及其座下令使率领反物质军团侵攻一切存有文明的世界，将之化为灰烬。

联盟与烬灭军团的大小战斗记录已逾万条；斥候情报中，开始频繁缺失某些曾与仙舟建立文明交流的星球近况——在仙舟人看来，「也许在不久的未来，联盟所面对的大敌将不止孽物一种」。

## 一瞥与烙印

《绝灭大君图鉴》记载了纳努克擢升信徒的方式：行于毁灭命途的星神纳努克，为各个世界上萌生毁灭冲动的强大生物**投去一瞥，并为其烙下印记，赐予力量**。

这些强大的生物被由内向外反转，投身「战争洪炉」的世界中重新锤炼，以反物质补足其缺损，最终成为军团的一员。

## 绝灭大君

响应着「毁灭一切」的愿望，军团中出现了各自的统领者「绝灭大君」。他们既是星神令使、毁灭意志的执行人，也是战争的艺术家、至臻化纯的毁灭兵器。每位大君都抱持独特的「毁灭」理念——研究者认为，他们被拔升的原因正在于**这绝对尖锐、绝对强烈的毁灭美学**。

图鉴中还留有假说：大君们身受纳努克赐福，是为焚灭命途而生的「反物质弹」——倘若生命以负熵为食，一切行为都注定促成「毁灭」；而在万物归熵的终点，「毁灭」将与银河一同终结。

## 四末说的倒计时

厄兆先锋流传的「四末说」预言：四条命途会将银河推向「终末」的结局，「毁灭」是其中之一。该假说猜测：**纳努克作为最后出现的星神，其诞生便意味着「星神」这一概念在宇宙层面进入了倒计时阶段。**

换句话讲：宇宙已经不再有能力孕育新的星神了——祂是最后一个。往后的故事只有存量和坠毁。
