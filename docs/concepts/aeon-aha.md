# 阿哈

> 「神明拨弄银河时的一声感慨。」
>
> ——假面愚者的漫画台词

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 欢愉 |
| 别称 | 常乐天君（太卜司《星神论》）、诡计之神 |
| 信徒 | 假面愚者、悲悼伶人 |
| 特质 | 可能以人形示现 |

## 诡计之神

假面愚者与悲悼伶人称其为「阿哈」。如果非要在星神的运行方式中划出一个「神性」与「凡性」的尺度，**阿哈一定是相当接近「凡性」一侧的星神**——《星神论》如此定位。

祂会拨弄智慧生灵的悲喜爱恨，并促成命运的颠覆与转折——按照其信众的说法，祂本人也对此乐在其中，甚至会**以人形示现，推波助澜**。

## 并非丑角

《星神论》特意纠正了一个常见误解：

> 如果有人认为这位常乐天君仅仅是众神中的丑角，那就大错特错。是的，祂确实不能像帝弓司命或补天司命那般留下震惊寰宇的神迹。但祂以某种看不见的手段，无形中左右着众生的去向，显示出对现实非同一般的精妙操控。

书中举例：帝皇鲁珀特征服星海的时代，祂的信众在「哲学家联合」沦为无机生命的领土后于当地再度掀起叛乱，并以名为**「哲人鸩酒」的幽默悖论病毒**侵染了征服者们的运算中枢，推翻了当地机械军团的暴政。

「类似的神迹比比皆是，一圈微不足道的涟漪，最终演变成了地动山摇的海啸——这便是阿哈的行事风格。」

## 愚者与伶人的合谋

4.x 版本中，自称阿哈的花火披露了一个正在运作的计划：愚者和伶人可不是阿哈的私兵，酒馆甚至连门都不让她进——但只要告诉愚者「有个自称阿哈的疯子要哄骗伶人共赴贪饕之口的乐子之旅」，再告诉伶人「想拯救宇宙，必须在愚者面前演一出拱卫阿哈的好戏」，双方马上就会聚到一起，假装握手言和，**互相以为自己把对面骗得团团转**。

对付贪饕的方案，是让欢愉的信徒们演一出谁也不知道全貌的戏。
