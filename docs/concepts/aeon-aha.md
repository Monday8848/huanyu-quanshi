# 阿哈

> 「智识是坨废铁，存护是个呆子；巡猎毫无幽默感，毁灭像个疯子。星神都一根筋，阿哈真没面子！」
>
> ——某位通晓天文（自称）的假面愚者

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 欢愉 |
| 特征 | 行为不可预测 |
| 主张 | 欢乐是智慧生灵的特权 |
| 派系 | 假面愚者、悲悼伶人 |

## 智慧生灵的特权

懂得欢乐是智慧生灵独有的权利。顽石与星辰都无从体察生命的幽默。

阿哈鼓舞信徒享受生命的欢愉，自命运刀锋般的转折中寻求快乐。

## 祂寻求什么

- 寻求棋逢对手的敌人；
- 寻求消磨光阴的游戏；
- 寻求不问胜负的结局；
- 寻求捧腹绝倒的笑谈；
- 寻求阴差阳错的误会；
- 寻求神思飞舞的歌谣。

## 悲悼伶人

一个以「欢愉」为命途的星神，其信徒里却有一支专门哀悼的团体——[悲悼伶人](/factions/mourning-actors)。他们同样行走在欢愉命途上，只是选择了以悼亡的方式表达它。
