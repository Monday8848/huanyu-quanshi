# 吉奥里亚

> 「磐岩之脊。」
>
> 所有山脉都曾是吉奥里亚的神体化身，它是体积最大，也最温和、善良的泰坦，人世的守护神。

## 权柄

吉奥里亚不是「住在大地上」的泰坦，它就是大地。

- **大地与山脉**：翁法罗斯的每一道山脊都是它身体的一段。山会移动，因为它在翻身；山会塌，因为它在受伤。
- **耕作**：它让种子发芽，让土壤记得什么作物在什么时候该熟。
- **历史**：它替人世记住每一次耕种与每一场战争。岩石是翁法罗斯最古老的档案，一层一层压着几千年的账。

## 神体与山之民

在所有泰坦的画像里，吉奥里亚是最难画的一位——你无法为「所有山脉」画一张脸。翁法罗斯人索性不画它，只在山口堆石为记：一块石头是一句祷词，一堆石头是一座教堂。

山之民与大地兽是它的造物。山之民世代守山，把开矿、筑路、耕作都当作对神体的触碰，动土之前要先问山。大地兽则是它散落在地上的碎屑，温顺、缓慢、记路。

## 大地之死

黄金战争期间，刻律德菈的军队讨伐吉奥里亚。山之民与大地兽死战不退，最后是巨龙荒笛独自跃入深渊，与泰坦的神体一同沉下去。

三日后，大地火种浮出深渊。

吉奥里亚之死引发地坼之灾：山脉移位、地面开裂、城邦陷落。荒笛在这一片崩裂中继承大地神权，以自身熔合裂土，把翁法罗斯重新拼起来。它因此被追封为「掣地爵」——掣，是拉住、拽住的意思；它拉住的是整块大陆。

## 火种与半神

| 环节 | 内容 |
|------|------|
| 火种 | 「大地」 |
| 归还 | 黄金战争期间，具体年份史书失载 |
| 首任继承 | 荒笛（巨龙），追封「掣地爵」 |
| 第二任 | 丹恒·腾荒，3.6 版本 |
| 特殊性 | 大地火种归还最早，对应黄金裔却最晚现身 |

大地是十二枚火种里「最早归还、最晚有主」的一枚。在很长一段时间里，逐火小队知道火种在，却不知道谁该接过它——直到丹恒在第二轮回中与荒笛共鸣，以「腾荒」之名接续大地路径。

**3.6 版本**，丹恒借大地神权定位并救出被困的开拓者。这一步是第二轮回翻盘的关键：没有大地，就没有立足之处。
