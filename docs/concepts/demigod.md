# 半神

> 「击落泰坦、回收火种、填补神职，只是黄金裔的使命。」
>
> 缇里西庇俄丝接过雅努斯的火种，成为第一位半神。此后诸多黄金裔英雄通过试炼，接过泰坦神权，成为半神，维系着世间秩序。

## 什么是半神

半神不是「一半的神」，是「替神值班的人」。

泰坦失神或死去后，火种无人看守。黄金裔通过试炼接过火种，成为新的半神，替泰坦守住权柄，也替凡人挡住黑潮。

这个职位没有神座，也没有神庙。半神住在城里，会生病、会疲惫、会老，只是不能辞职。

## 成神流程

1. **让泰坦陨落**——或者让泰坦自愿交出火种。
2. **获得火种**——火种可以与泰坦分离，不必等它死。
3. **交火种开启试炼**——试炼与火种提交可以脱钩。
4. **接过神权**——成为半神。

四步看似清晰，实际每一步都在被剧情修改。规则越修越宽，是因为翁法罗斯等不起了：黑潮不按规则走。

## 代价

成为半神，意味着把一部分人性交出去。

- 刻律德菈献祭五百名黄金裔，再把自己当作最后一枚棋子掷出棋局。
- 阿格莱雅以自身之死为丝线，为圣城织起名为「团结」的战袍。
- 遐蝶归还火种后永居冥界，生死之间的门不再关闭，守门的人却回不来。
- 那刻夏火种离体，肉身彻底归殁。
- 万敌请求缇安主持「裂魂仪式」，把灵魂裂成五份，让纷争的锋刃永远高悬。
- 风堇成为半神后做的第一件事不是征战，是治病；她守到最后一个普通人死去。
- 海瑟音守通道守到自我沉眠，缇宝守到最后一个「自己」燃尽。

神职不是奖赏，是一份没有退休年限的工作。

## 与泰坦

半神与泰坦不是取代关系，是继承关系。

泰坦是原初的神，半神是后来的人。人接过神的权柄，也接过神的孤独。区别在于：泰坦的孤独是「无人可说话」，半神的孤独是「还有话没说，但已经没时间了」。

## 结局

3.6 的再创世仪式上，十二枚火种归位，半神体系随之终结。

3.7 的决战里，最后的十二泰坦走完最后一程，火种化作「记忆」的筹码，被用来覆写铁墓的方程式。

翁法罗斯不再需要人替神值班。世界不再需要神谕许诺的明天。
