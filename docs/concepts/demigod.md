# 半神

> 击落泰坦、回收火种、填补神职。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 神权承载者 |
| 来源 | 黄金裔 + 火种 |
| 代表 | 阿格莱雅、万敌、风堇、海瑟音等 |
| 活跃 | 3.0—3.7 版本 |

## 什么是半神

半神不是「一半的神」，是「替神值班的人」。

泰坦失神或死去后，火种无人看守。黄金裔通过试炼接过火种，成为新的半神，替泰坦守住权柄，也替凡人挡住黑潮。

## 代价

成为半神，意味着把一部分人性交出去。

万敌把自己裂成五份，风堇的思维模块磨损到嵌入晨昏之眼，海瑟音献上余生的自由与清醒。神职不是奖赏，是一份没有退休年限的工作。

## 与泰坦

半神与泰坦不是取代关系，是继承关系。

泰坦是原初的神，半神是后来的人。人接过神的权柄，也接过神的孤独。

## 结局

3.6 的再创世仪式上，十二枚火种归位，半神体系随之终结。

3.7 的决战里，最后的十二泰坦在时光归墟走完最后一程，火种化作「记忆」的筹码，被用来覆写铁墓的方程式。

翁法罗斯不再需要人替神值班。世界不再需要神谕许诺的明天。
