# 火种

> 十二泰坦各持一枚火种，代表十二泰坦的原初神性。

## 基本信息

| 项目 | 内容 |
|------|------|
| 数量 | 十二枚 |
| 存放 | 创世涡心·灵水盆 |
| 作用 | 试炼、继承神权、成为半神 |
| 活跃 | 3.0—3.7 版本 |

## 什么是火种

火种不是一团火，是一份权柄。

天空、大地、海洋、岁月、律法、门径、浪漫、负世、理性、诡计、纷争、死亡——十二枚火种，对应十二种神职。

## 试炼

黄金裔必须击落泰坦、回收火种，才能接受试炼。

试炼不是考试，是让火种认人。认不上的，会被烧死；认上的，会成为新的半神。

## 灵水盆

创世涡心中封存火种的圣器是「灵水盆」，寄宿着渴求秘酿的灵体。

十二枚火种在盆中等待，像十二个还没决定要不要醒来的梦。

## 归还

3.6 末章，再创世的所有条件达成。

开拓者回到大墓深处的德谬歌矩阵前，归还十二枚泰坦的火种，完成再创世的仪式。名为「黄金裔」的人子归还众神火种，再度支撑起天地。

新世界就此到来。

## 3.7

火种的账，到 3.7 才真正结清。

三千万世里，每一世都有十二位黄金裔夺火、负火、失火。缇宝说，记忆中的逐火者是「三千万世」乘以「十二」；万敌说，等着他们归还的火种有四亿枚。

这些火种没有回到某座祭坛，而是被收进开拓者与昔涟身上。它们不再是神的权柄，而是「心灵」压过「身体」的筹码——用来覆写铁墓「毁灭」的方程式。

这一次，世界不再需要神谕许诺的明天。
