# 药师

> 「生命因何而沉睡？因为生命终将从梦中醒来。」
>
> ——药师（残句）

## 生命之神

药师令生命兴盛不熄。祂的神迹从不分辨对象——福泽与灾祸同源：受赐福者长生，受赐福者变异；受赐福者永生，受赐福者失去死亡的权利。

仙舟人给祂的称号「寿瘟祸祖」精准概括了这种双重性：既是长寿（寿）之祖，也是瘟疫（瘟）与灾祸（祸）之祖。

## 建木

祂示现罗浮留下的神迹「建木」，是丰饶之力在仙舟最大的实体遗存。建木复生引爆了饮月之乱；1.2 版本幻胧之乱中，它再度成为幻胧操纵仙舟的枢纽，最终被丹恒一枪断开联结。

## 占卜禁令

太卜司《星神论》对药师着墨最深的部分，不是神迹而是禁令：

> **需要再度向各位重申，任何以「寿瘟祸祖」本体为主方、占算其未来的行径都是不可饶恕的重罪。**

对其他星神占卜，「或许可以睁一只眼，闭一只眼」。但对药师，十王司颁布禁令，违者视同触犯「不赦十恶」——原因是仙舟人本身：**「寿瘟祸祖」是仙舟人转变为长生种的根源，因此仙舟人与药师之间存有某种无法廓清的超距作用**。

《星神论》原文指出，这种格物学尚不能解释的联系，可能是「魔阴身」产生的原因之一；任何试图以占算手段窥视药师者，都将在这种作用下承受反噬。所有类似行为都招致了惨烈的结果，记录在太卜司书库「违命」一栏。

## 长生种的根源

一份博识学会学者写给同僚的信件从外部视角印证了这段关系：「受某位星神一时兴起的赐福（通常是药师），有些灵长目智慧生命跨越了死亡为血肉凡胎划定的界限」——这就是「长生种」人类亚种的由来。

学者同时记录了长生种的另一面：这不是恩赐而是状态。受赐福的世界「四海萧条、黎庶涂炭」——这正是《寰宇通鉴》所载仙舟求药时代的历史，也是仙舟人对「丰饶」态度反转的起点。
