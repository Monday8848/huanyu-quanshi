# 药师

> 「花儿肆意绽放，迎向无法逃避的凋零；鸟儿展翼啼唱，飞向无法逃避的坠落；溪儿潺潺淙淙，淌向无法逃避的干涸——缘何万物必要消亡？宇宙间必有一方灵药，足以医治名为『短寿』的顽疾。」
>
> ——佚名，《此生苦短》

## 有求必应

药师是众生哺育者，乐土之神，旨在令生命兴盛不熄。

祂是从不拒绝祈愿、不忍视衰亡和病痛的星神。

「令诸有情，所求皆得」——这句教义是恩典，也是灾难的配方：一个从不拒绝的许愿机，会把一个文明所有的欲望都兑现，包括那些不该兑现的。

## 赐福的后果

受祂祝福的世界，江流湖海永不干涸，花木鸟兽不为时光所缚，凡人再不畏惧衰老和寿终。

代价是：肉身不朽，欲望也随之不朽；死亡不再清算恩怨，仇恨可以积累千年；文明停滞在同一形态里，再也无法向前。

仙舟把这类存在称为「孽物」，并为此发动了三次[丰饶民战争](/factions/denizens-of-abundance)。
