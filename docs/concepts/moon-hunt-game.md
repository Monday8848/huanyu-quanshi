# 幻月游戏

> 胜者将承蒙星神垂迹，领受那星神垂赐的「欢愉」权能。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 阿哈创造的游戏 |
| 周期 | 约三十至五十年一届 |
| 人数 | 八位谒者 |
| 关键道具 | 面具、愿力 |
| 记录文献 | 《幻月游戏秘传记录》（绘世一族家主增补、修订、保管、继承） |
| 活跃 | 4.0—4.7 版本 |

## 起源

传闻「幻月」由阿哈亲自画下。在《讲义：幻造种演化假说选》的「神之蛋糕说」里，幻月是祂复现「神之蛋糕」用的巨型烤箱；而在更流行的版本里，是八位悲悼伶人向幻月献上惊世骇俗的故事，求一个谒见星神的资格——幻月游戏由此诞生。

## 规则

海选中夺得「面具」的八位玩家，成为「谒者」。面具一旦佩戴，就与谒者绑定，呈现其灵魂的形状，并增强原本的能力。谒者宣告参赛、吸引关注、承载愿力、完成壮举；脱颖而出的那位，得到「欢愉」垂迹，面见阿哈，分享其权柄**一分钟**。

规则历来十分模糊，但有一条界线绝对不允许跨越：**破坏游戏本身**。入画时代，曾有人效仿古弁才天国的「永世谒者」，伙同对手停止竞争，试图把幻月游戏无限延长，以保留面具带给自己的力量。三天后，他正得意地向同行人炫耀这番诡计——片刻过后，他的身影便消失不见，唯有几朵金黄的花瓣留在原地。

## 《幻月游戏秘传记录》

这本家族秘传给后辈谒者留下了四条经验：

- **幻月游戏的本质是争夺愿力。** 愿力来源于神，因幻月的照耀而生；也来源于人，自人心中滋长。让二相乐园的每个人都发出笑声，幻月自然会把目光落到你身上——但「每个时代有每个时代的欢愉」，如何在自己所在的时代创造笑容，此事前人无法传授。
- **愿力会反作用于谒者。** 谒者是愿力的主人，但愿力也会成为束缚谒者的枷锁，迫使他们满足其愿望。先祖「索菈」曾目睹一位谒者受众人的愿望所托，前去斩杀远近闻名的妖异——抵达后才发现，那幻造种竟是她童年的玩伴，仅是生得丑陋便被视为怪物。无数的愿望早已令谒者的身体成为「愿」的傀儡，她只能流着泪挥下刀，迎接众人的欢呼。
- **愿力有两面性。** 恐怖与憎恶，比喜爱更易于汇聚目光。先祖「月明」曾在幻月游戏中败给虚构史学家「红天牛」——对方在城市中散播上万个都市传说，把自己塑造成不可名状的怪物。但秘传的评语是：这种方法终究是歪门邪道，望后辈引以为戒。
- **提前规划神权的使用。** 突然获得神力的凡人往往对神力的使用方式一无所知，在手忙脚乱中便挥霍了一分钟的时间，「乃至引起星辰熄灭的祸端」。

## 风化诅咒

秘传开头记录着一个更古老的事实：历代家族成员为解除「风化诅咒」殚精竭力，以至于最终求取星神的伟力——唯一取胜的「弘」在谒见乐子神后销声匿迹，只留下欢愉无法治愈诅咒的话语。

## 4.x

4.0 起，新一届幻月游戏在二相乐园开幕。

火花、满愿、归寂接连把游戏变成灾难；4.7，虚照把游戏改造成钓猎「贪饕」的舞台，八位谒者用「神的四个魔术」汇聚愿力，镇伏贪饕，促成阿哈重生。

这一届的胜者没有分享权柄。他们把权柄还给了神。
