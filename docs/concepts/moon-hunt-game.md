# 幻月游戏

> 胜者将承蒙星神垂迹，领受那星神垂赐的「欢愉」权能。

## 基本信息

| 项目 | 内容 |
|------|------|
| 起源 | 阿哈与八位悲悼伶人 |
| 周期 | 约三十至五十年一届 |
| 人数 | 八位谒者 |
| 关键道具 | 面具、愿力 |
| 活跃 | 4.0—4.7 版本 |

## 起源

阿哈在天空画下「幻月」，使它成为第一个幻造种。

后来八位悲悼伶人向幻月献上惊世骇俗的故事，求一个谒见星神的资格。幻月游戏由此诞生。

## 规则

海选中夺得「面具」的八位玩家，成为「谒者」。

面具一旦佩戴，就与谒者绑定，呈现其灵魂的形状，并增强原本的能力。谒者要做的，是宣告自己参赛、吸引关注、承载愿力、完成壮举。

行动不受干涉，尽情取悦众生。脱颖而出的那位，得到「欢愉」垂迹，面见阿哈，分享其权柄一分钟。

## 面具

面具既是入场券，也是枷锁。

它放大谒者的能力，也放大谒者的欲望。戴久了的人，很难说清哪一面才是自己。

## 4.x

4.0 起，新一届幻月游戏在二相乐园开幕。

火花、满愿、归寂接连把游戏变成灾难；4.7，虚照把游戏改造成钓猎「贪饕」的舞台，八位谒者用「神的四个魔术」汇聚愿力，镇伏贪饕，促成阿哈重生。

这一届的胜者没有分享权柄。他们把权柄还给了神。
