# 法吉娜

> 满溢之杯。

## 基本信息

| 项目 | 内容 |
|------|------|
| 神位 | 海洋 |
| 称号 | 满溢之杯 |
| 对应黄金裔 | 海瑟音（海列屈拉） |
| 所属 | 十二泰坦 |

## 权柄

法吉娜掌大海、风暴与蜜酿。它让潮汐守时，也让宴席不散；它洗刷世界的污秽，也把污秽冲回岸边。

## 神体与信仰

它赐下蜜酿与宴会，也赐下风暴与潮汐。翁法罗斯人相信，最好的葬礼是一场喝到天亮的宴席，这份乐观多半来自法吉娜。海妖国度最早拥抱毁灭，被侵蚀殆尽；海瑟音为同胞送葬，拼凑满溢之杯，登岸后接过海洋火种。3.5 版本，她与刻律德菈一同登神。

## 与黄金裔

海瑟音（海列屈拉）是它的火种继承者。击落泰坦、回收火种、通过试炼——这是黄金裔成为半神的唯一路径，也是泰坦退场的方式。
