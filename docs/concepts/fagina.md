# 法吉娜

> 「满溢之杯。」
>
> 法吉娜喜欢在人世中漂流，出现在海上的波涛、河上的湍流、宴上的酒杯中，带来歌舞与欢笑。

## 权柄

法吉娜的权柄全都和「流动」有关。

- **海洋与风暴**：潮汐的涨落、风暴的来去，都是它的呼吸。
- **秘酿**：它掌管酒，也掌管一切让人忘掉痛苦的东西。翁法罗斯的蜜酿配方据说是它亲手写的。
- **宴会与狂欢**：它出现在宴上的酒杯里。只要还有人举杯，法吉娜就没有离席。

## 神体与海妖

法吉娜没有固定的神体，所有水体都是它——海上的波涛、河上的湍流、宴上的酒杯，都是同一双手的不同姿势。你喝下一杯酒，就等于让它经过你一次。

海妖是它的眷属，聚居在斯缇科西亚外的深海。海妖的国度信奉一句话：既然终将散场，不如先干杯。这份乐观让它们成为翁法罗斯最早拥抱「毁灭」的一族——黑潮在世界深处暗涌时，海妖们主动迎了上去。

## 海瑟音

海列屈拉是海妖中的异类。当同胞被黑潮侵蚀、成为黑潮造物，她没有逃，而是孤独地洄游，为每一个同胞送葬。她在海里寻找满溢之杯的碎片，想拼起女王许诺过的那场欢宴。

杯子拼好了，法吉娜却给不出答案。女王以迷醉回避她的追问，只说大地之上总有她渴求的欢宴。海列屈拉于是上岸，走进斯缇科西亚——迎接她的只有寂静流淌的冥河，没有蜜酿，没有庆典。

**光历 3860 年**，海列屈拉遇见刻律德菈，加入逐火军。她把「律法」当作生命的纲领，成为凯撒的剑旗，在逐火中收获了短暂的幸福。游鱼天性趋光，因为海渊昏暗苍茫。

**光历 3960 年**，刻律德菈以「出征法吉娜」为名，献祭五百名黄金裔完成律法试炼，随后命海瑟音刺杀自己。这一战名义上指向海洋，实际上指向的是一位半神的自我清算。

**3.5 版本**，海瑟音清洗「海洋」火种，成为海洋半神。她在第二轮回中与遐蝶、缇宝一同开凿通往创世涡心的密道，并守在通道外对抗来古士的思维，直到自我沉眠。

## 火种与半神

| 环节 | 内容 |
|------|------|
| 火种 | 「海洋」 |
| 归还 | 3.5 版本前，逐火旅程中完成 |
| 继承 | 海瑟音（海列屈拉），「剑旗爵」 |

海洋火种的归还被记在逐火之旅的中段，但它真正的重量在第二轮回：海瑟音用一场没有终点的守夜，替所有人把通道留到了千年之后。
