# 命途

> 星神所行的「道路」。它既是宇宙层面的法则，也是命途行者获取力量的来源。

## 定义

命途不是地理意义上的路，而是一种由星神的存在本身所定义的秩序。星神行走在哪条命途上，那条命途就成为宇宙中一条真实生效的规则：毁灭倾向于毁灭，存护倾向于守护，巡猎倾向于追索。

命途行者——行走在某条命途上的人——能从这条规则里借到力量。借得越多，越难回头。

## 运作机制

- **命途由星神定义，但不依赖星神存活。** 阿基维利陨落之后，「开拓」这条命途依然存在，依然有人行走其上。星神是命途的源头，不是命途的开关。
- **命途可以被吞并。** 「秩序」的星神太一被「同谐」的希佩吸收，秩序命途随之并入同谐。这是已知唯一一次命途级别的吞并。
- **令使是星神亲自赐福的存在**，实力远超凡俗，但数量极少，且往往背负着星神的意志。
- **命途之间存在天然的张力。** 巡猎与丰饶、存护与毁灭，这些对立不是立场问题，而是规则层面的互斥。

## 机制命途与设定命途

游戏里角色卡上标注的「命途」（毁灭、巡猎、智识、同谐、虚无、存护、丰饶、记忆）是**战斗定位**，用于区分技能组与装备适配。

它与设定上的命途归属多数时候一致——景元是巡猎，砂金是存护——但并不严格对应。判断一个角色的设定归属，要看剧情与角色故事，不能只看卡片。

这个区分很重要：把机制命途当设定命途，会得出「所有毁灭角色都信奉纳努克」这类明显错误的结论。
