# 命途行者

> 星神走在前面。行者是自己走上同一条路的。

## 基本信息

| 项目 | 内容 |
|------|------|
| 定义 | 踏上命途并获得力量的人 |
| 前提 | 与某条命途的核心理念高度契合 |
| 与令使的区别 | 令使由星神授予，行者自行走上 |
| 典型例子 | 黄泉（虚无）、景元（智识）、刃（毁灭） |

## 什么是行者

命途是星神留下的「道路」。普通人走在上面不会发生任何事，但极少数人会在某个时刻与某条命途产生共鸣，从而获得力量。

这些人就是命途行者。

行者没有入职仪式，也没有组织认证。踏上命途往往不是选择，而是被选择——一个人的经历、信念、执念走到了某个极端，自然就与对应的命途对上了。

## 与令使的区别

这是最容易混淆的一组概念。

| 项目 | 命途行者 | 令使 |
|------|----------|------|
| 力量来源 | 命途本身 | 星神直接授予 |
| 数量 | 相对较多 | 极少 |
| 与星神的关系 | 无直接联系 | 代表星神意志 |
| 力量上限 | 取决于契合度 | 接近星神权柄的一部分 |

简单说：行者是「同路人」，令使是「代理人」。黄泉能承受虚无，是因为她与虚无的契合度极高；纳努克的绝灭大君能毁灭星系，是因为毁灭星神把权柄分给了他们。

## 命途会改变人

踏上命途不是获得一件装备，而是接受一套逻辑。

毁灭的行者会越来越倾向于「终结」，虚无的行者会越来越难感受到意义，巡猎的行者会越来越无法停下。命途给力量，也收走别的东西。

仙舟的「魔阴身」是这种现象的极端版本：活得够久，人格被命途磨损殆尽，只剩本能。

## 游戏机制与设定

游戏里每个角色都标注命途（毁灭、巡猎、智识等），这套标注基本对应设定，但不完全等同：有些角色的命途是玩法分类，未必代表设定上真的行走于该命途。

阅读时要注意区分「这个角色在游戏里是存护命途」和「这个角色在设定上是存护的行者」。
