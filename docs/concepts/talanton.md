# 塔兰顿

> 公正之秤。

| 项目 | 内容 |

| 神位 | 律法 |
| 称号 | 公正之秤 |

## 权柄

塔兰顿掌律法与公正。它捍卫禁忌与边界，给万事万物定下可以丈量的尺度。

## 神体与信仰

它把砂砾变成神力砝码，设立统一货币「利衡币」，让翁法罗斯第一次有了「公平」的度量。它守护边界，也守护禁忌——门里的事归雅努斯，门外的事归它。3960 年，刻律德菈献祭五百名黄金裔，完成律法试炼，接过它的火种，随后自杀。

## 与黄金裔

刻律德菈是它的火种继承者。击落泰坦、回收火种、通过试炼——这是黄金裔成为半神的唯一路径，也是泰坦退场的方式。
