# 魔阴身

> 「原本的『标准』遭到突破，肉体展现出极具破坏性的生长，使原本生活在文明世界中的『人』，变成缺乏灵智的『孽物』。」
>
> ——《药王秘传·证物集册》

| 项目 | 内容 |
|------|------|
| 外文名 | Mara |
| 本质 | 长生种生命周期的临界阶段 |
| 高发人群 | 退役云骑 |

## 它的原理

仙舟人的长生来自药师。他们的细胞可以依照出生时已注定的「标准」相互转化，把身体特征恒定在原初状态，后天残缺也会恢复到「标准」。这套系统维持着严格的天生平衡，侵入式义肢与激素等外力都会引起强烈反弹。

魔阴身就是这套系统的崩溃：在生命周期的某个临界点，**原本的「标准」遭到突破**，肉体开始极具破坏性的生长，人变成缺乏灵智的孽物。

医士的解释更冷一些：魔阴身与记忆有关。长生种寿命极长，但记忆容量有极限；数百年、上千年过去，情绪阈值不断提升，记忆在天长日久的磨蚀下稀薄、厌倦，只留下最极端鲜明的沉淀——而那几乎必定是痛苦与悔恨的残渣。在这些极端情绪下，身为人的自我开始崩溃，这就是魔阴身的开端。

还有一种无法证实的猜想：因为长生源于寿瘟祸祖，仙舟人与药师之间存在某种「超距作用」，这可能是魔阴身的成因之一；而任何试图以占算手段窥视药师的人，也会在这种作用下承受反噬。

## 五种症状

| 症状 | 含义 |
|------|------|
| **残伤** | 肉体因外界暴力遭受严重损伤，必须通过自愈能力进行漫长而痛苦的修复 |
| **垢染** | 肉身不朽，感染了某种顽强的天外病毒或细菌并与之长期共存 |
| **嗔恚** | 产生怨恨、损害他人的心境，情绪在剧烈的悲喜怨嗔中起伏 |
| **他化** | 肉身开始生出变异器官，无法再保持人形稳定 |
| **无记** | 心被莫名的空虚感所占夺，陷于浑浑噩噩的状态 |

这五项不是随机症状，是一份「人如何不再是人的清单」：从身体的伤，到外来的病，到情绪的失控，到形体的崩解，最后到自我的消失。

## 四场古代惨剧

仙舟史上留名的四次魔阴身灾祸，各以一艘仙舟为背景：

| 仙舟 | 惨剧 |
|------|------|
| 曜青 | 腴肉连城 |
| 朱明 | 赤怒焚王 |
| 虚陵 | 白骨夏宫 |
| 玉阙 | 碧血山茔 |

名字都极狠：城是肉做的，王是火做的，宫是骨做的，坟是血做的。

## 怎么处理

- **十王司**负责监管魔阴身，其「不赦十恶」中就有「令堕长生」「贪取不死」「迷乱心智」「诱陷魔阴」等条律。
- **冥想遗忘疗法**被用于健康长生者，延缓记忆沉淀成毒。
- **退役云骑是最容易陷入魔阴身的群体**——他们的记忆里最不缺的就是痛苦与悔恨。
- 对已经堕入魔阴身者，处置方式基本只有一种：杀。

## 为什么这个设定重要

魔阴身把仙舟的核心矛盾钉死了：**长生不是奖励，是一份分期付款的账单。**

它同时解释了仙舟人的性格——他们拼命工作、拼命喝酒、拼命记住值得记住的事，因为知道某一天自己会变成需要被自己人杀掉的怪物。
