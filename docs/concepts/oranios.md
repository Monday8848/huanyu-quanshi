> 「永夜之帷。」
>
> 欧洛尼斯梳理岁月的脉络，支撑着世间的过去、现在与未来，让万事万物得以流转。

## 权柄

欧洛尼斯是十二泰坦里最特殊的一位——它管的是「时间」，而时间在翁法罗斯是可以被翻开的书。

- **岁月**：梳理岁月的脉络，支撑过去、现在与未来。万事万物得以流转，靠的是它把时间撑住。
- **夜幕**：永夜之帷。它把夜幕当作帘子，垂下来就是黑夜，掀起来就是黎明。
- **记忆**：它把记忆当作书页收藏。这是它与「记忆」命途、与记忆星神浮黎产生联系的原因——欧洛尼斯称浮黎为「天父」。

## 神体与祷言

欧洛尼斯的神体是一个独眼发光的巨人，栖于命运重渊深处的命运三相殿。它只有一只眼，因为「看」这件事对它而言不是观看，而是翻阅。

翁法罗斯各地流传的「欧洛尼斯祷言」，一直被当作向泰坦借力的仪式。3.0 版本，开拓者在命运重渊与欧洛尼斯交谈，才得知真相：所谓借用泰坦的力量，实际上是在**役使**泰坦——祷言是命令，不是祈求。欧洛尼斯并不介意，它把这件事说得像一桩旧账。

同一段剧情里，欧洛尼斯带开拓者进入了一段「不存在的记忆」。在那里，两人一同得到记忆星神浮黎的瞥视。回过神来，开拓者身边多了一只粉色的小狗生物——迷迷。

## 历史

**3.0 版本**，开拓者与丹恒为讨伐尼卡多利前往命运重渊求援。欧洛尼斯给出岁月的力量，也给出了那句后来被反复验证的话：时间不是线，是可以折叠的帷幕。

**3.1 版本**，缇宝为整理逐渐模糊的记忆，与缇安、缇宁重返命运三相殿，却发现欧洛尼斯已经死了——连火种都被盗火行者夺走。愤怒的盗火行者随即对三人出手，缇安开出最后一扇门送走缇宝与缇宁，自己与克拉特鲁斯跌落山崖。此后逐火小队在悬锋城设局围猎盗火行者，迈德漠斯以纷争半神之姿掷出决定性的一枪，岁月火种被带回奥赫玛。

**3.2 版本**，开拓者接受「岁月」试炼，却被告知一个更惊人的事实：自己早在进入翁法罗斯时就已经「死去」。为了寻回被夺走的未来，众人加快寻找死亡泰坦塞纳托斯的踪迹。最终遐蝶炼成死龙玻吕刻斯，回到冥界，把火种与开拓者的未来一并带回，翁法罗斯的生死流转重归有序。

**3.5 版本之后**，第二轮回中「负世」出现漏洞，原白厄的救世主身份由开拓者接手，「岁月」半神的权能则易主给长夜月。长夜月借岁月火种试图参与翁法罗斯的运作，与开拓者发生冲突；最终三月七完成岁月试炼，这条路径才有了新的主人。

## 火种与半神

| 环节 | 内容 |
|------|------|
| 火种 | 「岁月」 |
| 状态 | 3.1 被夺，旋即在悬锋城夺回；3.2 由开拓者交还 |
| 历任持有者 | 欧洛尼斯 → 开拓者（暂持）→ 长夜月 → 三月七 |
| 特殊性 | 欧洛尼斯死后，「岁月」路径出现逻辑漏洞，成为永劫回归的入口之一 |

欧洛尼斯是十二泰坦中第一个「死透了」的——没有火种留存、没有神性碎片、没有复活的余地。它死后，翁法罗斯的时间开始出问题：同一天可以被过很多次，同一个人可以死很多次。
