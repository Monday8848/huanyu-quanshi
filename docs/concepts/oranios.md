# 欧洛尼斯

> 永夜之帷。

| 项目 | 内容 |

| 神位 | 岁月 |
| 称号 | 永夜之帷 |

## 权柄

欧洛尼斯掌岁月与夜幕。它支撑过去、现在与未来，把每一段记忆收进永夜之帷。

## 神体与信仰

它把记忆当作书页，称记忆星神浮黎为「天父」。哀丽秘榭在它的庇护下保留麦田与风车，成为永夜里的例外。3.1 版本，缇宝前往命运重渊寻找欧洛尼斯，发现它已经死去。此后「岁月」路径出现逻辑漏洞，长夜月与三月七先后接续，最终由三月七完成岁月试炼。

## 与黄金裔

长夜月 / 三月七是它的火种继承者。击落泰坦、回收火种、通过试炼——这是黄金裔成为半神的唯一路径，也是泰坦退场的方式。
