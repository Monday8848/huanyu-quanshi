# 幻造种

> 幻造种，一种由内部的核心驱动，以幻月和人类提供的愿力为能量，以离散物质作为身体的智慧生命。——《幽灵也能读懂的幻造种科普》

## 基本信息

| 项目 | 内容 |
|------|------|
| 所属 | 二相乐园 |
| 构成 | 核心 + 愿力（能量）+ 离散物质（身体）+ 绘师描摹（形体） |
| 命途 | 欢愉（幻月带来的命途力量辐射） |
| 发明者 | 绘世（烬土纪元发明幻造技术并广泛传播） |
| 保护法规 | 《灵物保护法》及附加条例 |

## 构成

**核心**是幻造种最重要的部分——它像引擎一样驱动行动，又兼具骨骼的作用，一旦失去，身体就无法维持形态。核心能够在自然界中生成：在高密度能量或愿力的环境下，游离物质中会自然聚合出「核」，呈现出类似命途行者的特殊性质，并开始兼并、驱动周边物质组成身体。

「核」的本质是一团凝聚的物质，真正赋予它驱动力的，是幻月带来的命途力量辐射。换言之，**幻造种从诞生的那一刻起，就是踏在命途上的生物**。

由于驱动幻造种需要大量愿力，人为制造「核」往往需要官方组织的许可和参与；星际和平公司近年开发的幻造种生产流水线如何突破苛刻条件，属于专利保密事项。

**形体**由绘师决定。绘师绘制形体、赋予故事文脉，为幻造种提供足够坚实的「骨骼」，以支撑大量物质与能量——复杂的行为模式与骨骼，又为智慧的形成提供土壤。

## 起源假说

《讲义：幻造种演化假说选》记录了三种主流解释：

| 假说 | 主张 |
|------|------|
| 元胞自动机说（博识学会主流） | 幻月满盈时，「愿力」渗透物质，能量、物质、行为模式三要素驱动下产生规律性的生命机器——「妖怪」。绘世的发明克服了自然生成时难以形成复杂结构的难题 |
| 魂骨肉说（悲悼伶人特色） | 智慧生命由魂（愿力/意识）、骨（存在的概念）、肉（物质/皮囊）组成，三者均可在自然界独立诞生；绘世只是发现了复现幻造种形成的手段 |
| 神之蛋糕说（结构主义烘焙学派） | 阿哈在寰宇蝗灾时期饥饿至极时烘焙过一块「神之蛋糕」，祂不断尝试复现味道，材料越堆越多，最终砌成了二相乐园；幻月就是祂的巨型烤箱。后世烘焙大师绘世参照神迹，用泥土、墨水和故事仿制出神之蛋糕，唤作幻造种 |

关于幻造种身体物质的来源，学界还有「命途狭间说」（诞生瞬间从欢愉命途狭间获取质量，死亡时归还）与「离散物质说」（核心迅速吸纳周边离散物质）之争——近来更有新兴学派主张「两种假说都是对的」。

## 设定的限度

给幻造种赋予强大「设定」并不能造出强大的幻造种——「设定」终究需要足够且适配的愿力支撑。如果绘师打算为一个附加「刀枪不入、飞天遁地、火箭飞拳」设定的幻造种创造形体，最大的可能是核心根本无法生成；个别情况下会得到不完整的幻造种。二维市第三医院的幻造种疗养院中，就收容着大量因个人私欲而诞生的、有缺陷的幻造种。

目前这类行为已被列入《灵物保护法》附加条例，与制造人类幻造种一样，是严重的违法行为。

## 衍生类型

- **尘灵**：由细小愿望凝聚而成的幻造种雏形，缺乏足够智慧，依靠本能聚集、达到阈值后溃散。
- **妖怪**：幻月时代的自然造物，从花草树木到彩电冰箱，任何获得愿力的物质都可能活过来。
- **机铠**：上次「幻月游戏」劫数后由公司打造的新幻造种，与其制造图纸相同、拥有完整的内部构造——但那也只是拟态。
- **雷虬**：为二相乐园供电的幻造种族，质量与能量负载已是一颗核心能承载的极限。

## 与人类的关系

幻造种拥有和人类同等的工作权利。《绘世学院校规》要求学生会设人类、幻造种两位会长；《渡画泉隐酒店价目表》为机铠列出专用床铺与洗漱用品的附加费。在二相乐园，幻造种不是道具，是居民。
