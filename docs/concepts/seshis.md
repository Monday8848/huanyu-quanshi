# 瑟希斯

> 「裂分之枝。」
>
> 瑟希斯以一棵巨圣树的形象降临世间，它允许人类在它的身旁漫步、醒神和思辨，获取知识。

## 权柄

瑟希斯不要求信徒跪下，只要求他们思考。

- **理性**：它给万物以逻辑，让人能够从「是什么」推到「为什么」。
- **智慧**：它不是知识的仓库，是知识的方法。树庭的学者说，瑟希斯从不回答问题，只把问题拆成更小的问题。
- **植物与生态**：它让枝杈分叉、让根系相连。森林是它写在地上的论证。

## 神体与神悟树庭

瑟希斯以一棵巨圣树的形象降临世间。神悟树庭围着这棵树而建，成为翁法罗斯的学术中心。树庭有七贤人、七学派，学者们在树荫下互相挑刺——这不是不敬，这正是瑟希斯要的：理性只有在被质疑时才活着。

它曾因意外失去神体，身躯四散。墨涅塔搜集这些碎片，想用丝线把它收拢，创生若虫也加入了这场苦旅。最终瑟希斯以圣树的形态重新立起，但裂痕留了下来——「裂分之枝」这个名字，说的就是一棵被拼回去的树。

## 那刻夏

那刻夏（阿那克萨戈拉斯）是神悟树庭的七贤人之一，也是翁法罗斯最难归类的一位黄金裔。他不信神谕，只信怀疑；他的名言是「这世界遍地虚假，唯有我才是真实」。

**3.1 版本**，树庭遭黑袍剑士（盗火行者）袭击。那刻夏用炼金术粉碎灵魂、布下大阵，把一众黑潮造物困在樊笼中，并打算与瑟希斯同归于尽，把火种送往奥赫玛。瑟希斯没有同意——它把火种分成三份藏匿，化名「卡吕普索」与开拓者等人同行，一路考察这些人是否值得托付，最后才在那刻夏体内把火种拼合。

此后一段时间，一人一神共用一具身体：那刻夏在明处说话，瑟希斯在暗处提问。

**3.2 版本**，那刻夏完成「理性」试炼，在黄金裔的见证下归还火种，肉身彻底归殁。他的灵魂在冥界见到遐蝶，完成了创世猜想的证明；他在公民大会上投出关键一票，并用渎神罪行重挫元老院夺权的野心，让逐火之旅得以继续。

一个人用死证明了自己活着时的判断——这是瑟希斯教给他的最后一课。

理性火种是十二枚中最「不听话」的一枚：它不选最强的人，选最会问的人。
