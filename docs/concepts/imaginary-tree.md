# 虚数之树与量子之海

> 宇宙的形状，被描述成一棵树，和一片海。树上有无数世界，海里漂着没能长上去的那些。

## 定义

虚数之树与量子之海，是官方用来描述宇宙整体结构的一组意象。

- **虚数之树**：宇宙的骨架。无数世界像枝叶一样生长在树上，彼此通过星轨、裂隙或更隐蔽的方式相连。
- **量子之海**：树之外的另一种存在状态。它更像是「可能性」的集合——没能成为现实的世界、被放弃的选择、以及无法归类的存在，都可能沉在海里。

这套说法不是严格意义上的物理模型，而更接近一种宇宙观：世界不是孤立的球体，而是一棵树上的不同枝条。

## 树上的世界

在树的框架下，「不同世界」之间的关系变得可解释：

- 星轨是枝条之间的通路，星穹列车沿星轨行驶，本质上是沿着树的结构移动。
- 星核、裂隙、梦境空间，都可以理解为树结构上的异常。
- 某些存在能够跨越世界，意味着它们能绕过树的结构，直接从海或更高的层面介入。

这个框架没有解释一切，但它把很多零散的设定串成了一条线。

## 海的意义

量子之海在故事里出现得不多，但每次出现都意味着「规则之外的规则」。

它承载的是未被选择的可能性。这意味着两件事：第一，海里的东西不一定遵守树上的规则；第二，从海里来的存在，往往对树上的秩序构成威胁。

## 争议与空白

这组概念目前仍停留在「意象」层面，官方没有给出可验证的机制。

玩家中比较流行的推测是：虚数之树与量子之海的关系，类似于「现实」与「潜在」的关系——树是已经实现的世界，海是尚未实现的可能性。也有推测认为，海的深处存在比星神更古老的东西，星神只是树上的产物。

这些说法都缺乏直接证据，但至少解释了为什么官方在描述宇宙时，始终使用「树」与「海」这两个意象，而不是「星系」或「维度」。
