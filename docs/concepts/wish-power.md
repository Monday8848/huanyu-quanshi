# 愿力

> 在这片由人与幻造种共同构筑的乐园里，你的心愿将作为一般等价物来流通。

## 基本信息

| 项目 | 内容 |
|------|------|
| 本质 | 「命途原动力」的显化形态 |
| 来源 | 智慧生命的思维活动与精神波长 |
| 稳定形态 | 二态愿 |
| 凝结物 | 愿宝 |
| 关键条件 | 幻月的晖光 |
| 活跃 | 4.0—4.7 版本 |

## 定义

据二相乐园各大高校通用的教科书《基础愿力学》：

> 愿力，本质上即是「命途原动力」。它是驱动宇宙中有情众生踏上特定「命途」的核心能量，潜藏于每一份智慧生命的思维活动与精神波长之中。

在广袤的寰宇中，愿力大多以无形、离散的状态存在。唯有在二相乐园，当欢愉的幻月洒下晖光，愿力才在命途能量的干涉下发生显化——获得物理上的实体与可干涉的特性，凝聚成形态千姿百态、生机盎然的「幻造生命」。

## 二态愿

愿力组成形态极其丰富，但乐园当前的技术水平只能稳定控制其中一种：「二态愿」。

只有在幻月辐射范围内或极少数实验室条件下，愿力才能维持稳定的二态愿结构。这种结构有极强的排他性：幻造种的生理机能只支持摄取二态愿，无法直接吸收宇宙中广泛分布的「离散愿力」。

教科书用了一个后来被自己批判的类比：

> 陆地与海洋中都蕴含着大量的氧气，但依靠肺部呼吸的动物只能摄取空气中的氧气，一旦进入海洋，便会因无法有效提取水中的氧气而溺水。

对幻造种而言，离散愿力就是「海洋中的氧气」，随处可见却无法吸收。它们必须依赖某种「愿力氧气瓶」才能维持生命。

乐园历 1999 年的再版注承认，这个类比带有「有机生命至上主义」的时代局限。

## 它撑起了整座乐园

在二相乐园的社会学与工程学里，愿力不只是幻造种的生理组成，更是现代文明的基本单元：

| 用途 | 说明 |
|------|------|
| 电力与通讯 | 通过雷虬的生理转化，愿力被成规模输出为稳定电流与通讯频段 |
| 交通 | 疾锋龙列车以愿力为唯一动能，构成乐园永不停歇的交通动脉 |
| 精密咒偶 | 依靠愿力驱动的机械造物 |
| 照明 | 照亮永夜的愿力电灯 |
| 军事 | 破晓战队所装备的尖端战甲，核心能源皆来自愿力 |

## 愿宝

愿力凝结成「愿宝」，成为乐园的通货。

公司颁布《愿宝与信用点兑换协议》，把愿力纳入信用体系。从此，想象也可以标价。

## 循环

愿力需要循环：幻造种完成壮举，民众关注，愿力增长，幻造种继续存在。

4.6 中，千星城的愿力循环崩溃，幻造种面临消散。灯塔献出自身一切愿力，才让它们暂时存续。

## 4.7

4.7 中，虚照与谒者们汇聚寰宇众生的愿力，用「神的四个魔术」镇伏贪饕。

愿力第一次不是用来消费，而是用来救神。

## 学科的困境

《基础愿力学》的序言承认得很坦率：

> 由于我们对愿力的运用几乎完全依托于「欢愉」星神力量的影响，其本质带有极强的不确定性与混沌色彩，这使得传统的还原主义解析方法在它面前显得捉襟见肘。

直至今日，这门学科仍充斥着理论猜想、基于经验的半定量公式，以及无法复现的实验结果。
