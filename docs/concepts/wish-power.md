# 愿力

> 在这片由人与幻造种共同构筑的乐园里，你的心愿将作为一般等价物来流通。

## 基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 想象力与关注力 |
| 作用 | 幻造种存在的基础、乐园通货 |
| 凝结物 | 愿宝 |
| 活跃 | 4.0—4.7 版本 |

## 什么是愿力

愿力是人们对某件事的想象、关注与相信。

幻造种靠愿力存在：有人看，它就活着；没人看，它就会消散。二相乐园把这件事做成了经济制度——心愿可以作为一般等价物来流通。

## 愿宝

愿力凝结成「愿宝」，成为乐园的通货。

公司颁布《愿宝与信用点兑换协议》，把愿力纳入信用体系。从此，想象也可以标价。

## 循环

愿力需要循环：幻造种完成壮举，民众关注，愿力增长，幻造种继续存在。

4.6 中，千星城的愿力循环崩溃，幻造种面临消散。灯塔献出自身一切愿力，才让它们暂时存续。

## 4.7

4.7 中，虚照与谒者们汇聚寰宇众生的愿力，用「神的四个魔术」镇伏贪饕。

愿力第一次不是用来消费，而是用来救神。
