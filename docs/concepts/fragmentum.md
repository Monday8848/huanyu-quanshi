# 裂界

> 「看到没有，这痕迹……空间站有『裂界』化迹象的传闻看来也不是毫无根据。」
>
> ——空间站防卫科员

## 基本信息

| 项目 | 内容 |
|------|------|
| 外文名 | Fragmentum |
| 成因 | 星核力量的侵蚀 |
| 特征 | 空间畸变、物质异化、持续蔓延 |
| 产物 | 裂界造物（怪物）、被冻结或重构的地貌 |
| 已知案例 | 雅利洛-Ⅵ（永冬）、空间站「黑塔」（局部裂界化） |
| 应对 | 封锁区域、切断能源、武装清剿 |

## 它是什么

裂界不是「另一个世界」，而是现实被星核啃出来的伤口。它出现在星核所在或曾经所在的星球上，表现为空间结构的畸变、地貌的异常重构，以及从裂界里走出来的怪物——裂界造物。

它有三个稳定特征：

1. **会蔓延**。裂界不是静态的景点，它像锈一样沿着物质与能量扩散。
2. **会改造生态**。雅利洛-Ⅵ 的疯地鼠就是例子：学界普遍认为它们那些不利种群存续的怪异性状，成因是裂界侵蚀加速蔓延；它们对裂界中的某种物质异常敏感，因而变得极度暴力，甚至同类相食。
3. **会造出敌人**。裂界造物不是野生生物，是裂界对入侵者的反应产物。

## 雅利洛-Ⅵ：一场没有尽头的冬天

雅利洛-Ⅵ 的永冬与裂界是同一个问题的两面。星核让星球冻结，裂界在城市外围不断生成敌人，贝洛伯格只能缩在城墙后面。

这决定了贝洛伯格的全部政治：

- 大守护者必须把资源投入对裂界的战事，于是下层区被牺牲。
- 银鬃铁卫的主要职责从对外防御变成守城与清剿。
- 可可利亚最终选择引入星核——用造成问题的东西去解决问题。

## 空间站「黑塔」：裂界化的另一种样本

空间站的裂界不是整颗星球的灾难，而是局部感染：怪物破坏电源设备、电梯停运、科员被困在下层区域，防卫科只能封锁区域再逐段清理。

两个案例对照起来能看出裂界的尺度差异：在雅利洛-Ⅵ 它是文明的终结条件，在空间站它是一次需要封锁与抢修的工业事故。

## 怎么对付它

游戏里给出的手段都很朴素，也很说明问题：

| 手段 | 出处 | 逻辑 |
|------|------|------|
| 封锁区域 | 空间站防卫科 | 先切断蔓延路径，再处理内部 |
| 恢复供电 | 空间站维修人员 | 裂界会破坏基础设施，抢修即作战 |
| 武装清剿 | 银鬃铁卫 | 裂界造物必须物理清除 |
| 星核处理 | 贝洛伯格主线 | 治本是取走源头 |

## 与星核的关系

裂界是星核的「症状」，不是星核本身。这也解释了为什么反物质军团往星球上投星核：他们要的不是毁灭一颗星，而是让这颗星自己长出毁灭。
