# 克里珀

> 「哲思者仰望星河，探求文明的终极目标——『筑墙』，雄浑的回声响彻脑海：『筑墙。』」
>
> ——阿德里安·斯宾塞-史密斯，《有关星空的寓言集》

## 基本信息

| 项目 | 内容 |
|------|------|
| 命途 | 存护 |
| 别称 | 琥珀王、补天司命（仙舟《星神论》）、天垣之神 |
| 工程 | 天慧星墙、亚空晶壁、巨引源基盘 |

| 派系 | 筑城者、星际和平公司 |

## 砌造者

天慧星墙、亚空晶壁、巨引源基盘的砌造者，崇拜者称其「琥珀王」。其为更古老的「黄昏战争」的幸存者。

祂知晓大敌的吞噬迫在眉睫。因此不得不以光年为单位铸造障壁加以封印，隔绝保护尚有生机的世界。

## 厄喀德娜天垣

太卜司《星神论》留下了对克里珀工程最直接的目击记录：星历 1000 年左右，最初的九艘仙舟巨舰别离故乡、迢迢苦旅后，**目睹了分隔世界与无尽虚空的藩篱——厄喀德娜天垣**。

克里珀所筑的天体级造物「亚空晶壁」分隔并保护了诸界。这道墙是什么材质、砌到何处、墙外有什么，没有任何后续记录——因为墙的另一侧，正是琥珀王拼命想隔开的东西。

## 与信徒背道而驰

《星神论》记下了银河中最耐人寻味的矛盾：为琥珀王奉献的主要派系「星际和平公司」，所做的却是促成星海间的文明交流与融合——他们拥有寰宇最大的星际航行舰队，贸易、迁徙，贯穿祂竖起的墙。

更矛盾的是，公司中甚至出现了「存护」的**令使**。《星神论》的评述意味深长：「这种与神明背道而驰的行为没有受到任何谴责，颇耐人寻味。」——或许对克里珀而言，被「护住」的方式并不重要；也或许，筑墙与通商本就是同一件事的两面。

## 为什么筑墙

银河对克里珀的动机有两种猜测：

- 祂预见了足以令宇宙湮灭的危机，为万千世界建筑壁垒；
- 祂甘愿沦为其它星神的苦隶，尊奉旨意为祂们修筑城墙。

克里珀从不回答。祂只是继续砌。

## 琥珀纪

星际和平公司以「琥珀纪」为宇宙通用纪年，名号取自琥珀王。把一位星神的形象用作历法的刻度，是公司对祂最高的敬意，也是最实际的利用。贝洛伯格的大守护者官邸「克里珀堡」同样以祂命名——冰封的城市里，存护之名无处不在。
