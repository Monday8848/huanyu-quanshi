# 塞纳托斯

> 「灰黯之手。」
>
> 当众多灵魂无处安息时，冥河潮汐便会涌上大地，塞纳托斯会掌船前来，接引它们去往来世。

## 权柄

塞纳托斯不负责杀人，只负责引渡。

- **死亡**：它是那道手续，不是那把刀。人怎么死，归纷争、归黑潮、归自己；死之后往哪里去，归它。
- **湮灭**：当灵魂无处安息，冥河潮汐便会涌上大地。潮水不是惩罚，是溢出的收纳。

## 两个半身

塞纳托斯是十二泰坦中唯一一位「把自己劈开」的神。

- **死之半身·玻吕茜亚**：上一代「死亡」的黄金裔。她背负「拒绝死亡」的命运，在人间诞生的那一瞬间便宣告死去。她出生即死，所以泰坦也在世上不复存在。
- **生之半身·遐蝶**：塞纳托斯的「生之侧面」，被赐予「赐予死亡」的永生。她是被强加诅咒的人——不会死，只能送别人死。

3.2 版本的剧情把这条线补完了：遐蝶是创世时玻吕茜亚灵魂的再组合，加上炼金术的造物。她以巨龙玻吕刻斯的模样，承载着姐姐的灵魂在冥河里溯流而上，送她重返人间。

## 哀地里亚与冥河

哀地里亚是敬爱死亡的国度，终日飘雪。那里的人把死亡看作最后一道手续，不哭、不闹、不拖延。遐蝶在那里长大，被训练成送别亡者的督战圣女。

**3.2 版本**，为了寻回开拓者被夺走的未来，众人加快寻找塞纳托斯的踪迹。遐蝶促成元老院提出「暂停逐火之旅」的议题，并在诡计半神赛飞儿的帮助下赶往龙骸古城斯缇科西亚。她成功炼成死龙玻吕刻斯，借它回到冥界，见到塞纳托斯，把泰坦火种与夺走的未来悉数归还。

翁法罗斯的生死流转重归有序。代价是遐蝶自己永居冥界——生死之间的门从此不再关闭，但守门的人回不来了。

**第二轮回（3.5 版本之后）**，光历 4123 年，遐蝶完成死亡试炼成为半神。奥赫玛全境沦陷后，为保护通往创世涡心的密道，她化作死龙，成为通道的守护者。开拓者前往莹骨海床时一路看见的龙骨，就是她的化身。

## 火种与半神

| 环节 | 内容 |
|------|------|
| 火种 | 「死亡」 |
| 状态 | 3.2 由遐蝶归还 |
| 继承 | 遐蝶（生之半身）／玻吕茜亚（死之半身） |
| 代价 | 继承者永居冥界，或出生即死 |
| 第二轮回 | 遐蝶化龙守通道，直至开拓者归来 |

死亡火种是十二枚里最公平的一枚：它不问你是谁，只问你能不能替别人走完最后一段路。
