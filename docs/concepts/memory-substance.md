# 忆质

> 记忆在这里不是抽象的东西，而是可以挖出来、装进罐子、卖给别人。

## 定义

忆质是承载记忆的特殊介质。它能记录、保存、甚至再现某段经历，是「记忆」这条命途在物质层面的表现形式之一。

在大多数世界，忆质只是微量存在，普通人一辈子也接触不到。但在某些忆质储量异常丰富的星球，它会成为一种资源——可以被开采、加工、交易，也可以被用来建造。

## 匹诺康尼

匹诺康尼是已知忆质储量最丰富的地方。

整座梦境之城都建在忆质之上：街道、建筑、天空，甚至空气中的气味，都是忆质对记忆的重构。家族接手这颗星球之后，做的第一件事就是把忆质变成商品——宾客付费入梦，消费的是别人（或自己）的记忆。

这也是匹诺康尼最不舒服的地方：它的繁华建立在对记忆的开采上，而记忆原本属于谁，往往没人追问。

## 忆质与梦

忆质和梦不是一回事，但关系极近。

梦是忆质的活动状态，忆质是梦的物质基础。一个人的梦，本质上是他的忆质在自行重组；一座城的梦，则是大量忆质被统一调度的结果。

这解释了一个现象：在匹诺康尼，梦可以被设计、被修改、被出售。因为梦的底层是物质，物质就可以被工程化。

## 风险

忆质不是安全的东西。

长期接触忆质的人会出现记忆混乱，分不清哪些经历是自己的；被过度开采的忆质会失去结构，变成无法还原的残渣；而用忆质构建的梦境，一旦结构崩塌，里面的人未必能醒过来。

匹诺康尼危机中，这些风险全部变成了现实。

## 未解的问题

官方对忆质的解释始终留有余地。它来自哪里、为什么某些星球储量特别丰富、开采殆尽之后会发生什么——这些问题都还没有答案。

有一种推测是：忆质与「记忆」星神浮黎有关，甚至是浮黎存在的某种副产物。这个说法目前没有直接证据，但能解释忆质为什么会集中在少数区域。
