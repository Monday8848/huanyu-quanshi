# 扎格列斯

> 「翻飞之币。」
>
> 扎格列斯无心履行神职，它热爱在众神的道路上制造分歧，戏耍众神，创造出种种混乱失序。

## 权柄

扎格列斯是十二泰坦里唯一一位「不想上班」的神。

- **混乱**：它热爱在众神的道路上制造分歧、戏耍众神，把秩序拨歪一点点，看它怎么自己倒。
- **机遇**：它掌管运气，但不保证好运。它只保证「事情会变得有趣」。

## 神体与信徒

它的形象是一枚翻飞的硬币，也是一张双面的脸——一面在笑，一面在哭。翁法罗斯人说，你永远不知道落下来的是哪一面，因为硬币还在空中。

它是贫民与凡人的神。贵族向塔兰顿求公平，穷人向扎格列斯求一次好运。多洛斯是失落的盗寇之都，三百侠盗在那里纵情游戏、横行无忌；那座城的传说里，有一半功劳要记在扎格列斯头上。

## 赛飞儿

赛飞儿（赛法利娅）是「捷足的贼星」，戏弄诡计火种的黄金裔。她执掌诡计神权多年，神出鬼没、来去如风，从未有人能捕捉到她的真实轨迹。她的口头禅是「呵，还想诓我？没门！」

**3.3 版本**，赛飞儿受命回城，承诺在逐火小队离城时守护「负世」泰坦刻法勒的火种。她在龙骸古城与循火种而来的盗火行者周旋许久，最终不敌被杀。

但她早就设计好了后手：刻法勒的火种已交予贼灵巴特鲁斯，命它伺机交给白厄等人。她死后，依靠她的谎言维持运转的黎明机器陷入静默，奥赫玛陷入永夜。

一个以谎言为权能的人，最后用一句谎话救了整座城。

| 环节 | 内容 |

| 火种 | 「诡计」 |

| 继承 | 赛飞儿（赛法利娅） |
| 结局 | 3.3 被盗火行者杀害 |
| 遗产 | 刻法勒火种经巴特鲁斯转交白厄 |

诡计火种是十二枚中最早「有主」的一枚。扎格列斯大概很满意这个结果：别的神都在等英雄，它的英雄早就在路上了。
